# distro-exam – Exam: distributions and packages

Status: **ogranskad**

Provfrågorna bygger på sub-kapitlen i huvudkapitlet distro. De rätta svaren är påståenden som
granskas här.

| Påstående | Källa | Status | Datum |
|---|---|---|---|
| `/etc/os-release` visar distributionens namn och version | | ogranskad | 2026-10-30 |
| `uname -r` visar kärnans version | | ogranskad | 2026-10-30 |
| `pacman` hör ihop med `.pkg.tar.zst` (inte `dnf`/`.deb` eller `apt`/`.rpm`) | | ogranskad | 2026-10-30 |
| Arch är en rullande distribution utan versioner | | ogranskad | 2026-10-30 |
| `apt update` hämtar paketlistan, `apt upgrade` installerar nya versioner | | ogranskad | 2026-10-30 |
| `sudo pacman -S htop` installerar htop | | ogranskad | 2026-10-30 |
| `pacman -Sy` följt av `pacman -S paket` är en partiell uppgradering som kan förstöra systemet | | ogranskad | 2026-10-30 |
| dnf:s `[y/N]`: Enter installerar inget | | ogranskad | 2026-10-30 |
| AUR har byggrecept, granskas inte av Arch, uppdateras inte av `pacman -Syu`, och `makepkg` körs utan sudo | | ogranskad | 2026-10-30 |
| `sudo dnf copr enable användare/projekt` lägger till ett COPR-förråd | | ogranskad | 2026-10-30 |
| Snaps uppdateras automatiskt i bakgrunden | | ogranskad | 2026-10-30 |
| En nedladdad AppImage utan körrättighet ger `Permission denied` | | ogranskad | 2026-10-30 |
| Tumregeln: Flatpak för ett nyare skrivbordsprogram eller ett som saknas i förråden | | ogranskad | 2026-10-30 |
