# 在文件系统中导航

Linux 没有像 `C:` 这样的盘符。所有东西——硬盘、U 盘，甚至硬件设备——都位于**同一棵**目录树中，这棵树从**根目录**（root）开始，写作 `/`。

## 最重要的目录

| 目录 | 内容 |
|---|---|
| `/` | 根目录——整棵树的顶端 |
| `/home` | 用户的主目录，例如 `/home/elev` |
| `/root` | 管理员 root 的主目录 |
| `/etc` | 系统设置（配置文件） |
| `/usr/bin` | 程序（命令），例如 `ls` 和 `cat` |
| `/var/log` | 日志文件 |
| `/tmp` | 任何人都可以写入的临时文件 |
| `/dev` | 设备，例如磁盘 |
| `/proc` | 关于进程和内核的信息 |
| `/boot` | 启动计算机所需的文件 |

这种布局叫做*文件系统层次结构标准*（*Filesystem Hierarchy Standard*），在各个发行版之间几乎完全相同。

## 我在哪里？——`pwd`

`pwd`（*print working directory*，打印工作目录）显示你当前所在的目录：

```sh
pwd
```

## 这里有什么？——`ls`

`ls` 列出目录的内容。不带参数时，它显示你当前所在的目录，但你也可以指定另一个目录：

```sh
ls /etc
```

`-l` 选项会以长格式显示，给出更多信息：

```sh
ls -l
```

名字以点开头的文件是**隐藏文件**，默认不会显示。它们通常是设置文件，比如 `.bashrc`。`-a`（*all*，全部）选项可以把它们显示出来：

```sh
ls -a
```

选项可以组合使用：`ls -la` 与 `ls -l -a` 效果相同。

## 切换目录——`cd`

`cd`（*change directory*，切换目录）把你带到另一个目录：

```sh
cd /var/log
```

路径有两种：

- **绝对路径**以 `/` 开头，从根目录出发，例如 `/var/log`。无论你身在何处，它都有效。
- **相对路径**从你当前所在的目录出发。如果你在 `/`，只需 `cd var/log` 就能到达 `/var/log`。

有几个特殊名称值得记住：

| 名称 | 含义 |
|---|---|
| `.` | 你当前所在的目录 |
| `..` | 上一级目录（父目录） |
| `~` | 你的主目录 |
| `-` | （仅用于 `cd`）你上一次所在的目录 |

不带参数的 `cd` 总是会把你带回主目录。

```sh
cd ..
```

## Tab 补全

你很少需要把名字完整地敲出来。先输入开头部分，例如 `cd /va`，然后按 **Tab**——shell 会帮你补全剩下的部分。如果有多种可能，按 Tab 时会把它们都列出来。有经验的 Linux 用户总是在按 Tab！
