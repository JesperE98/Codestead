# ユーザー、パーミッション、sudo

Linux は、複数のユーザーが同じコンピューターを共有できるように作られています。
そのため、すべてのファイルには所有者と、誰が何をしてよいかを決めるルールが
あります。

## ユーザーとグループ

あなたはユーザー `elev` としてログインしています。どのユーザーも 1 つ以上の
**グループ** に属しています。

```sh
id
```

最も重要なユーザーは **root** です。root は何でもできる管理者です。root として
ログインすることはめったにありません。代わりに `sudo` を使います（後述）。

## パーミッションを読む

`ls -l` を実行して、最初の列を見てみましょう。

```text
-rw-r--r-- 1 elev elev  174 Oct 29 13:55 anteckningar.txt
drwxr-xr-x 2 elev elev 4096 Oct 29 13:55 dokument
```

最初の文字は種類を表します。`-` はファイル、`d` はディレクトリです。その後に
3 文字ずつのまとまりが 3 つ続きます。

```text
-     rw-     r--     r--
種類  所有者  グループ その他
```

| 文字 | ファイルの場合 | ディレクトリの場合 |
|---|---|---|
| `r`（read） | 内容を読む | 内容を一覧表示する |
| `w`（write） | 内容を変更する | 中にファイルを作成・削除する |
| `x`（execute） | ファイルをプログラムとして実行する | `cd` でディレクトリに入る |

その後に所有者（`elev`）とグループ（`elev`）が続きます。

## パーミッションを変更する – `chmod`

パーミッションは **数字** で指定できます。各まとまりは、r = 4、w = 2、x = 1
の合計である 1 桁の数字で表します。

| 数字 | パーミッション | よく使う対象 |
|---|---|---|
| `755` | `rwxr-xr-x` | プログラムとディレクトリ |
| `644` | `rw-r--r--` | 通常のファイル |
| `600` | `rw-------` | 秘密のファイル |

```sh
chmod 644 anteckningar.txt
```

**記号** でも指定できます。`u`（所有者）、`g`（グループ）、`o`（その他）、
`a`（全員）の後に、`+`、`-`、`=` のいずれかとパーミッションを続けます。

```sh
chmod u+x skript.sh
chmod go-w fil.txt
```

## スクリプト

**スクリプト** は、コマンドを書いたテキストファイルです。1 行目の
`#!/bin/bash` は *シバン*（shebang）と呼ばれ、どのプログラムでファイルを
実行するかをシステムに伝えます。

```sh
echo '#!/bin/bash' > datum.sh
echo 'echo "今日の日付:"; date' >> datum.sh
cat datum.sh
```

スクリプトをプログラムとして実行するには、実行可能にする必要があります。

```sh
chmod +x datum.sh
./datum.sh
```

今いるディレクトリは `PATH` に含まれていないので、`./` が必要です。

## root と sudo

パスワードが保存されている `/etc/shadow` のように、root しか読めないファイルも
あります。`sudo`（*superuser do*）を使うと、1 つのコマンドを root として
実行できます。

```sh
sudo whoami
```

初回は、`sudo` が **あなた自身の** パスワードを尋ねます。sudo を使えるのは、
管理者グループに属するユーザーだけです。{{distro}} では、そのグループは
**{{adminGroup}}** という名前です。

:::debian
Debian ファミリーでは、このグループは `sudo` という名前です。
:::

:::arch
Arch ファミリーでは、このグループは `wheel` という名前です。これは「偉い人たち」
（英語の *big wheel*）を意味する、昔の Unix の呼び名です。
:::

:::redhat
Red Hat ファミリーでは、このグループは `wheel` という名前です。これは「偉い人たち」
（英語の *big wheel*）を意味する、昔の Unix の呼び名です。
:::

root としてたくさんのコマンドを実行する必要がある場合は、`sudo -i` で root
シェルを起動できます。プロンプトが `#` に変わります。`exit` で元に戻ります。

> **覚えておきましょう！** sudo には安全網がありません。理解している
> コマンドだけを実行しましょう。

### よくある落とし穴

```text
sudo echo "text" > /etc/file     # これはうまくいかない
```

`>` のためにファイルを開くのは sudo ではなく、*あなたの* シェルです。
代わりに、sudo 付きで実行される `tee` を使いましょう。

```sh
echo "127.0.0.1 test.local" | sudo tee -a /etc/hosts
```
