# Setting up your IDE (DirectX 12) – no tasks

A reading chapter: choosing an IDE, a compiler, CMake, the libraries and the "Your project" panel. There are no
tasks; `start/` = `solution/` = `introduction/start` (the orange triangle) so the learner can copy the start files,
build and run them in their own IDE to check the setup. `edits.txt` is empty.
