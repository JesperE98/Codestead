## `prefilter-map`
- **Task:** Create the pre-filtered environment map: a 64 × 64 floating-point cube map with mipmaps (`prefilterMap`) whose five mip levels hold the environment blurred for the roughness 0, 0.25, 0.5, 0.75 and 1.0. Write `ImportanceSampleGGX` and the sampling loop in `prefilter.fs` (128 samples, the mip level of the environment chosen from each sample's pdf), give the environment cube map mipmaps for that, and render every face of every level before the render loop. For now show the pre-filter map's mip level 1.2 as the background.
- **Hint:** `glEnable(GL_TEXTURE_CUBE_MAP_SEAMLESS);`. The environment map: minification filter `GL_LINEAR_MIPMAP_LINEAR`, and after its six faces were rendered `glBindTexture(GL_TEXTURE_CUBE_MAP, envCubemap); glGenerateMipmap(GL_TEXTURE_CUBE_MAP);`. The pre-filter cube map: like the irradiance map but 64 × 64 with `GL_LINEAR_MIPMAP_LINEAR` and `glGenerateMipmap(GL_TEXTURE_CUBE_MAP)` (that allocates the levels). The capture: `for (unsigned int mip = 0; mip < maxMipLevels; ++mip)`: `mipWidth = static_cast<unsigned int>(64 * std::pow(0.5, mip))`, resize the renderbuffer, `glViewport(0, 0, mipWidth, mipHeight)`, `float roughness = (float)mip / (float)(maxMipLevels - 1);`, and for the six faces `glFramebufferTexture2D(GL_FRAMEBUFFER, GL_COLOR_ATTACHMENT0, GL_TEXTURE_CUBE_MAP_POSITIVE_X + i, prefilterMap, mip)` – the last argument is the mip level. `prefilter.fs`: `ImportanceSampleGGX` turns the two random numbers `Xi` into a halfway vector (`phi = 2.0 * PI * Xi.x`, `cosTheta = sqrt((1.0 - Xi.y) / (1.0 + (a*a - 1.0) * Xi.y))`, then tangent space → world space); in `main` for each `i`: `Xi = Hammersley(i, SAMPLE_COUNT)`, `H = ImportanceSampleGGX(Xi, N, roughness)`, `L = normalize(2.0 * dot(V, H) * H - V)`, and if `NdotL > 0.0`: `pdf = D * NdotH / (4.0 * HdotV) + 0.0001`, `saTexel = 4.0 * PI / (6.0 * resolution * resolution)`, `saSample = 1.0 / (float(SAMPLE_COUNT) * pdf + 0.0001)`, `mipLevel = roughness == 0.0 ? 0.0 : 0.5 * log2(saSample / saTexel)`, `prefilteredColor += textureLod(environmentMap, L, mipLevel).rgb * NdotL; totalWeight += NdotL;`. The background: bind `prefilterMap` and read level 1.2 in `background.fs`.
- **When done:** `main.cpp`: `glEnable(GL_TEXTURE_CUBE_MAP_SEAMLESS);`; `Shader prefilterShader("cubemap.vs", "prefilter.fs");`; `envCubemap`'s `GL_TEXTURE_MIN_FILTER` is `GL_LINEAR_MIPMAP_LINEAR` and `glGenerateMipmap(GL_TEXTURE_CUBE_MAP)` follows the conversion loop (with `envCubemap` bound); learnopengl's blocks `// pbr: create a pre-filter cubemap, and re-scale capture FBO to pre-filter scale.` (`prefilterMap`, six faces `GL_RGB16F, 64, 64`, `GL_LINEAR_MIPMAP_LINEAR`, `glGenerateMipmap(GL_TEXTURE_CUBE_MAP)`) and `// pbr: run a quasi monte-carlo simulation on the environment lighting to create a prefilter (cube)map.` (`maxMipLevels = 5`, the `mip` loop with `mipWidth` / `mipHeight` from `64 * std::pow(0.5, mip)`, `glRenderbufferStorage`, `glViewport`, `prefilterShader.setFloat("roughness", roughness)`, the face loop with `glFramebufferTexture2D(…, prefilterMap, mip)`, `glClear`, `renderCube()`); the background binds `prefilterMap`; `glDeleteTextures(1, &prefilterMap);`. `background.fs`: `textureLod(environmentMap, WorldPos, 1.2)`. `prefilter.fs`: `ImportanceSampleGGX` and learnopengl's sampling loop with `SAMPLE_COUNT = 128u` and `resolution = 128.0`.

Write `ImportanceSampleGGX`, the geometry functions (with the IBL `k`) and `IntegrateBRDF` in `brdf.fs`, render the screen quad once into the texture, and for now show the texture on a screen quad that covers the window.

## Notes
- All the IBL passes (environment capture, mipmaps, irradiance convolution, pre-filter levels, BRDF texture) run
  **once, in the setup**, before the render loop.
- The pre-filter pass assumes the view direction equals the reflection direction equals the normal (learnopengl's
  simplification, from Epic's split sum approximation).
- Without the mip-level trick the 128 samples per texel would miss or over-count the small, very bright sun and the
  lamps: the rougher levels show bright dots. Sampling a blurrier level of the environment for samples with a low pdf
  removes them; that is why the environment cube map gets mipmaps (`glGenerateMipmap` after the capture).
- `glGenerateMipmap` on the pre-filter map is only there to allocate the mip levels; every level is then rendered.
- The vertex tangent replaces learnopengl's `dFdx` / `dFdy` trick in `getNormalFromMap()`: see the note in
  `../pbr-lighting/tasks.md`.
