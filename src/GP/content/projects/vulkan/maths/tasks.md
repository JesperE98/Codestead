# The maths of 3D – no tasks (Vulkan)

The first lesson of *Going 3D*: the mathematics behind the part (axes and handedness, degrees and radians, sine and
cosine on the unit circle, vectors, matrices, a matrix's columns, why 4×4) – the same for every API, with quiz
questions but no code to write. There are no tasks; `start/` = `solution/` = `textures/solution` (the finished
Textures program) so the learner can still build and run it while reading. `edits.txt` is empty.
