# プロジェクト: クラブハウス

あなたは友だち数人と秘密クラブを結成しました。クラブには名前も、合図の握手も、
パスワードもあります。でも、クラブハウスがありません。とはいえ、あなたのコンピューターには
場所がたっぷりあります。ルールは簡単です。中に入れるのはメンバーだけ、ドアのノックは
スクリプトで、秘密の入口があり、夜は誰かが見張りに立ち、クラブハウスが見つかってしまった
ときのために、いつでもバックアップがあること。

必要なものはすべて「システム」で学びました。パーミッション、変数、リンク、プロセス、
アーカイブです。新しいことは何もありません。部品を自分で組み立てるのがこの課題です。

## ミッション

1. **クラブハウスを建てる。** ディレクトリ `~/{{clubDir}}` を作ります。読み、書き、中に
   入れるのはあなただけ。グループとその他には何も与えません（`rwx------`）。
2. **ドアマンを雇う。** `echo` でクラブのパスワードを表示するスクリプト
   `~/{{clubDir}}/{{knockScript}}` を書きます。実行できるようにして、実行してみましょう。
3. **道しるべを立てる。** クラブハウスへのフルパスを値に持つ環境変数 `{{clubVar}}` を
   作り、`cd ${{clubVar}}` でそこへ行けるようにします。
4. **秘密の入口を隠す。** クラブハウスにまっすぐ通じるシンボリックリンク
   `~/{{documents}}/{{wardrobe}}` を作ります。洋服だんすの奥にクラブハウスを探す人は
   いません。
5. **夜の見張りを立てる。** `sleep 3600` をバックグラウンドで実行して、1 時間見張りを
   させます。ログアウトしても続けさせること。（眠る以外に何もしない見張り番:
   とてもリアルです。）
6. **バックアップを取る。** クラブハウス全体を圧縮アーカイブ `~/{{clubBackup}}` に
   まとめます。
7. **見張りを帰らせる。** 朝になりました。プロセスを終了させます。

このテキストの横にあるリストのマイルストーンは、コマンドを実行するたびに自動で
チェックされます。

## ヒント

- `ls -ld ~/{{clubDir}}` は、ディレクトリの中身ではなくディレクトリ自体のパーミッションを
  表示します。r = 4、w = 2、x = 1 です。
- ドアマンに必要なのは 1 行だけです。シングルクォートで囲めば、書いたとおりにファイルに
  入ります。今いるディレクトリのスクリプトは、名前の前に `./` を付けて実行します。
- 変数を作るときは `=` の前後にスペースを入れないこと。そして `export` を忘れずに。
  忘れると、ただのシェル変数のままです。`echo ${{clubVar}}` で確かめましょう。
- `ln -s` は、先にリンク先、最後にリンクの名前を指定します。そのあと
  `cd ~/{{documents}}/{{wardrobe}}` を試して、どこに着くか見てみましょう。
- `jobs` はバックグラウンドジョブを番号付きで表示し、`ps` はその PID を表示します。
- ホームディレクトリからまとめると、アーカイブの中のパスが `{{clubDir}}/` で始まります。
  `tar -tzf` で何が入ったかがわかります。

## もっとやってみたい？

マイルストーンが終わったら、クラブはもっと大きくなれます。1 語でクラブハウスへ行ける
エイリアスを作りましょう。クラブハウスにメンバー名簿を置き、ホームディレクトリにそれへの
ハードリンクを置きましょう。バックアップを新しいディレクトリに展開して、ドアマンがまだ
パスワードを覚えているか確かめましょう。それから、クラブハウスが引っ越したら、秘密の
入口はどうなるでしょう？
