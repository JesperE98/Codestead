# プロジェクト: 中古のノートパソコン

友だちの Alex が中古のノートパソコンを買いました。そして、少し説得したところ、
あなたが {{distro}} をインストールすることになりました。インストールはうまくいきました。
さて、Alex から希望リストが届いています。

> 1. 最新の状態にしてね。セキュリティの穴だらけのコンピューターなんていやだから。
> 2. 来週からプログラミング言語 Go の講座が始まるんだ。
> 3. 何がコンピューターを重くしているのかわかるもの。
> 4. ちゃんとしたエディター。みんな Vim って言ってる。
> 5. 映画！ 映画が見られないと困る。

必要なものはすべて「ディストリビューションとパッケージ」で学びました。新しいことは
何もありません。パッケージマネージャーの正しいコマンドと、正しいパッケージ名を自分で
見つけるのがこの課題です。

## ミッション

1. **コンピューターを最新にする。** 最新のパッケージリストを取得し、インストール済みの
   パッケージをすべてアップグレードします。
2. **Go を探す。** パッケージリストを検索して、プログラミング言語 Go のパッケージが、
   あなたのディストリビューションで何という名前なのかを調べます。どこでも同じ名前とは
   限りません！
3. **希望リストをインストールする。** プロセスビューアー `htop`、プログラミング言語 Go、
   テキストエディター Vim です。
4. **再確認する。** *インストール済み* のパッケージの一覧で Go を探します。
5. **Vim を削除する。** Alex は Vim を試して、抜け出し方がわからなくなりました。
   「消して！」Vim をアンインストールします。
6. **映画。** メディアプレーヤー VLC（`org.videolan.VLC`）を Flatpak として Flathub から
   インストールします。
7. **試運転。** ノートパソコンを返す前に、Go にバージョンを表示させて、講座を始められる
   ことを Alex に見せましょう。

このテキストの横にあるリストのマイルストーンは、コマンドを実行するたびに自動で
チェックされます。マイルストーンはファミリーごとに数えられます。別のファミリーの
ディストリビューションでもう一度やれば、新しい「方言」に出会えます。

## ヒント

:::debian
- {{distro}} のパッケージマネージャーは `apt` です。システムを変えるコマンドは `sudo` を
  付けて実行します。`apt update` はリストを取得するだけで、新しいバージョンを
  インストールするのは `apt upgrade` です。
:::
:::arch
- {{distro}} のパッケージマネージャーは `pacman` です。大文字が操作（`-S`、`-R`、`-Q`）で、
  小文字は修飾子です。アップグレードはいつも `-Syu` で。
:::
:::redhat
- {{distro}} のパッケージマネージャーは `dnf` です。`[y/N]` は Enter が **いいえ** と
  答えるという意味なのを忘れずに。
:::
- 検索は名前と説明の両方を調べます。結果が長いときは、もっと絞り込んだ検索か `grep` が
  役に立ちます。
- パッケージ名はたいていどこでも同じですが、いつもとは限りません。迷ったら検索です。
- Flatpak がない、または Flathub を知らない？ パッケージ `flatpak` をインストールして、
  `flatpak remote-add` で Flathub を追加しましょう。ユニバーサルパッケージの章で
  やったとおりです。

## もっとやってみたい？

マイルストーンが終わっても、Alex にはもちろんまだ希望があります。`htop` を起動して、
何が動いているか見てみましょう。Go パッケージの情報を見て、大きさを調べましょう。
VLC にどんな権限があるか Flatpak に聞いてみましょう。そして、やっぱり Alex が
ターミナルを大好きになったら、Vim をもう一度インストールしましょう。
