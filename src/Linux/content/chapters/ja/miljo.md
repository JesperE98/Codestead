# 変数、PATH、エイリアス

シェルは **変数** という形で独自の記憶を持っています。この章では、変数の
読み方と設定のしかた、シェルがプログラムを見つけるしくみ、そして自分だけの
ショートカットの作り方を学びます。

## 環境変数

変数を読むには、名前の前に `$` を付けます。

```sh
echo $HOME
echo "私の名前は $USER です"
```

`env` はすべての *環境変数* を一覧表示します。環境変数とは、あなたが起動した
プログラムからも読める変数のことです。

```sh
env
```

変数は `NAME=value` で作成します（`=` の前後にスペースを入れてはいけません！）。
`export` を付けると環境変数になります。

```sh
export EDITOR=nano
```

```quiz
値 `blue` を持つ変数 `COLOR` を作るのはどの行ですか？
- [ ] `COLOR = blue`
- [x] `COLOR=blue`
- [ ] `$COLOR=blue`
---
`=` の前後にスペースを入れてはいけません。スペースがあると、シェルは `COLOR`
をコマンドだと思ってしまいます。`$` は変数を *読む* ときにだけ使います。
```

## シングルクォートとダブルクォート

ここには重要な違いがあります。

```sh
echo "ホーム: $HOME"
echo 'ホーム: $HOME'
```

**ダブル** クォートの中では、変数はその値に置き換えられます。**シングル**
クォートの中では、すべてが書いたとおりにそのまま表示されます。

```predict
$ x=linux
$ echo "I like $x"
$ echo 'I like $x'
I like linux
I like $x
```

## PATH – コマンドはどこにある？

`ls` と入力すると、シェルは `PATH` 変数に並んでいるディレクトリを順番に
調べて、`ls` という名前のファイルを探します。

```sh
echo $PATH
```

定番の技として、コロンを改行（`\n`）に変えて、`PATH` の各ディレクトリを
1 行ずつ表示する方法があります。

```sh
echo $PATH | tr ':' '\n'
```

`which` は、プログラムがどこで見つかったかを表示します。`cd` のように、
ファイルではなくシェルに *組み込まれている* コマンドもあります。`type` を使うと、
ある名前が何なのかがわかります。

```sh
which ls
type cd
```

`PATH` にないプログラムを実行したい場合は、そのパスを指定する必要があります。
たとえば、今いるディレクトリにあるファイルなら `./myprogram` のようにします。

```quiz
今いるディレクトリに `hello` というプログラムがあり、そのディレクトリは
`PATH` に入っていません。どうやって実行しますか？
- [ ] `hello`
- [x] `./hello`
- [ ] `type hello`
---
パスを指定しないと、シェルは `PATH` にあるディレクトリしか探しません。`./hello`
はファイルの場所、つまり今いるディレクトリを正確に示します。
```

## 終了コード – `$?`

どのコマンドも、終了するときに **終了コード** を残します。`0` はすべて
うまくいったことを意味し、それ以外はエラーを意味します。直前の終了コードは
`$?` に保存されます。

```sh
ls /{{missing}}
echo $?
```

`&&` と `||` が見ているのは、この終了コードです。

## エイリアス

**エイリアス** は自分で作るショートカットです。

```sh
alias ll='ls -la'
ll
```

引数なしの `alias` はすべてのエイリアスを一覧表示し、`unalias ll` で
エイリアスを削除します。

```predict
$ alias hi='echo Hello'
$ hi
Hello
```

## 設定を保存する – `~/.bashrc`

作成した変数やエイリアスは、ターミナルを閉じると消えてしまいます。残して
おくには、`~/.bashrc` ファイルに書いておきます。bash は新しいターミナルが
開かれるたびにこのファイルを読み込みます。ファイルを変更したあとは、
次のコマンドですぐに読み込めます。

```sh
source ~/.bashrc
```

```quiz
エイリアスを作ってからターミナルを閉じ、新しいターミナルを開きました。
エイリアスが消えています。どうすればよかったのでしょうか？
- [ ] 引数なしで `alias` を実行する
- [x] エイリアスを `~/.bashrc` に書いておく
- [ ] `export` で作成する
---
`~/.bashrc` に書いたものは、新しいターミナルが開かれるたびに読み込み直されます。
```
