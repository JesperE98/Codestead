# プロジェクト: 月曜日に新しい同僚が来る

金曜日の午後 3 時半。上司がドアから顔をのぞかせます。
「そうそう、{{newUser}} さんが月曜からサポートチームに入るんだ。準備を全部
お願いできる？ アカウント、チームのフォルダー、最初の週に読む資料。それから、
今度こそイントラネットが動くようにしておいてね。前回の新人さんは、最初の午前中
ずっと *Couldn't connect to server* を眺めていたから」

必要なものはすべて「システム管理」の中にあります。ユーザーとグループ、ディスク、
サービスに、それより前のパートの知識を少し足せば十分です。新しいことは何も
ありません。部品を自分で組み立てて、月曜の朝を何事もなく迎えるのがこの課題です。

## ミッション

1. **アカウント。** ホームディレクトリ付きで、シェルが `/bin/bash` のユーザー
   `{{newUser}}` を作り、アカウントにパスワードを設定します。
2. **チーム。** グループ `{{teamGroup}}` を作り、`{{newUser}}` と自分自身の両方を
   追加します。`{{newUser}}` には sudo の権限はありません。試用期間が終わるまでは
   お預けです。
3. **共有フォルダー。** グループ `{{teamGroup}}` が所有する `/srv/{{teamGroup}}` を
   作ります。グループはフォルダーの読み書きと中に入ることができ、ほかの人は何も
   できません。
4. **アカウントを試す。** `{{newUser}}` になって共有フォルダーにファイルを作り、
   権限がうまく働くことを確かめたら、自分のアカウントに戻ります。
5. **ウェルカムパック。** 最初の週に読む資料 `{{report}}` は USB メモリ
   （`/dev/sdb1`）にあります。`{{newUser}}` のホームディレクトリにコピーを置き
   ます。所有者は root ではなく `{{newUser}}` です。終わったら USB メモリを
   アンマウントしましょう。
6. **イントラネット。** チームのイントラネットはサービス `myserver` です。今
   動いていて、**さらに** コンピューターが起動するたびに自動で起動するように
   します。
7. **リハーサル。** コンピューターを再起動し、今回の起動でイントラネットが自動で
   起動したことをジャーナルで示します。

このテキストの横にあるリストのマイルストーンは、コマンドを実行するたびに自動で
チェックされます。

## ヒント

- ここでの作業はほとんどがシステムを変更するので、たいていのコマンドに `sudo` が
  必要です。
- `usermod -aG` の `-a` を忘れずに。忘れると、ユーザーはほかのすべてのグループ
  から外されてしまいます。`id {{newUser}}` で、アカウントが入っているグループが
  わかります。
- `ls -ld` でディレクトリの所有者、グループ、権限がわかります。権限は 8 進数で
  数えましょう。*rwx* が 7、何もなしが 0 です。
- `sudo` でコピーしたファイルの所有者は root です。代わりに新人 *として* コピー
  すれば（`su -` か `sudo -u` を使います）、最初から正しい人の所有になります。
- root が所有するコピーがもう置いてある？ 自分のホームディレクトリの中なので、
  `{{newUser}}` はそれを削除して、もう一度コピーできます。
- `umount` が *target is busy* と言う？ 自分のシェルがそのディレクトリの中に
  います。先に `cd ~` しましょう。
- `start` と `enable` は別のことです。`systemctl is-active` と
  `systemctl is-enabled` で今の状態がわかります。
- 再起動のあとは、`journalctl -b` で今回の起動の分だけが表示されます。

## もっとやってみたい？

マイルストーンを終えたら、さらに続けてみましょう。新人のファイルは収まるでしょう
か？ `df -h` と `du -sh` が知っています。`usermod -L` でアカウントを月曜の朝まで
ロックし、`passwd -S` で確認して、`usermod -U` でロックを解除してみましょう。
システムの側からも自分の仕事を眺めてみてください。`/etc/passwd` と `/etc/group` の
`{{newUser}}` の行、そして `systemctl status myserver` です。
