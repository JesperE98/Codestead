# プロジェクト: dotfiles を荷造りしよう

ビッグニュースです。来週、新品のコンピューターが届きます。すてきですね。ただ、
このコンピューターで設定したものは全部置いていくことになります。エイリアスも、
git の名前も、細かな調整も全部です。それらはホームディレクトリにある小さな隠し
ファイル、つまり名前が点で始まるファイルに入っています。だから *dotfiles* と
呼ばれ、世界中のプログラマーが自分の dotfiles を git リポジトリに入れています。
新しいコンピューターではそれをクローンするだけで、1 分後にはもうくつろげるのです。

あなたの dotfiles も荷造りしましょう。必要なものはすべて「その他のツール」に
あります。git と、シェルとその設定ファイルについて学んだことです。それを自分で
組み立てるのがこの課題です。

## ミッション

1. **引っ越し用の箱を用意する。** ディレクトリ `~/{{dotfilesDir}}` を作り、git
   リポジトリにします。
2. **今あるものを詰める。** bash の設定 `~/.bashrc` と git の設定 `~/.gitconfig` を
   リポジトリにコピーします。名前の点は残しても取っても構いません。どちらもよく
   使われています。
3. **自分のものを加える。** リポジトリにファイル `{{aliasFile}}` を書き、役に立つ
   エイリアスを 2 つ以上入れます。
4. **箱に封をする。** 2 つのコピーと `{{aliasFile}}` を含むコミットを作ります。
5. **秘密は外に置く。** Wi-Fi のパスワードは `~/{{dotfilesDir}}/{{secretFile}}` に
   置くことにします。でも、履歴には絶対に入れてはいけません。dotfiles の
   リポジトリは公開されていることが多いのです！ ファイルを作り、git に無視させ、
   そのために必要なものをコミットしましょう。
6. **ブランチで実験する。** ブランチ `{{aliasBranch}}` を作り、`{{aliasFile}}` に
   エイリアスを 1 つ以上追加して、そのブランチでコミットします。
7. **荷ほどきして使う。** 新しいエイリアスはちゃんと動くので、`{{aliasBranch}}` を
   メインのブランチにマージします。それから `source` で `{{aliasFile}}` をシェルに
   読み込み、エイリアスを 1 つ実行してみましょう。

このテキストの横にあるリストのマイルストーンは、コマンドを実行するたびに自動で
チェックされます。

## ヒント

- `ls -a` は隠しファイル、つまり名前が点で始まるファイルも表示します。
- `git status` をこまめに実行しましょう。何が新しく、何が変わり、何が次のコミット
  に入るのかを教えてくれます。
- エイリアスは `alias ll='ls -la'` のように書き、`=` の前後に空白は入れません。
  `echo` でこの行を書くなら、外側をダブルクォート、内側をシングルクォートにします。
- git が *Please tell me who you are* と言ったら、まず `git config --global` で
  `user.name` と `user.email` を設定しましょう。
- `.gitignore` が効くのは、git がまだ追跡していないファイルだけです。うっかり
  パスワードをコミットしてしまったら？ `git rm --cached` でリポジトリから外せます。
  ディスクには残ります。ただし古いコミットにはまだ入っているので、現実の世界なら
  パスワードを変えるところです。
- `source` はファイルを今いるシェルに読み込みます。zsh は bash と同じエイリアスの
  行を理解するので、このファイルはどちらでも使えます。

## もっとやってみたい？

マイルストーンを終えても、まだ詰めるものはあります。`~/.bashrc` の最後に
`source ~/{{dotfilesDir}}/{{aliasFile}}` という行を加えれば、新しい端末を開く
たびにエイリアスが使えます。`~/.zshrc` や fish の `~/.config/fish/config.fish` が
あれば、それもコピーしましょう。新しいコンピューターのふりもしてみましょう。
`git clone ~/{{dotfilesDir}} ~/new-computer` で、全部そろっていますか？
`{{secretFile}}` は本当に入っていませんか？ 最後に `git log --oneline --graph --all`
で自分の仕事を眺めましょう。
