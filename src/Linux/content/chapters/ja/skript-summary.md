# まとめ: スクリプトと自動化

このパートでは、コマンドを自分だけのプログラムに変えました。

## sed と awk によるテキスト処理

`sed` は行を編集します。`s/古い/新しい/` は置換（すべての一致には`g`）、アドレスは行を選び、`d` は削除し、`-n` と `p` を組み合わせると指定したものだけを表示します。`sed -i` はファイルそのものを変更します。`awk` は列を扱います。`-F` は区切り文字を指定し、`$1` … `$NF` はフィールドで、`{ }` の前のパターンは行を選び、`END { }` は最後の行のあとに実行されます。

## シェルスクリプト

スクリプトは、シバン `#!/bin/bash` で始まる、コマンドを書いたテキスト
ファイルです。ヒアドキュメント（`cat > file << '{{heredocEnd}}'`）で書き、`chmod +x` で
実行可能にし、`./` を付けて実行します。`#` で始まる行はコメントです。

変数は `name=value` で作り（スペースは入れません）、ダブルクォートの中で
使います。`"$name"`、またはすぐあとにテキストが続くときは `"${name}_text"` と
書きます。`$(command)` はコマンドが出力したものに置き換えられ、`$(( ))` は
整数の計算をします。スクリプトは引数を `$1`、`$2` …、`$#`、`"$@"` から
読みます。

`if` はコマンドの終了コードを見ます。たいていはテストコマンド `[ ]` です。
数値は `-eq`、`-lt` などで比較し、テキストは `=` と `!=` で比較します。`for` は
リストを順にたどり、`while` は条件が真であるあいだ続き、`while read` は
ファイルを 1 行ずつ処理します。`case` はパターンの中から選び、関数は独自の `$1`
を持つ名前の付いたコードのまとまりで、`read` はユーザーに入力を求めます。
`exit 1` は、スクリプトを呼び出した側に何かがうまくいかなかったことを伝えます。

## cron で定期的なジョブを実行する

**cron** は、あなたの **crontab** にあるジョブを決まった時刻に実行します。
各行には 5 つの時刻フィールド（分、時、日、月、曜日）があり、その後に
コマンドが続きます。`*` は毎回、`*/5` は 5 ごとという意味です。`crontab -l` は
ジョブを表示し、`crontab -` は入力から新しいジョブを登録します。このとき古い
ジョブはすべて置き換えられます。ジョブはターミナルの設定なしで、短い `PATH` で
実行されるので、出力はファイルに送りましょう。`journalctl -u cron` は実行の
記録を表示し、`systemctl list-timers` は systemd のタイマーを表示します。

## コマンドと構文

| 構文 | 何をするか |
|---|---|
| `sed`: `s/…/…/g`、`d`、`p`、`q`、`-n`、`-i`、`-E`、`-e` | 行のストリームを編集する |
| `awk`: `-F` 区切り文字、`$1`、`$NF`、`NF`、`NR`、`BEGIN`、`END` | 列を扱う |
| `#!/bin/bash` | シバン: どのプログラムでスクリプトを実行するか |
| `cat > file << '{{heredocEnd}}'` | `{{heredocEnd}}` の行まで、行をファイルに書き込む |
| `name=value` · `"$name"` · `"${name}"` | 変数を作る · 使う |
| `$(command)` | コマンドが出力したものに置き換えられる |
| `$(( a * 6 ))` · `(( a++ ))` | 整数の計算 · 変数を変更する |
| `$0` · `$1` · `$#` · `"$@"` | スクリプトの名前 · 最初の引数 · 引数の数 · すべての引数 |
| `if [ ... ]; then ...; elif ...; else ...; fi` | 条件分岐 |
| `-f` · `-d` · `-z` | ファイルが存在する · ディレクトリが存在する · 変数が空 |
| `=` · `!=` | テキストが等しい · 異なる |
| `-eq` · `-ne` · `-lt` · `-le` · `-gt` · `-ge` | 数値を比較する |
| `[[ $file == *.txt ]]` | パターンが使える、bash の賢いテスト |
| `for x in list; do ...; done` | リストを順にたどるループ |
| `while [ ... ]; do ...; done` | 条件が真であるあいだ繰り返すループ |
| `while read line; do ...; done < file` | ファイルを 1 行ずつ処理する |
| `break` · `continue` | ループを抜ける · 次の周回へ進む |
| `case $x in pattern) ...;; *) ...;; esac` | パターンで選ぶ |
| `name() { ...; }` · `local` · `return` | 関数 · ローカル変数 · 関数を終える |
| `read -p "Question " var` | キーボードから 1 行読む |
| `exit 1` | 終了コードを付けてスクリプトを終える |
| `set -euo pipefail` | 最初のエラーでスクリプトを止める |
| `crontab -l` · `crontab -r` | 自分の crontab を表示する · 削除する |
| `echo '* * * * * command' \| crontab -` | 入力から crontab を登録する（古いものは置き換えられる） |
| `(crontab -l; echo 'LINE') \| crontab -` | 古いジョブを残したままジョブを追加する |
| `MIN HOUR DAY MONTH WEEKDAY command` | crontab の 1 行。たとえば `30 2 * * 1-5` |
| `systemctl list-timers` | systemd のタイマーを表示する |
