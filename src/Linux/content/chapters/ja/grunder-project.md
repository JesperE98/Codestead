# プロジェクト: ログ探偵

朝 7 時 45 分。上司がコーヒーカップを手に、あなたの机の横に立っています。
「昨日サーバーの調子が悪かったんだ。原因は誰にもわからないし、お客さんから電話が
かかってきはじめている。何が起きたのか調べて、お昼までに短いレポートを書いてくれる？」

必要なものはすべてログファイル `~/{{documents}}/server.log` と、「基本」で学んだコマンドの
中にあります。新しいことは何もありません。部品を自分で組み立てるのがこの課題です。

## ミッション

1. **捜査を始める。** フォルダー `~/{{caseDir}}` とサブフォルダー `{{evidence}}` を作ります。
   証拠もレポートもすべてここに入れます。
2. **証拠を確保する。** ログを `{{evidence}}` にコピーします。そのあとはコピーのほうで
   作業します。元のファイルには手を付けません。
3. **エラーを抜き出す。** `ERROR` を含む行をすべて、別のファイル
   `~/{{caseDir}}/{{errorsFile}}` に保存します。
4. **レポートを書く。** レポート `~/{{caseDir}}/{{caseReport}}` は 1 行ずつ作っていきます。
   - まず**警告の数**。`WARN` を含む行で、大文字か小文字かは問いません。
   - 次に**最初のエラー行**。いつ問題が始まったのかがわかるようにします。
   - 最後にすべてのエラーの**時刻**。1 行に 1 つずつ、新しいものから並べます。
5. **事件を解決する。** レポート全体を表示して、すべてそろっているか確かめます。

このテキストの横にあるリストのマイルストーンは、コマンドを実行するたびに自動で
チェックされます。

## ヒント

- まずは `cat` か `less` でログを眺めて、各行がどんな形なのかを確かめましょう。
- `>` と `>>` の違いを思い出しましょう。一方はファイルを上書きし、もう一方は末尾に
  追加します。うっかりレポートを上書きしても大丈夫。警告の数からやり直せば済みます。
- パイプ（`|`）は、あるコマンドの出力を次のコマンドに渡します。2 つか 3 つの
  コマンドをつなげると、いくつものマイルストーンが短い 1 行で片付きます。
- ログの各行は、スペースで区切られたフィールドでできています。日付、時刻、レベル、
  メッセージです。

## もっとやってみたい？

マイルストーンを終えたら、自分でさらに調べてみましょう。`404` エラーを返したのは
どのページでしょう？ レベルが `INFO` の行はいくつあるでしょう？ 見つけたことを
レポートに書き足してください。本物の探偵は謎を残しません。
