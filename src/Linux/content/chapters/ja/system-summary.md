# まとめ: システム

このパートでは、コマンドのまわりで起きていることを見てきました。シェルの記憶、
誰が何をしてよいか、どのプログラムが動いているか、そしてファイルをどうやって
まとめるかです。

## 変数、PATH、エイリアス

変数は `$NAME` で読み、`NAME=値` で作ります。`=` の前後にスペースは入れません。
`export` は変数を環境変数にし、あなたが起動するプログラムからも読めるように
します。ダブルクォートの中では変数がその値に置き換えられ、シングルクォートの
中では、すべてが書いたとおりに表示されます。シェルは `PATH` にあるディレクトリ
からコマンドを探します。`$?` には直前のコマンドの終了コードが入っていて、`0` は
うまくいったという意味です。エイリアスと変数は、`~/.bashrc` に書いておかない
限り、ターミナルを閉じると消えてしまいます。

## ユーザー、パーミッション、sudo

どのファイルにも、所有者、グループ、そして所有者・グループ・その他のための
3 組のパーミッションがあります。`r` = 4、`w` = 2、`x` = 1 なので、`755` は
`rwxr-xr-x`、`600` は `rw-------` です。スクリプトには `x` パーミッションが
必要で、今いるディレクトリは `PATH` に含まれていないので、`./` を付けて
実行します。`sudo` は 1 つのコマンドを root として実行し、あなた自身の
パスワードを尋ねます。Ubuntu では、グループ `sudo` に属するユーザーが sudo を
使えます。

## リンクとファイルの情報

ファイルの中身とパーミッションは **inode** にあり、ディレクトリの中の名前は
inode を指しています。`ln -s` は **シンボリックリンク** を作ります。これはパスが
入った小さなファイルで、リンク先がなくなると壊れます。リンクの中の相対パスは、
リンク自身があるディレクトリから数えられます。`-s` を付けない `ln` は
**ハードリンク**、つまり同じ inode のもう 1 つの名前を作ります。`stat` は
ファイルのすべてを表示し、`file` は名前に関係なくファイルの中身が何かを教えて
くれます。そして **umask** が新しいファイルのパーミッションを決めます。`022`
なら `644`、`077` なら `600` だけになります。

## プロセスとジョブ

実行中のプログラムはどれも、PID と親（PPID）を持つプロセスです。`ps aux` は
すべてのプロセスを表示し、`top` はプロセッサーの使用率順にリアルタイムで表示
します。`kill` はシグナルを送ります。既定は `SIGTERM`（15）で、最後の手段が
`SIGKILL`（9）です。`&` を付けるとコマンドはバックグラウンドで実行され、`jobs`、
`fg`、`bg` でターミナルのジョブを管理できます。`nohup` はログアウトしたあとも
コマンドを動かし続け、`watch` はコマンドを何度も繰り返し実行します。

## アーカイブと圧縮

`tar` はファイルを 1 つのアーカイブにまとめ、`gzip` は 1 つのファイルを小さく
します。両方を組み合わせると `.tar.gz` になります。`c`、`x`、`t` のうち
ちょうど 1 つで tar に何をするかを伝え、`f` のあとにはアーカイブの名前を
続けます。`zcat` は `.gz` ファイルを展開せずに読み、`zip -r` / `unzip` は
zip ファイルを扱います。zip ファイルは Windows や macOS と共有しやすい形式です。

## コマンドとオプション

| コマンド | 何をするか |
|---|---|
| `echo $NAME` | 変数の値を表示する |
| `export NAME=value` | 環境変数を作る |
| `env` | すべての環境変数を一覧表示する |
| `which ls` · `type cd` | プログラムがどこにあるか · 名前が何なのかを表示する |
| `echo $?` | 直前のコマンドの終了コードを表示する |
| `alias ll='ls -la'` · `unalias ll` | エイリアスを作る · 削除する |
| `source ~/.bashrc` | `~/.bashrc` をすぐに読み込む |
| `id` · `groups` | 自分のユーザーとグループを表示する |
| `ls -l` | パーミッション、所有者、グループを表示する |
| `chmod 644 file` · `chmod u+x file` | パーミッションを数字で · 記号で変更する |
| `sudo command` · `sudo -i` | コマンドを root として実行する · root シェルを起動する |
| `sudo tee -a file` | パイプの最後で: root しか変更できないファイルにテキストを追記する |
| `ln -s target name` · `ln file name` | シンボリックリンクを作る · ハードリンクを作る |
| `readlink link` · `realpath path` | リンクがどこを指しているか · リンクをたどった完全なパス |
| `ls -li` | inode 番号とリンク数を表示する |
| `stat file` · `stat -c '%a %U' file` | ファイルのすべて · 指定したものだけ |
| `file file` | ファイルの中身が何か |
| `umask` · `umask 077` | 新しいファイルから取り除かれるパーミッションを表示する · 設定する |
| `ps` · `ps aux` · `ps -ef` | 自分のプロセス · すべてのプロセス · 親の PID 付き |
| `ps aux --sort=-%cpu` | すべてのプロセスを、重いものから順に |
| `pgrep -l name` | 名前からプロセスの PID を探す |
| `top` | プロセスのリアルタイム表示 |
| `kill PID` · `kill -9 PID` | プロセスに終了を頼む · 強制終了する |
| `pkill pattern` · `killall name` | 名前でプロセスを止める |
| `command &` | コマンドをバックグラウンドで実行する |
| `jobs` · `fg %1` · `bg %1` · `kill %1` | ジョブの一覧 · フォアグラウンドへ · バックグラウンドへ · 終了 |
| `nohup command &` | ログアウトしたあとも動かし続ける |
| `watch -n 5 command` | コマンドを 5 秒ごとに実行する |
| `uptime` · `free -h` | 負荷 · メモリ |
| `tar -czvf archive.tar.gz dir` | ディレクトリをまとめて圧縮する |
| `tar -tzvf archive.tar.gz` | アーカイブの中身を一覧表示する |
| `tar -xzvf archive.tar.gz -C dir` | アーカイブをディレクトリに展開する |
| `gzip file` · `gzip -k file` · `gunzip file.gz` | 圧縮する · 元のファイルを残す · 展開する |
| `zcat file.gz` | 圧縮ファイルを直接読む |
| `zip -r archive.zip dir` · `unzip archive.zip -d dir` | zip ファイルを作る · 展開する |
| `du -sh dir` | 何かがどれだけの容量を使っているかを表示する |
