# まとめ: 基本

どのディストリビューションでも毎日使うコマンドを学びました。テストの前に、
手早くおさらいしましょう。

## ファイルシステムを移動する

すべてはルート `/` から始まる 1 本のツリーにあります。設定は `/etc`、
プログラムは `/usr/bin`、ログは `/var/log`、自分のファイルはホームディレクトリ
`~` にあります。`pwd` は今いる場所を表示し、`ls` はそこにあるものを一覧表示し、
`cd` で移動します。**絶対パス** は `/` から始まり、**相対パス** は今いる
ディレクトリから始まります。`..` は 1 つ上のディレクトリで、引数なしの `cd` は
ホームに戻ります。

## ファイルとディレクトリ

`mkdir` はディレクトリを作り（`-p` で複数の階層を一度に作れます）、`touch` は
空のファイルを作ります。`cp` はコピーし（ディレクトリごとなら `-r`）、`mv` は
移動と名前の変更の両方を行い、`rm` は削除します。削除は完全で、ごみ箱は
ありません。`rmdir` は空のディレクトリしか削除しません。`rm -r` はディレクトリと
その中身をすべて削除します。`*`、`?`、`[abc]` のようなワイルドカードは、
コマンドが実行される前にシェルが展開します。スペースを含む名前には引用符が
必要です。

## テキストを読む、検索する

`cat` はファイルを表示し、`less` ではファイルをスクロールしながら読めます。
`head` と `tail` は先頭と末尾を表示します（`-n` で行数を選び、`tail -f` は
ファイルを追いかけます）。`wc` は行数、単語数、バイト数を数えます。`grep` は
パターンに一致する行を表示し、`sort` は行を並べ替え、`uniq` は隣り合った
重複行を取り除きます。`man` はコマンドのマニュアルを表示します。`cut` はフィールドを取り出します（`-d` で区切り文字、`-f` でフィールドを指定します）。

## リダイレクトとパイプ

どのプログラムにも 3 つのストリーム、stdin、stdout、stderr があります。`>` は
stdout をファイルに送り（ファイルは上書きされます）、`>>` は追記し、`<` は
stdin をファイルから読み込み、`2>` はエラーメッセージを、たとえば `/dev/null` に
リダイレクトします。パイプ `|` は、あるコマンドの出力を次のコマンドに送り、
`tee` は途中でコピーを保存します。`xargs` は入力の単語をコマンドの引数に
変えます。`;`、`&&`、`||` を使うと、1 行で複数のコマンドを実行できます。`tr` は 1 文字ずつ置き換え、削除（`-d`）、または圧縮（`-s`）し、stdin だけを読みます。

## コマンドとオプション

| コマンド | 何をするか | このパートで出てきたオプションと構文 |
|---|---|---|
| `pwd` | 今いるディレクトリを表示する | |
| `ls` | ディレクトリの中身を一覧表示する | `-l` 詳細形式、`-a` 隠しファイルも |
| `cd` | ディレクトリを移動する | `..` 上へ、`~` ホーム、`-` 直前のディレクトリ、引数なし = ホーム |
| `mkdir` | ディレクトリを作る | `-p` 複数の階層を一度に |
| `touch` | 空のファイルを作る | |
| `cp` | コピーする | `-r` ディレクトリごと |
| `mv` | 移動する、または名前を変える | |
| `rm` | 削除する | `-r` ディレクトリとその中身、`-f` 確認なし |
| `rmdir` | 空のディレクトリを削除する | |
| `cat` | ファイルを表示する | |
| `less` | ファイルを 1 ページずつ表示する | `/単語` で検索、`q` で終了 |
| `head` / `tail` | 先頭 / 末尾の行 | `-n N` 行数、`tail -f` 追いかける |
| `wc` | 行数、単語数、バイト数を数える | `-l` 行数だけ |
| `grep` | 一致する行を表示する | `-i`、`-n`、`-v`、`-c`、`-r`、`-E` |
| `sort` | 行を並べ替える | `-n` 数値、`-r` 逆順 |
| `uniq` | 隣り合った重複行を取り除く | `-c` 回数を数える |
| `man` | マニュアルページを表示する | |
| `tee` | 入力を先に渡しつつコピーを保存する | |
| `xargs` | 入力をコマンドの引数に変える | `-n 1` 1 つずつ、`-I {}` 1 行ずつ |
| `tr` | 文字を置き換える | `-d` 削除、`-s` 圧縮 |
| `cut` | フィールドを取り出す | `-d` 区切り文字、`-f` フィールド |

| 構文 | 意味 |
|---|---|
| `>` / `>>` | stdout をファイルへ（上書き / 追記） |
| `<` | stdin をファイルから |
| `2>` | stderr をファイルへ。例: `2> /dev/null` |
| `2>&1` | stderr を stdout と同じ行き先へ |
| `\|` | パイプ: あるコマンドの stdout を次のコマンドの stdin へ |
| `a ; b` | a を実行してから b を実行する |
| `a && b` | a が成功したときだけ b を実行する |
| `a \|\| b` | a が失敗したときだけ b を実行する |
| `*`、`?`、`[abc]` | ファイル名のワイルドカード |
