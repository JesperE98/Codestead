# 项目：二手笔记本

你的朋友 Alex 买了一台二手笔记本电脑，经过一番劝说，同意让你在上面装 {{distro}}。安装
很顺利。现在 Alex 发来了一份愿望清单：

> 1. 请保持最新。我可不想要一台满是漏洞的电脑。
> 2. 下周我要开始上 Go 编程语言的课。
> 3. 来个能看出是什么拖慢了电脑的东西。
> 4. 一个正经的编辑器。大家都说 Vim。
> 5. 电影！它必须能放电影。

你需要的一切都在《发行版和软件包》里学过。这里没有新知识；挑战在于自己找到包管理器的
正确命令——以及正确的软件包名。

## 任务

1. **把电脑更新到最新。** 获取最新的软件包列表，并升级所有已安装的软件包。
2. **找到 Go。** 在软件包列表中搜索，查出 Go 编程语言的软件包在你的发行版中叫什么。
   它不是到处都叫同一个名字！
3. **安装愿望清单。** 进程查看器 `htop`、Go 编程语言和文本编辑器 Vim。
4. **再确认一遍。** 在*已安装*软件包的列表中找到 Go。
5. **删除 Vim。** Alex 试了一下 Vim，结果找不到出口了。"把它弄走！"卸载 Vim。
6. **电影。** 从 Flathub 以 Flatpak 形式安装媒体播放器 VLC（`org.videolan.VLC`）。
7. **试运行。** 在把电脑还回去之前：让 Go 显示它的版本，好让 Alex 看到课程可以开始了。

这段文字旁边列表里的里程碑会在你运行命令时自动检查。它们按发行版家族分别计算——在另一个
家族的发行版上再做一遍这个项目，你就能认识一种新的"方言"。

## 小提示

:::debian
- 在 {{distro}} 上，包管理器是 `apt`。会修改系统的命令要用 `sudo` 运行，而
  `apt update` 只获取列表——安装新版本的是 `apt upgrade`。
:::
:::arch
- 在 {{distro}} 上，包管理器是 `pacman`。大写字母是操作（`-S`、`-R`、`-Q`），小写字母是
  修饰符。升级时一定要用 `-Syu`。
:::
:::redhat
- 在 {{distro}} 上，包管理器是 `dnf`。记住，`[y/N]` 表示按 Enter 回答的是**否**。
:::
- 搜索会同时查看名称和描述。如果结果很长，可以搜得更精确一些——或者用 `grep`。
- 软件包名在各处通常相同，但并不总是如此。拿不准时：搜索。
- 没有 Flatpak，或者它不认识 Flathub？安装软件包 `flatpak`，再用 `flatpak remote-add`
  添加 Flathub，就像你在通用软件包那一章里做的那样。

## 还想多做一点？

完成里程碑后，Alex 当然还会有更多愿望。启动 `htop`，看看有什么在运行。查看 Go 软件包的
信息，弄清楚它有多大。问问 Flatpak，VLC 有哪些权限。如果结果发现 Alex 其实很喜欢终端：
那就再把 Vim 装回去。
