# 项目：打包你的 dotfiles

大新闻：下周你就要拿到一台崭新的电脑了。真好——只不过你在这台电脑上设置好的一切都会留在原地。你的别名、你在 git 里的名字、所有那些小调整。它们住在主目录里的一些隐藏小文件中，这些文件的名字以点开头。所以它们被称为 *dotfiles*，世界各地的程序员都把自己的 dotfiles 放在一个 git 仓库里：到了新电脑上，克隆一下，一分钟后就有回家的感觉了。

是时候打包你的了。你需要的一切都在“更多工具”里——git，以及你学到的关于 shell 和它们的设置文件的知识。挑战在于你自己把它们拼起来。

## 任务

1. **找一个搬家纸箱。** 创建目录 `~/{{dotfilesDir}}`，并把它变成一个 git 仓库。
2. **打包你已有的东西。** 把你的 bash 设置 `~/.bashrc` 和 git 设置 `~/.gitconfig` 复制到仓库里。文件名里的点可以保留，也可以去掉——两种做法都很常见。
3. **加点自己的东西。** 在仓库里写文件 `{{aliasFile}}`，里面至少有两个对你有用的别名。
4. **封好箱子。** 做一次提交，包含两个副本和 `{{aliasFile}}`。
5. **把秘密挡在外面。** 你的 Wi-Fi 密码将放在 `~/{{dotfilesDir}}/{{secretFile}}` 里——但它绝不能进入历史记录。dotfiles 仓库常常是公开的！创建这个文件，让 git 忽略它，并提交为此需要提交的内容。
6. **在分支上做实验。** 创建分支 `{{aliasBranch}}`，在 `{{aliasFile}}` 中至少再加一个别名，并在这个分支上提交。
7. **拆箱并使用。** 新别名都能用，那就把 `{{aliasBranch}}` 合并到主分支。然后用 `source` 把 `{{aliasFile}}` 读进你的 shell，并运行你的一个别名。

这段文字旁边列表里的里程碑会在你运行命令时自动检查。

## 小提示

- `ls -a` 会显示隐藏文件——名字以点开头的那些。
- 经常运行 `git status`。它会告诉你哪些是新的、哪些改了，以及哪些会进入下一次提交。
- 别名写成 `alias ll='ls -la'`，`=` 两边没有空格。要用 `echo` 写这一行，外面用双引号，里面用单引号。
- git 说 *Please tell me who you are*？那就先用 `git config --global` 设置 `user.name` 和 `user.email`。
- `.gitignore` 只对 git 还没有跟踪的文件有效。不小心把密码提交了？`git rm --cached` 会把它从仓库里移除，但留在磁盘上。不过旧的提交里仍然有它——在现实中，你应该更换密码。
- `source` 会把文件读进你当前所在的 shell。zsh 能理解和 bash 一样的别名行，所以这个文件在两者中都能用。

## 还想多做一点？

完成里程碑之后，还有更多东西可以打包。在 `~/.bashrc` 末尾加上一行 `source ~/{{dotfilesDir}}/{{aliasFile}}`，这样每个新终端都会有你的别名。如果你有 `~/.zshrc` 或 fish 的 `~/.config/fish/config.fish`，也把它们复制进去。再扮演一下新电脑：`git clone ~/{{dotfilesDir}} ~/new-computer`——东西都在吗？`{{secretFile}}` 真的不在吗？最后，用 `git log --oneline --graph --all` 欣赏一下你的成果。
