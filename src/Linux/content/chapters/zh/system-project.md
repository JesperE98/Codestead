# 项目：俱乐部会所

你和几个朋友成立了一个秘密俱乐部。俱乐部有名字、有暗号握手、有密码——就是没有会所。
不过你的电脑空间多得是。规矩很简单：只有会员能进门，敲门要靠一个脚本，有一个秘密
入口，夜里有人站岗，而且永远留着一份备份，以防哪天会所被人发现。

你需要的一切都在《系统》里学过：权限、变量、链接、进程和归档。这里没有新知识；挑战
在于自己把这些零件拼起来。

## 任务

1. **建造会所。** 创建目录 `~/{{clubDir}}`。只有你可以读取、写入和进入它——所属组和
   其他人什么权限都没有（`rwx------`）。
2. **雇一个门卫。** 编写脚本 `~/{{clubDir}}/{{knockScript}}`，用 `echo` 打印出俱乐部的
   密码。让它可以执行，然后运行它。
3. **标出道路。** 创建环境变量 `{{clubVar}}`，值为会所的完整路径，这样
   `cd ${{clubVar}}` 就能带你过去。
4. **藏一个秘密入口。** 创建一个符号链接 `~/{{documents}}/{{wardrobe}}`，让它直通会所。
   谁也不会到衣柜深处去找俱乐部会所。
5. **安排夜间守卫。** 在后台运行 `sleep 3600`，让它守夜一小时——即使你退出登录也继续
   守着。（一个除了睡觉什么都不干的守卫：非常写实。）
6. **做一份备份。** 把整个会所打包进压缩归档 `~/{{clubBackup}}`。
7. **让守卫下班。** 天亮了——结束这个进程。

这段文字旁边列表里的里程碑会在你运行命令时自动检查。

## 小提示

- `ls -ld ~/{{clubDir}}` 显示目录本身的权限，而不是它里面的内容。r = 4，w = 2，x = 1。
- 门卫只需要一行。用单引号把这一行括起来，它就会原样写进文件。当前目录里的脚本要在
  名字前加 `./` 来运行。
- 创建变量时 `=` 两边不能有空格，也别忘了 `export`——否则它只是一个普通的 shell
  变量。用 `echo ${{clubVar}}` 检查一下。
- `ln -s` 先写目标，再写链接的名字。然后试试 `cd ~/{{documents}}/{{wardrobe}}`，看看
  你会到哪里。
- `jobs` 显示你的后台作业及其编号，`ps` 显示它们的 PID。
- 在主目录里打包，这样归档中的路径就以 `{{clubDir}}/` 开头。`tar -tzf` 可以看到里面
  有什么。

## 还想多做一点？

完成里程碑后，俱乐部还可以继续壮大。创建一个别名，一个词就能带你去会所。在会所里放
一份会员名单，并在主目录里放一个指向它的硬链接。把备份解压到一个新目录，检查门卫是否
还记得密码。还有：如果会所搬家了，秘密入口会怎么样？
