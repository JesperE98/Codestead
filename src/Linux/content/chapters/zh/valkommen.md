# 欢迎来到 Linux shell

本教程将教你如何通过命令行使用 Linux——从你的第一条命令，一直到在不同发行版上进行软件包管理。每一章讲解一个主题。正文中穿插着一些简短的**问题**；其中一些要在右侧的终端里动手试一试。回答完所有问题，本章的**任务**就会解锁。只要你做对了，任务就会被自动勾选。学习的最好方法就是*动手*：阅读、尝试、犯错，然后再试一次。

## 什么是 Linux？

严格来说，**Linux** 只是*内核*（kernel）：它是与硬件打交道的程序，让其他程序能够共享处理器、内存和磁盘。内核由 Linus Torvalds 于 1991 年创建，是自由软件。

要得到一个能用的系统，光有内核还远远不够：你还需要 shell、管理文件的工具、包管理器，也许还要一个桌面环境。**发行版**（*distribution*，简称 *distro*）把这些东西打包成一个开箱即用的整体。Debian、Ubuntu、Arch Linux 和 Fedora 就是几个著名的例子。

你在本教程中学到的大部分内容在每个发行版上都一样，所以课程就从这些内容开始。这里的终端运行的是 **Ubuntu 24.04 LTS**。各个发行版的区别主要在于如何安装软件——这会在关于发行版的那一章中讲到。

## 什么是 shell？

**shell** 是读取你输入的命令并执行它们的程序。最常见的 shell 是 **bash**，几乎所有发行版都默认使用它。其他流行的 shell 还有 **zsh**（macOS 的默认 shell）和 **fish**。它们的基础用法都是一样的。

注意*终端*（terminal）和 *shell* 的区别：终端是显示文字的窗口，而 shell 是在窗口里运行的程序。

```quiz
你输入 `ls` 并按下 Enter。是哪个程序读取并运行这条命令？
- [ ] 终端
- [x] shell
- [ ] 内核
---
终端只负责显示文字。shell（这里是 bash）读取你输入的内容并运行它。
```

## 提示符

当 shell 在等待命令时，它会显示一个**提示符**（prompt）。在这里的终端中，它看起来是这样的：

```text
{{user}}@ubuntu:~$
```

它告诉你：你是谁（`{{user}}`）、你在哪台计算机上（`ubuntu`），以及你在文件系统中的位置（`~` 表示你的主目录）。`$` 符号表示你是普通用户。如果你是管理员（*root*），看到的会是 `#`。

```quiz
提示符以 `#` 而不是 `$` 结尾。这说明了什么？
- [ ] 你在自己的主目录中
- [ ] 上一条命令失败了
- [x] 你是管理员 root
```

## 你的第一条命令

点击终端，输入下面的命令，然后按 **Enter**：

```sh
echo {{helloWorld}}
```

`echo` 只是把你给它的内容打印出来——这里是 *{{helloWorld}}*。大多数命令都遵循同样的格式：

```text
command  -options  arguments
ls       -l        /etc
```

*命令*（command）是要运行的程序，*选项*（options，也叫 *flags*）改变命令的行为，*参数*（arguments）则是命令要处理的对象。

```quiz
在命令 `ls -l /etc` 中，哪一部分是**选项**？
- [ ] `ls`
- [x] `-l`
- [ ] `/etc`
---
`ls` 是命令，`-l` 改变它的行为，而 `/etc` 是参数——也就是 `ls` 要处理的对象。
```

用 `echo` 输出一段你自己的文字试试：

```try
echo Linux is fun
---
`echo` 原样打印出了你给它的那些单词。
```

## 我是谁，我在哪里？

有两个小命令可以告诉你所在系统的情况。`whoami` 打印你当前登录所用的用户名。文件 `/etc/os-release` 描述了这个发行版，而 `cat` 会打印一个文件（后面的章节会进一步介绍 `cat`）：

```sh
whoami
cat /etc/os-release
```

## 模拟器是如何工作的

这里的终端是一个完全在本应用内部运行的**模拟器**。它的表现就像一台真正的 Linux 计算机，但你在这里做的任何事都不会伤害你自己的电脑——如果你搞砸了，随时可以用设置中的*重置终端*从头开始。

- **点击代码示例**，即可把命令放进终端。
- **Tab** 键可以补全命令和文件名。
- **上/下方向键**可以翻看之前输入过的命令。
- **Ctrl+L** 清屏，**Ctrl+C** 取消你正在输入的这一行。
- `help` 列出所有命令，`man command` 显示某个命令（command）的手册页。

```quiz
你输入了 `ech`，然后按下 **Tab**。会发生什么？
- [ ] 这一行被取消
- [x] shell 会尝试补全名字的剩余部分
- [ ] 屏幕被清空
---
Tab 键可以补全命令和文件名。**Ctrl+C** 取消这一行，**Ctrl+L** 清屏。
```
