# المتغيرات وPATH والأسماء المستعارة

للـ shell ذاكرة خاصة به على شكل **متغيرات**. ستتعلّم في هذا الفصل كيف تقرأها
وتضبطها، وكيف يجد الـ shell البرامج، وكيف تصنع اختصاراتك الخاصة.

## متغيرات البيئة

تقرأ قيمة متغير بوضع `$` قبل اسمه:

```sh
echo $HOME
echo "My name is $USER"
```

يعرض `env` كل *متغيرات البيئة* (environment variables) – وهي المتغيرات التي
تستطيع البرامج التي تشغّلها أن تقرأها أيضًا:

```sh
env
```

تنشئ متغيرًا بـ `NAME=value` (من دون مسافات حول `=`!). ومع `export` يصبح متغير
بيئة:

```sh
export EDITOR=nano
```

```quiz
أيّ سطر ينشئ المتغير `COLOR` بالقيمة `blue`؟
- [ ] `COLOR = blue`
- [x] `COLOR=blue`
- [ ] `$COLOR=blue`
---
يجب ألا توجد مسافات حول `=`. فمع المسافات يظن الـ shell أن `COLOR` أمر.
ولا تُستخدم `$` إلا عندما *تقرأ* متغيرًا.
```

## علامات الاقتباس المفردة والمزدوجة

هناك فرق مهم:

```sh
echo "Home: $HOME"
echo 'Home: $HOME'
```

داخل علامات الاقتباس **المزدوجة** تُستبدَل المتغيرات بقيمها. أما داخل علامات
الاقتباس **المفردة** فيُطبع كل شيء كما كُتب تمامًا.

```predict
$ x=linux
$ echo "I like $x"
$ echo 'I like $x'
I like linux
I like $x
```

## PATH – أين توجد الأوامر؟

عندما تكتب `ls`، يبحث الـ shell عن ملف اسمه `ls` في المجلدات المذكورة في المتغير
`PATH`، واحدًا تلو الآخر:

```sh
echo $PATH
```

يعرض `which` المكان الذي وُجد فيه البرنامج. بعض الأوامر، مثل `cd`، ليست ملفات
أصلًا، بل هي *مدمجة* في الـ shell – ويخبرك `type` بماهية الاسم:

```sh
which ls
type cd
```

إذا أردت تشغيل برنامج غير موجود في `PATH`، فعليك أن تعطي مساره، مثل
`./myprogram` لملف في المجلد الذي أنت فيه.

```quiz
لديك برنامج اسمه `hello` في المجلد الذي أنت فيه، وهذا المجلد ليس في `PATH`.
كيف تشغّله؟
- [ ] `hello`
- [x] `./hello`
- [ ] `type hello`
---
من دون مسار، لا يبحث الـ shell إلا في المجلدات الموجودة في `PATH`. أما `./hello`
فيحدّد مكان الملف بالضبط: في المجلد الحالي.
```

## رموز الخروج – `$?`

كل أمر يترك **رمز خروج** (exit code) عند انتهائه: `0` يعني أن كل شيء سار على ما
يرام، وأي قيمة أخرى تعني خطأً. ويُحفظ آخر رمز خروج في `$?`:

```sh
ls /{{missing}}
echo $?
```

رمز الخروج هو ما ينظر إليه `&&` و`||`.

## الأسماء المستعارة (aliases)

**الاسم المستعار** (alias) هو اختصار خاص بك:

```sh
alias ll='ls -la'
ll
```

يعرض `alias` من دون وسائط كل الأسماء المستعارة، ويحذف `unalias ll` واحدًا منها.

```predict
$ alias hi='echo Hello'
$ hi
Hello
```

## حفظ الإعدادات – `~/.bashrc`

المتغيرات والأسماء المستعارة التي تنشئها تختفي عندما تغلق الطرفية. وللاحتفاظ بها
تضعها في الملف `~/.bashrc`، الذي يقرؤه bash في كل مرة تُفتح فيها طرفية جديدة. بعد
تعديل الملف يمكنك تحميله فورًا بـ:

```sh
source ~/.bashrc
```

```quiz
أنشأت اسمًا مستعارًا، ثم أغلقت الطرفية وفتحت طرفية جديدة. فاختفى الاسم
المستعار. ما الذي كان ينبغي أن تفعله؟
- [ ] تشغيل `alias` من دون وسائط
- [x] وضع الاسم المستعار في `~/.bashrc`
- [ ] إنشاؤه باستخدام `export`
---
كل ما تضعه في `~/.bashrc` يُقرأ من جديد في كل مرة تُفتح فيها طرفية جديدة.
```
