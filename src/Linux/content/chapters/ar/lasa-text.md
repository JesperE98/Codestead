# قراءة النصوص والبحث فيها

كل شيء تقريبًا في لينكس عبارة عن نص: الإعدادات، والسجلات، والقوائم. لهذا توجد
أدوات صغيرة كثيرة لقراءة الملفات النصية والبحث فيها. في مجلد المنزل الخاص بك
مجلد اسمه `{{documents}}` فيه ملفات للتدرّب عليها، منها قائمة بالفواكه `{{fruits}}`
و`server.log`، وهو سجل لخادم ويب وهمي. والكلمات التي ستبحث عنها فيه – `INFO`
و`WARN` و`ERROR` – هي نفسها الموجودة في السجلات الحقيقية.

## عرض ملف – `cat` و`less`

يطبع `cat` الملف كاملًا:

```sh
cat {{documents}}/{{fruits}}
```

أما للملفات الطويلة فالأمر `less` أفضل. فيه تتنقل بمفاتيح الأسهم ومفتاح المسافة،
وتبحث بـ `/word`، وتخرج بـ `q`.

ألقِ نظرة على قائمة الفواكه – ستحتاج إليها في السؤال التالي:

```try
cat {{documents}}/{{fruits}}
```

## البداية والنهاية – `head` و`tail`

يعرض `head` الأسطر الأولى، و`tail` الأسطر الأخيرة. القيمة الافتراضية 10 أسطر،
لكن يمكنك اختيار العدد بـ `-n`:

```sh
head -n 5 {{documents}}/server.log
tail -n 3 {{documents}}/server.log
```

يقوم `tail -f` *بمتابعة* الملف ويعرض الأسطر الجديدة فور كتابتها – وهذا مثالي
للسجلات. أوقفه بـ **Ctrl+C**.

```predict
$ tail -n 1 {{documents}}/{{fruits}}
مانجو
---
يعرض `tail -n 1` السطر الأخير فقط.
```

## العدّ – `wc`

يعدّ `wc` (*word count*) الأسطر والكلمات والبايتات:

```sh
wc {{documents}}/{{fruits}}
```

غالبًا ما تريد عدد الأسطر فقط: `wc -l`.

## البحث – `grep`

`grep` من أكثر الأوامر فائدة على الإطلاق. فهو يعرض كل سطر يحتوي على نمط معيّن:

```sh
grep INFO {{documents}}/server.log
```

بعض الخيارات التي ستستخدمها كثيرًا:

| الخيار | المعنى |
|---|---|
| `-i` | تجاهل الفرق بين الأحرف الكبيرة والصغيرة |
| `-n` | إظهار أرقام الأسطر |
| `-v` | إظهار الأسطر التي *لا* تطابق |
| `-c` | عدّ الأسطر المطابقة |
| `-r` | البحث تعاوديًّا في كل ملفات المجلد |
| `-E` | أنماط موسّعة، مثل `"ERROR|WARN"` |

```sh
grep -n WARN {{documents}}/server.log
```

النمط هو *تعبير نمطي* (regular expression). مثالان: `^` تعني بداية السطر و`$`
نهاية السطر، لذا فإن `grep "^2026"` يجد الأسطر التي تبدأ بـ 2026.

```quiz
في `server.log` سطران فيهما `WARN` وسطر واحد فيه `warn` بأحرف صغيرة.
ماذا يطبع `grep -c WARN {{documents}}/server.log`؟
- [ ] 1
- [x] 2
- [ ] 3
---
يعدّ `-c` الأسطر المطابقة، ومن دون `-i` تختلف الأحرف الكبيرة عن الصغيرة.
أما `grep -ic WARN` فسيعدّ الثلاثة كلها.
```

```quiz
أيّ أمر يعرض كل سطر في `server.log` **لا** يحتوي على `INFO`؟
- [ ] `grep -i INFO {{documents}}/server.log`
- [ ] `grep -c INFO {{documents}}/server.log`
- [x] `grep -v INFO {{documents}}/server.log`
```

## الترتيب – `sort` و`uniq`

يرتّب `sort` الأسطر أبجديًا (`-n` للأرقام، و`-r` للترتيب العكسي). أما `uniq`
فيحذف الأسطر المطابقة للسطر الذي *فوقها مباشرة* – ولهذا يُستخدم دائمًا تقريبًا
بعد `sort`:

```sh
sort {{documents}}/{{fruits}}
```

```quiz
لماذا يُستخدم `uniq` دائمًا تقريبًا بعد `sort`؟
- [ ] لأن `uniq` لا يعمل إلا على الملفات المرتّبة ويفشل في غيرها
- [x] لأن `uniq` لا يحذف إلا الأسطر المطابقة للسطر الذي فوقها مباشرة، لذا يجب أن تكون الأسطر المتطابقة متجاورة
- [ ] لأن `sort` يحذف التكرارات و`uniq` يعيدها
```

## اقتطاع الحقول – `cut`

في `{{documents}}` يوجد ملف تمرين ثالث، وهو ملف CSV فيه درجات الطلاب:

```sh
cat ~/{{documents}}/{{grades}}
```

CSV اختصار لـ *comma-separated values* (قيم مفصولة بفواصل) – فالأعمدة مفصولة
بفواصل، والسطر الأول ترويسة.

عندما يتكوّن ملف من حقول بينها فاصل، يستطيع `cut` أن يلتقط حقلًا واحدًا. يختار
`-d` الفاصل (*delimiter*) ويختار `-f` الحقل الذي يُحتفظ به. وهذه هي المواد – الحقل
2 – من ملف CSV:

```sh
cut -d, -f2 ~/{{documents}}/{{grades}}
```

في `/etc/passwd` تُفصل الحقول بنقطتين رأسيتين، والحقل 1 هو اسم المستخدم، لذا
فإن `cut -d: -f1 /etc/passwd` يسرد كل المستخدمين.

## الدليل – `man`

نسيت ما يفعله أحد الخيارات؟ لكل أمر صفحة دليل (manual):

```sh
man grep
```
