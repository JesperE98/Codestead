# التنقل في نظام الملفات

لا توجد في لينكس أحرف للأقراص مثل `C:`. كل شيء – الأقراص الصلبة، وذواكر USB، بل
وحتى العتاد – يعيش في **شجرة واحدة** من المجلدات (directories) تبدأ من **الجذر**
(root)، ويُكتب `/`.

## أهم المجلدات

| المجلد | المحتوى |
|---|---|
| `/` | الجذر – قمة الشجرة |
| `/home` | مجلدات المنزل للمستخدمين، مثل `/home/{{user}}` |
| `/root` | مجلد المنزل الخاص بالمدير root |
| `/etc` | إعدادات النظام (ملفات الإعداد) |
| `/usr/bin` | البرامج (الأوامر) مثل `ls` و`cat` |
| `/var/log` | ملفات السجلات (logs) |
| `/tmp` | ملفات مؤقتة يمكن لأي أحد الكتابة فيها |
| `/dev` | الأجهزة، مثل الأقراص |
| `/proc` | معلومات عن العمليات والنواة |
| `/boot` | الملفات اللازمة لإقلاع الحاسوب |

يُسمّى هذا التنظيم *Filesystem Hierarchy Standard* (معيار هرمية نظام الملفات)،
وهو متطابق تقريبًا في جميع التوزيعات.

```quiz
يكتب برنامج ما ملف سجل. في أيّ مجلد تتوقع أن تجده؟
- [ ] `/etc`
- [ ] `/usr/bin`
- [x] `/var/log`
- [ ] `/home`
---
توضع ملفات السجل في `/var/log`. أما الإعدادات فتوجد في `/etc` والبرامج في `/usr/bin`.
```

## أين أنا؟ – `pwd`

يعرض `pwd` (*print working directory*) المجلد الذي أنت فيه حاليًا:

```sh
pwd
```

## ماذا يوجد هنا؟ – `ls`

يعرض `ls` محتويات مجلد. من دون وسائط يعرض المجلد الذي أنت فيه، لكن يمكنك أيضًا
تحديد مجلد آخر:

```sh
ls /etc
```

يعطيك الخيار `-l` تنسيقًا مطوّلًا فيه معلومات أكثر:

```sh
ls -l
```

الملفات التي تبدأ أسماؤها بنقطة تكون **مخفية** ولا تظهر افتراضيًا. وغالبًا ما
تكون ملفات إعدادات، مثل `.bashrc`. ويُظهرها الخيار `-a` (*all*):

```sh
ls -a
```

يمكن دمج الخيارات: `ls -la` هو نفسه `ls -l -a`.

```quiz
لماذا لا يُظهر الأمر `ls` وحده الملف `.bashrc` في مجلد المنزل؟
- [ ] لأنه ملف نظام لا يراه إلا root
- [x] لأن اسمه يبدأ بنقطة، فهو مخفي
- [ ] لأن `ls` لا يعرض إلا المجلدات
---
الملفات التي تبدأ أسماؤها بنقطة مخفية. ويعرضها `ls -a` أيضًا.
```

جرّب التنسيق المطوّل مع الملفات المخفية معًا:

```try
ls -la
```

## تغيير المجلد – `cd`

ينقلك `cd` (*change directory*) إلى مجلد آخر:

```sh
cd /var/log
```

هناك نوعان من المسارات:

- المسار **المطلق** يبدأ بـ `/` وينطلق من الجذر، مثل `/var/log`. وهو يعمل أينما
  كنت.
- المسار **النسبي** ينطلق من المجلد الذي أنت فيه. إذا كنت في `/`، يمكنك الوصول
  إلى `/var/log` بمجرد `cd var/log`.

```quiz
أنت في `/home`. أيّ الأوامر تنقلك إلى `/home/{{user}}/{{documents}}`؟ (اختر كل ما يعمل.)
- [x] `cd {{user}}/{{documents}}`
- [x] `cd /home/{{user}}/{{documents}}`
- [ ] `cd /{{user}}/{{documents}}`
- [ ] `cd {{documents}}`
---
`{{user}}/{{documents}}` مسار نسبي إلى `/home`، و`/home/{{user}}/{{documents}}` مسار مطلق،
لذا يعمل من أي مكان. أما `/{{user}}/{{documents}}` فيبدأ من الجذر، حيث لا يوجد
`{{user}}`.
```

هناك بعض الأسماء الخاصة التي تستحق المعرفة:

| الاسم | المعنى |
|---|---|
| `.` | المجلد الذي أنت فيه |
| `..` | المجلد الأعلى (الأب) |
| `~` | مجلد المنزل الخاص بك |
| `-` | (مع `cd` فقط) المجلد الذي كنت فيه آخر مرة |

`cd` من دون وسائط يعيدك دائمًا إلى المنزل.

```sh
cd ..
```

```predict
$ cd /usr/bin
$ cd ..
$ pwd
/usr
---
`..` هو المجلد الأعلى، لذا تنتهي من `/usr/bin` في `/usr`.
```

## الإكمال التلقائي بـ Tab

نادرًا ما تحتاج إلى كتابة الأسماء كاملة. اكتب البداية، مثل `cd /va`، ثم اضغط
**Tab** – وسيُكمل الـ shell الباقي. وإذا كانت هناك عدة احتمالات، فستظهر عندما
تضغط Tab. مستخدمو لينكس المتمرّسون يضغطون Tab طوال الوقت!
