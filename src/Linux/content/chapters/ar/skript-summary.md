# ملخّص: البرمجة النصية والأتمتة

في هذا الجزء حوّلت الأوامر إلى برامج خاصة بك.

## سكربتات الـ shell

السكربت ملف نصي فيه أوامر ويبدأ بالـ shebang `#!/bin/bash`. يمكنك كتابته باستخدام
here document (`cat > file << '{{heredocEnd}}'`)، وجعله قابلًا للتنفيذ باستخدام `chmod +x`،
وتشغيله باستخدام `./`. والأسطر التي تبدأ بـ `#` تعليقات.

تنشئ المتغيرات باستخدام `name=value` – دون مسافات – وتستخدمها داخل علامات اقتباس
مزدوجة: `"$name"`، أو `"${name}_text"` عندما يأتي نص بعده مباشرةً. يُستبدل
`$(command)` بما يطبعه الأمر، ويُجري `$(( ))` العمليات الحسابية على الأعداد
الصحيحة. ويقرأ السكربت وسائطه من `$1` و`$2` … و`$#` و`"$@"`.

ينظر `if` إلى رمز خروج أمر، وهو عادةً أمر الاختبار `[ ]`. تُقارن الأعداد باستخدام
`-eq` و`-lt` وأخواتهما، والنصوص باستخدام `=` و`!=`. تمر `for` على قائمة، وتستمر
`while` ما دام الشرط صحيحًا، وتمر `while read` على ملف سطرًا سطرًا. يختار `case`
بين أنماط، والدوال أجزاء مسمّاة من الشيفرة لها `$1` خاص بها، ويطلب `read` إدخالًا
من المستخدم. ويخبر `exit 1` من استدعى السكربت بأن شيئًا ما لم يسر على ما يرام.

## المهام المجدولة باستخدام cron

يشغّل **cron** المهام الموجودة في **crontab** الخاص بك في أوقات محدّدة. في كل سطر
خمسة حقول للوقت – الدقيقة والساعة ويوم الشهر والشهر ويوم الأسبوع – ثم الأمر؛ وتعني
`*` كل، و`*/5` كل خامس. يعرض `crontab -l` المهام، ويثبّت `crontab -` مهام جديدة من
مدخله – مستبدلًا كل المهام القديمة. تعمل المهام من دون إعدادات طرفيتك، ومع `PATH`
قصير، لذا أرسل مخرجاتها إلى ملف. يعرض `journalctl -u cron` كل مرة تشغيل، ويعرض
`systemctl list-timers` مؤقّتات systemd.

## الأوامر والصيغ

| الصيغة | ماذا تفعل |
|---|---|
| `#!/bin/bash` | الـ shebang: أيّ برنامج يشغّل السكربت |
| `cat > file << '{{heredocEnd}}'` | تكتب أسطرًا في ملف حتى السطر `{{heredocEnd}}` |
| `name=value` · `"$name"` · `"${name}"` | إنشاء · استخدام متغير |
| `$(command)` | يُستبدل بما يطبعه الأمر |
| `$(( a * 6 ))` · `(( a++ ))` | حساب الأعداد الصحيحة · تغيير متغير |
| `$0` · `$1` · `$#` · `"$@"` | اسم السكربت · الوسيط الأول · عدد الوسائط · كل الوسائط |
| `if [ ... ]; then ...; elif ...; else ...; fi` | الشروط |
| `-f` · `-d` · `-z` | الملف موجود · المجلد موجود · المتغير فارغ |
| `=` · `!=` | النصان متساويان · مختلفان |
| `-eq` · `-ne` · `-lt` · `-le` · `-gt` · `-ge` | مقارنة الأعداد |
| `[[ $file == *.txt ]]` | اختبار bash الأذكى، مع الأنماط |
| `for x in list; do ...; done` | حلقة على قائمة |
| `while [ ... ]; do ...; done` | حلقة ما دام الشرط صحيحًا |
| `while read line; do ...; done < file` | المرور على ملف سطرًا سطرًا |
| `break` · `continue` | مغادرة الحلقة · الانتقال إلى الدورة التالية |
| `case $x in pattern) ...;; *) ...;; esac` | الاختيار حسب النمط |
| `name() { ...; }` · `local` · `return` | دالة · متغير محلي · إنهاء الدالة |
| `read -p "Question " var` | قراءة سطر من لوحة المفاتيح |
| `exit 1` | إنهاء السكربت برمز خروج |
| `set -euo pipefail` | إيقاف السكربت عند أول خطأ |
| `crontab -l` · `crontab -r` | عرض · حذف ملف crontab الخاص بك |
| `echo '* * * * * command' \| crontab -` | تثبيت crontab من المدخل (يستبدل القديم) |
| `(crontab -l; echo 'LINE') \| crontab -` | إضافة مهمة مع الاحتفاظ بالمهام القديمة |
| `MIN HOUR DAY MONTH WEEKDAY command` | سطر في crontab، مثل `30 2 * * 1-5` |
| `systemctl list-timers` | عرض مؤقّتات systemd |
