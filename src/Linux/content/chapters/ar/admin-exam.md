# اختبار: إدارة النظام

أظهر ما تعلّمته عن الخدمات والأقراص والمستخدمين. تغطي الأسئلة الجزء كله، وتحتاج
إلى 80 % من الإجابات الصحيحة للنجاح.

```quiz
يجب أن يبدأ `myserver` تلقائيًا في كل مرة يُقلع فيها الحاسوب، لكن **لا** يجب
تشغيله الآن. أيّ أمر يفعل ذلك بالضبط؟
- [ ] `sudo systemctl start myserver`
- [x] `sudo systemctl enable myserver`
- [ ] `sudo systemctl enable --now myserver`
- [ ] `sudo systemctl restart myserver`
---
يسري `enable` عند الإقلاع، ويسري `start` الآن، ويفعل `--now` الأمرين معًا.
```

فشلت الخدمة `reportd` في البدء على هذا الحاسوب. ماذا يطبع هذا الأمر؟

```predict
$ systemctl is-active reportd
failed
---
لا يطبع `is-active` سوى كلمة واحدة – وهي هنا الحالة نفسها التي يسردها
`systemctl --failed`. وتكون حالة الخروج 0 فقط عندما تكون الإجابة `active`.
```

```quiz
تريد مراقبة سجل `myserver` وأنت تختبره، بحيث تظهر الأسطر الجديدة فور وصولها.
أيّ أمر تستخدم؟
- [ ] `journalctl -n 20`
- [x] `journalctl -u myserver -f`
- [ ] `journalctl -p err -b`
- [ ] `systemctl status myserver --all`
---
يختار `-u` وحدة واحدة، ويواصل `-f` عرض الأسطر الجديدة حتى تضغط Ctrl+C.
```

```try
systemctl cat myserver
---
`ExecStart=` هو الأمر الذي يبدأ الخدمة، و`WantedBy=` هو ما يستخدمه `enable`.
```

```quiz
تشغّل `systemctl stop myserver` دون `sudo` فتحصل على
*Interactive authentication required*. لماذا؟
- [ ] لأن myserver لا يعمل
- [x] لأن كل ما يغيّر خدمة يتطلب صلاحيات root
- [ ] لأن عليك أن تشغّل `daemon-reload` أولًا
- [ ] لأن `stop` لا يعمل إلا مع الخدمات المفعّلة
```

```quiz
لماذا يُكتب في `/etc/fstab` عادةً `UUID=…` بدلًا من `/dev/sda2`؟
- [ ] لأن الـ UUID أقصر في الكتابة
- [x] لأن أسماء الأجهزة قد تتغير عند إضافة أقراص، أما الـ UUID فلا يتغير أبدًا
- [ ] لأن `mount` لا يفهم أسماء الأجهزة
- [ ] لأن الـ UUID يُظهر مدى امتلاء نظام الملفات
---
يُنشأ الـ UUID مع نظام الملفات. وتجده باستخدام `lsblk -f` أو `blkid` أو
`findmnt`.
```

```quiz
يُظهر `df -h` أن `/` ممتلئ بنسبة 98 %. أيّ أمر يساعدك على معرفة **أيّ المجلدات**
تشغل المساحة؟
- [ ] `df -hT`
- [ ] `lsblk -f`
- [x] `du -h -d 1`
- [ ] `swapon --show`
---
يسأل `df` نظام الملفات عن مدى امتلائه، أما `du` فيمرّ على الملفات ويجمع أحجامها.
```

مجلد منزلك ليس على نظام ملفات خاص به على هذا الحاسوب. ماذا يطبع هذا؟

```predict
$ df -h ~ | tail -n 1 | tr -s ' ' | cut -d' ' -f6
/
---
عندما تعطي `df` مسارًا، لا يعرض إلا نظام الملفات الذي يقع عليه. والعمود السادس هو
`Mounted on` – أي نظام الملفات الجذر.
```

```quiz
أضفت سطرًا إلى `/etc/fstab`. ماذا يجب أن تفعل **قبل** أن تعيد التشغيل؟
- [ ] لا شيء – فالملف لا يُقرأ إلا عند الإقلاع
- [x] أن تختبره باستخدام `sudo mount -a`
- [ ] أن تشغّل `sudo systemctl daemon-reload`
- [ ] أن تهيّئ القسم باستخدام `mkfs`
---
قد يمنع خطأ في `/etc/fstab` الحاسوب من الإقلاع بشكل سليم. يركّب `mount -a` كل ما
في الملف مما لم يُركَّب بعد، فترى الأخطاء الآن.
```

```quiz
أنت على وشك تهيئة قسم باستخدام `mkfs` على حاسوب حقيقي. ما الذي يجب أن تتحقق منه
أولًا؟ (اختر كل ما ينطبق.)
- [x] أن الحجم والعمود `RM` والتسمية متطابقة، باستخدام `lsblk -f`
- [x] أن القسم غير مركَّب
- [x] أن لديك نسخة احتياطية من كل ما هو مهم
- [ ] أن القسم مذكور في `/etc/fstab`
```

```quiz
لماذا توجد تجزئات كلمات المرور في `/etc/shadow` لا في `/etc/passwd`؟
- [ ] لأن `/etc/passwd` صغير جدًا
- [x] لأن `/etc/passwd` يجب أن يكون مقروءًا للجميع، أما `/etc/shadow` فلـ root فقط
- [ ] لأن التجزئات قابلة للعكس، لذا يجب إخفاؤها
- [ ] لأن `/etc/passwd` لا يُقرأ إلا عند الإقلاع
---
وإلا لاستطاع أي أحد نسخ التجزئات ومحاولة كسرها على مهل. ويحتاج `ls -l` إلى
`/etc/passwd` ليعرض أسماء المالكين.
```

الحقول في `/etc/group` هي اسم المجموعة، و`x`، والـ GID، والأعضاء.
من في المجموعة `sudo`؟

```predict
$ grep ^sudo /etc/group | cut -d: -f4
{{user}}
```

```quiz
ماذا يحدث مع `sudo userdel kim` – دون `-r`؟
- [x] يُحذف المستخدم، لكن مجلد المنزل `/home/kim` يبقى
- [ ] لا شيء – يحتاج `userdel` دائمًا إلى `-r`
- [ ] يُحذف المستخدم ومجلد المنزل
- [ ] يُقفل الحساب فقط
```

```quiz
لمستخدم الـ UID 33 والـ shell `/usr/sbin/nologin`. ما الذي يُرجَّح أن يكون؟
- [ ] root
- [ ] مستخدم عادي – شخص
- [x] مستخدم نظام تعمل خدمة باسمه
- [ ] مستخدم محذوف
---
أرقام UID من 1 إلى 999 لمستخدمي النظام، و`nologin` يعني أن لا أحد يستطيع تسجيل
الدخول بها.
```

```try
getent group sudo
---
يبحث `getent` عن المجموعة بالطريقة نفسها التي يبحث بها النظام.
```
