# ملخّص: الشبكات

في هذا الجزء تعرّفت من الطرفية على شبكة منزلية صغيرة: عنوانك أنت، والطريق إلى
الإنترنت، والأسماء وDNS، والمنافذ، والويب، والحواسيب الأخرى عبر SSH.

## الشبكات

لكل حاسوب على الشبكة **عنوان IP**، والعناوين التي تبدأ بـ `192.168.` أو `10.` أو
`172.16.`–`172.31.` عناوين **خاصة**. يعرض `ip a` واجهات الحاسوب وعناوينه – `lo`
هي بطاقة الحلقة الراجعة (loopback)، و`127.0.0.1` (**localhost**) يعني دائمًا
الحاسوب نفسه. يحدد **قناع الشبكة** (`/24`) العناوين الموجودة على الشبكة المحلية،
وكل ما عداها يمر عبر المسار الافتراضي إلى **البوابة** (gateway)، التي يعرضها
`ip route`. ويختبر `ping` ما إذا كان يمكن الوصول إلى حاسوب ما.

يترجم **DNS** الأسماء إلى عناوين. قبل أن يسأل الحاسوبُ DNS ينظر في `/etc/hosts`،
ويعرض `getent hosts` ما يحلّه النظام، أما `dig` فيسأل DNS مباشرةً. على Ubuntu يشير
`/etc/resolv.conf` إلى `127.0.0.53`، أي systemd-resolved، وتأتي `dig` و`host`
و`nslookup` في الحزمة `dnsutils`.

يدل **المنفذ** (port) على برنامج بعينه على حاسوب، ويعرض `ss -tulpn` المنافذ التي
تستمع. يجلب `curl` عنوان URL ويطبعه، وينزّل `wget` إلى ملف – على Ubuntu يكون
`wget` مثبّتًا مسبقًا ويُثبَّت `curl` باستخدام apt. ومع **SSH** تشغّل أوامر على حاسوب
آخر بشكل مشفّر؛ وفي المرة الأولى تؤكّد مفتاح المضيف الخاص بالخادم، ومع زوج مفاتيح
لا تعود بحاجة إلى كلمة مرور.

في `~/.ssh/config` تعطي الخوادم أسماء قصيرة باستخدام `Host` و`HostName` و`User`.
ينسخ `scp` مثل `cp`، لكن أحد الطرفين يُكتب على الشكل `HOST:PATH`، نسبةً إلى مجلد
المنزل هناك. لا ينسخ `rsync -av` إلا ما تغيّر؛ والشرطة المائلة في نهاية المصدر
تعني "ما بداخل المجلد"، ويجعل `--delete` الهدف نسخة مطابقة تمامًا – جرّبه
باستخدام `-n` أولًا.

عندما «لا يعمل الإنترنت»، انطلق من الداخل إلى الخارج: العنوان، ثم المسار، ثم
الموجّه (router)، ثم عنوان على الإنترنت، وأخيرًا اسم. إذا عملت العناوين ولم تعمل
الأسماء، فالمشكلة في DNS.

## الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `ip a`، `ip -br a`، `hostname -I` | عرض عناوين IP |
| `ip route` | عرض جدول التوجيه والبوابة |
| `ping -c 3 HOST` | اختبار ما إذا كان يمكن الوصول إلى حاسوب |
| `sudo ip link set CARD down` / `up` | إيقاف / تشغيل بطاقة شبكة |
| `cat /etc/resolv.conf` | أيّ خادم DNS يُسأل |
| `dig +short NAME`، `dig @SERVER NAME` | البحث عن اسم في DNS |
| `host NAME`، `nslookup NAME` | البحث عن اسم (ومن العنوان إلى الاسم أيضًا مع `host`) |
| `getent hosts NAME` | البحث كما يفعل النظام (مع `/etc/hosts`) |
| `sudo tee -a /etc/hosts` | إضافة ما يأتي من أنبوب إلى `/etc/hosts` بصلاحيات root |
| `ss -tulpn` | عرض المنافذ التي تستمع |
| `curl URL` | الجلب والعرض |
| `curl -I URL`، `curl -L URL` | الترويسات فقط، متابعة إعادة التوجيه |
| `curl -o FILE URL`، `wget URL`، `wget -O FILE URL` | التنزيل إلى ملف |
| `ssh USER@HOST COMMAND` | تشغيل أمر على حاسوب آخر |
| `ssh-keygen`، `ssh-copy-id USER@HOST` | إنشاء زوج مفاتيح ووضع المفتاح العام على الخادم |
| `ssh srv` مع `Host srv` في `~/.ssh/config` | تسجيل الدخول باسم قصير |
| `scp FILE HOST:` · `scp HOST:FILE .` · `scp -r` | النسخ إلى · من حاسوب آخر · مجلدات كاملة |
| `rsync -av SOURCE/ TARGET` | نسخ ما تغيّر فقط |
| `rsync -avn --delete SOURCE/ TARGET` | تجربة مرآة من دون فعل أي شيء |
