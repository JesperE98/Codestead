# ملخّص: الأساسيات

لقد تعلّمت الأوامر التي ستستخدمها كل يوم، على كل توزيعة.
إليك مراجعة سريعة قبل الاختبار.

## التنقل في نظام الملفات

كل شيء موجود في شجرة واحدة تبدأ من الجذر، `/`. الإعدادات في `/etc`، والبرامج في
`/usr/bin`، والسجلات في `/var/log`، وملفاتك أنت في مجلد المنزل، `~`. يعرض `pwd`
مكانك، ويسرد `ls` ما يوجد فيه، وينقلك `cd`. يبدأ المسار **المطلق** بـ `/`، أما
المسار **النسبي** فيبدأ من المجلد الذي أنت فيه. `..` هو المجلد الأعلى، و`cd` دون
وسائط يعيدك إلى المنزل.

## الملفات والمجلدات

ينشئ `mkdir` المجلدات (و`-p` ينشئ عدة مستويات دفعة واحدة)، وينشئ `touch` ملفات
فارغة. ينسخ `cp` (و`-r` للمجلدات كاملة)، وينقل `mv` ويعيد التسمية أيضًا، ويحذف
`rm` – نهائيًا، فلا توجد سلة مهملات. لا يحذف `rmdir` إلا المجلدات الفارغة، أما
`rm -r` فيحذف المجلد وكل ما فيه. يوسّع الـ shell أحرف البدل مثل `*` و`?` و`[abc]`
قبل تشغيل الأمر، والأسماء التي تحتوي على مسافات تحتاج إلى علامات اقتباس.

## قراءة النصوص والبحث فيها

يطبع `cat` الملف، ويتيح لك `less` التمرير فيه. يعرض `head` و`tail` البداية والنهاية
(يحدد `-n` عدد الأسطر، ويتابع `tail -f` الملف). يعدّ `wc` الأسطر والكلمات والبايتات.
يعرض `grep` الأسطر المطابقة لنمط، ويرتّب `sort` الأسطر، ويزيل `uniq` الأسطر المكررة
المتجاورة. ويعرض `man` دليل الأمر. ويقتطع `cut` حقلًا (يحدد `-d` الفاصل، و`-f` الحقل).

## إعادة التوجيه والأنابيب

لكل برنامج ثلاثة تدفقات: stdin وstdout وstderr. يرسل `>` المخرجات stdout إلى ملف
(ويستبدل محتواه)، ويضيف `>>` إلى نهايته، ويقرأ `<` الإدخال stdin من ملف، ويعيد
`2>` توجيه رسائل الخطأ – إلى `/dev/null` مثلًا. يرسل الأنبوب `|` مخرجات أمر إلى
الأمر التالي، ويحفظ `tee` نسخة في الطريق. ويحوّل `xargs` الكلمات الموجودة في مدخلاته
إلى وسائط لأمر ما. وتشغّل `;` و`&&` و`||` عدة أوامر في سطر واحد. يستبدل `tr` محارف مفردة أو يحذفها (`-d`) أو يضغط تكرارها (`-s`)، ولا يقرأ إلا من stdin.

## الأوامر والخيارات

| الأمر | ماذا يفعل | الخيارات والصيغ من هذا الجزء |
|---|---|---|
| `pwd` | يعرض المجلد الذي أنت فيه | |
| `ls` | يسرد محتويات مجلد | `-l` الصيغة الطويلة، `-a` الملفات المخفية أيضًا |
| `cd` | يغيّر المجلد | `..` إلى الأعلى، `~` المنزل، `-` المجلد السابق، دون وسيط = المنزل |
| `mkdir` | ينشئ مجلدًا | `-p` عدة مستويات دفعة واحدة |
| `touch` | ينشئ ملفًا فارغًا | |
| `cp` | ينسخ | `-r` المجلدات كاملة |
| `mv` | ينقل أو يعيد التسمية | |
| `rm` | يحذف | `-r` المجلدات ومحتوياتها، `-f` دون أسئلة |
| `rmdir` | يحذف مجلدًا فارغًا | |
| `cat` | يطبع ملفًا | |
| `less` | يعرض ملفًا صفحة صفحة | `/word` يبحث، `q` يخرج |
| `head` / `tail` | الأسطر الأولى / الأخيرة | `-n N` عدد الأسطر، `tail -f` يتابع |
| `wc` | يعدّ الأسطر والكلمات والبايتات | `-l` الأسطر فقط |
| `grep` | يعرض الأسطر المطابقة | `-i`، `-n`، `-v`، `-c`، `-r`، `-E` |
| `sort` | يرتّب الأسطر | `-n` أرقام، `-r` ترتيب عكسي |
| `uniq` | يزيل الأسطر المكررة المتجاورة | `-c` يعدّها |
| `man` | يعرض صفحة الدليل | |
| `tee` | يمرّر الإدخال ويحفظ نسخة | |
| `xargs` | يحوّل مدخلاته إلى وسائط لأمر | `-n 1` واحدًا تلو الآخر، `-I {}` سطرًا سطرًا |
| `tr` | يترجم المحارف | `-d` حذف، `-s` ضغط |
| `cut` | يقتطع الحقول | `-d` الفاصل، `-f` الحقل |

| الصيغة | معناها |
|---|---|
| `>` / `>>` | stdout إلى ملف (استبدال / إضافة) |
| `<` | stdin من ملف |
| `2>` | stderr إلى ملف، مثل `2> /dev/null` |
| `2>&1` | stderr إلى حيث يذهب stdout |
| `\|` | أنبوب: stdout لأمر إلى stdin للأمر التالي |
| `a ; b` | شغّل a، ثم b |
| `a && b` | شغّل b فقط إذا نجح a |
| `a \|\| b` | شغّل b فقط إذا فشل a |
| `*`، `?`، `[abc]` | أحرف البدل لأسماء الملفات |
