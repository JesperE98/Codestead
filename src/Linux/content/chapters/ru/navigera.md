# Навигация по файловой системе

В Linux нет букв дисков вроде `C:`. Всё – жёсткие диски, флешки, даже
устройства – находится в **одном общем дереве** каталогов, которое
начинается с **корня**, обозначаемого `/`.

## Самые важные каталоги

| Каталог | Содержимое |
|---|---|
| `/` | Корень – вершина дерева |
| `/home` | Домашние каталоги пользователей, например `/home/{{user}}` |
| `/root` | Домашний каталог администратора root |
| `/etc` | Системные настройки (конфигурационные файлы) |
| `/usr/bin` | Программы (команды), например `ls` и `cat` |
| `/var/log` | Файлы журналов (логи) |
| `/tmp` | Временные файлы, куда может писать кто угодно |
| `/dev` | Устройства, например диски |
| `/proc` | Информация о процессах и ядре |
| `/boot` | Файлы, нужные для загрузки компьютера |

Такая структура называется *Filesystem Hierarchy Standard* (стандарт иерархии
файловой системы), и она почти одинакова во всех дистрибутивах.

```quiz
Программа пишет файл журнала. В каком каталоге вы ожидаете его найти?
- [ ] `/etc`
- [ ] `/usr/bin`
- [x] `/var/log`
- [ ] `/home`
---
Файлы журналов лежат в `/var/log`. Настройки – в `/etc`, программы – в `/usr/bin`.
```

## Где я? – `pwd`

`pwd` (*print working directory*) показывает каталог, в котором вы сейчас
находитесь:

```sh
pwd
```

## Что здесь есть? – `ls`

`ls` выводит содержимое каталога. Без аргументов он показывает текущий
каталог, но можно указать и другой:

```sh
ls /etc
```

Опция `-l` даёт длинный формат с дополнительной информацией:

```sh
ls -l
```

Файлы, имена которых начинаются с точки, **скрыты** и по умолчанию не
показываются. Часто это файлы настроек, например `.bashrc`. Опция `-a`
(*all*) показывает их:

```sh
ls -a
```

Опции можно объединять: `ls -la` – то же самое, что `ls -l -a`.

```quiz
Почему простой `ls` в домашнем каталоге не показывает файл `.bashrc`?
- [ ] Это системный файл, который видит только root
- [x] Его имя начинается с точки, поэтому он скрыт
- [ ] `ls` показывает только каталоги
---
Файлы, имена которых начинаются с точки, скрыты. `ls -a` показывает и их.
```

Попробуйте длинный формат вместе со скрытыми файлами:

```try
ls -la
```

## Смена каталога – `cd`

`cd` (*change directory*) переводит вас в другой каталог:

```sh
cd /var/log
```

Пути бывают двух видов:

- **Абсолютный** путь начинается с `/` и отсчитывается от корня, например
  `/var/log`. Он работает, где бы вы ни находились.
- **Относительный** путь отсчитывается от текущего каталога. Если вы в `/`,
  то попасть в `/var/log` можно просто командой `cd var/log`.

```quiz
Вы находитесь в `/home`. Какие команды переведут вас в `/home/{{user}}/{{documents}}`? (Выберите все подходящие.)
- [x] `cd {{user}}/{{documents}}`
- [x] `cd /home/{{user}}/{{documents}}`
- [ ] `cd /{{user}}/{{documents}}`
- [ ] `cd {{documents}}`
---
`{{user}}/{{documents}}` отсчитывается от `/home`, а `/home/{{user}}/{{documents}}` – абсолютный
путь, поэтому он работает откуда угодно. `/{{user}}/{{documents}}` начинается от корня,
где никакого `{{user}}` нет.
```

Полезно знать несколько специальных имён:

| Имя | Означает |
|---|---|
| `.` | Текущий каталог |
| `..` | Каталог уровнем выше (родительский) |
| `~` | Ваш домашний каталог |
| `-` | (только с `cd`) каталог, в котором вы были перед этим |

`cd` без аргументов всегда возвращает вас домой.

```sh
cd ..
```

```predict
$ cd /usr/bin
$ cd ..
$ pwd
/usr
---
`..` – каталог уровнем выше, поэтому из `/usr/bin` вы попадаете в `/usr`.
```

## Дополнение по Tab

Полные имена набирать почти никогда не нужно. Введите начало, например
`cd /va`, и нажмите **Tab** – shell допишет остальное. Если вариантов
несколько, они будут показаны при нажатии Tab. Опытные пользователи Linux
жмут Tab постоянно!
