# Итоги: Администрирование системы

В этой части вы заботились о компьютере как администратор: о службах,
работающих в фоне, о дисках, на которые попадают файлы, и о пользователях,
которые делят компьютер. Почти всё, что здесь что-то **меняет**, требует прав
root – поэтому `sudo` встречался часто.

## Службы и журналы с systemd

**systemd** – это процесс номер 1, который запускает всё остальное. Всё, за
чем он следит, – это **юниты**, описанные юнит-файлами: поставляемые с
пакетами лежат в `/usr/lib/systemd/system`, ваши собственные – в
`/etc/systemd/system`, и они имеют приоритет. `systemctl` управляет службами,
и **`start` (сейчас) и `enable` (при загрузке) – две разные вещи**. Всё, что
выводят службы, попадает в **journal**, который вы читаете и фильтруете с
помощью `journalctl`. Если служба не запускается: `systemctl --failed`,
`systemctl status`, затем `journalctl -xeu` – и читайте журнал слово за
словом. В Ubuntu служба SSH называется `ssh`; в других семействах службы
иногда называются иначе.

## Диски и файловые системы

**Диск** разбивается на **разделы**, и каждому разделу нужна **файловая
система**, прежде чем на нём можно будет хранить файлы. Диски – это файлы в
`/dev` (`/dev/sda`, `/dev/sda1`, …). В Linux нет букв дисков: каждая
файловая система **монтируется** куда-то в единое дерево каталогов, которое
начинается с `/`. `lsblk` показывает диски, `df` – насколько заполнены
файловые системы, а `du` – сколько занимают файлы. Всегда **размонтируйте**
флешку, прежде чем выдернуть её, потому что изменения могут ещё ждать в RAM.
Что монтируется при загрузке, указано в `/etc/fstab`, лучше всего по
**UUID**, который никогда не меняется. `fdisk` и `mkfs` – одни из самых
опасных команд вообще: проверяйте дважды.

## Пользователи и группы

У каждого пользователя есть **UID** – у root это 0, системные пользователи
получают маленькие номера, а люди начинаются с 1000. Пользователи
перечислены в `/etc/passwd`, группы – в `/etc/group`, а хеши паролей – в
`/etc/shadow`, который может читать только root. У каждого пользователя одна
**основная группа** и любое количество **дополнительных групп**.
`useradd -m -s /bin/bash` создаёт пользователя, `passwd` задаёт пароль, а
`usermod -aG` добавляет в группу – **не забывайте `-a`**. В Ubuntu права
sudo даёт группа `sudo` (в других семействах – `wheel`). `su -` переключает
пользователя по паролю этого пользователя, а `sudo -u` выполняет одну команду
от имени другого по вашему собственному паролю.

## Команды

| Команда | Что делает |
|---|---|
| `systemctl status NAME` | Как дела у службы? |
| `sudo systemctl start` / `stop` / `restart` / `reload NAME` | Запустить, остановить, перезапустить, перечитать конфигурацию |
| `sudo systemctl enable --now NAME` | Запускать при загрузке – и сейчас |
| `systemctl is-active` / `is-enabled NAME` | Одно слово, код возврата 0 для «да» |
| `systemctl --failed` | Службы, которые завершились сбоем |
| `systemctl cat NAME` | Показать юнит-файл |
| `sudo systemctl daemon-reload` | Заново загрузить изменённые юнит-файлы |
| `journalctl -u NAME` | Журнал одной службы |
| `journalctl -p err -b` | Ошибки и всё серьёзнее с момента этой загрузки |
| `journalctl -n 20`, `-f`, `--since today` | Последние строки, следить, с полуночи |
| `lsblk -f` | Диски, разделы и файловые системы |
| `blkid`, `findmnt -n -o UUID /` | Тип, метка и UUID |
| `df -h`, `du -sh DIR` | Насколько заполнен диск, сколько занимают файлы |
| `sudo mount /dev/sdb1 /mnt/usb` | Смонтировать файловую систему |
| `sudo umount /mnt/usb` | Размонтировать |
| `cat /etc/fstab`, `sudo mount -a` | Что монтируется при загрузке – и проверка изменений |
| `swapon --show`, `free -h` | Swap и память |
| `id`, `groups` | UID, GID и группы |
| `sudo useradd -m -s /bin/bash NAME` | Создать пользователя |
| `sudo passwd NAME` | Задать пароль |
| `sudo groupadd GROUP` | Создать группу |
| `sudo usermod -aG GROUP NAME` | Добавить в группу |
| `sudo usermod -L` / `-U NAME` | Заблокировать / разблокировать учётную запись |
| `sudo userdel -r NAME` | Удалить пользователя и домашний каталог |
| `su - NAME`, `sudo -u NAME COMMAND` | Сменить пользователя, выполнить от имени другого пользователя |
