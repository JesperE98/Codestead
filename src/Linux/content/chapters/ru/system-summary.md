# Итоги: Система

В этой части вы посмотрели, что происходит вокруг ваших команд: память
shell, кому что разрешено, какие программы работают и как файлы упаковываются
вместе.

## Переменные, PATH и псевдонимы

Переменная читается как `$ИМЯ`, а создаётся так: `ИМЯ=значение` – без
пробелов вокруг `=`. `export` превращает её в переменную окружения, которую
могут читать и запускаемые вами программы. Внутри двойных кавычек переменные
заменяются своими значениями; внутри одинарных всё выводится в точности так,
как написано. Shell ищет команды в каталогах из `PATH`, а `$?` содержит код
возврата последней команды: `0` означает, что всё прошло хорошо. Псевдонимы
и переменные исчезают, когда вы закрываете терминал, если не записать их в
`~/.bashrc`.

## Пользователи, права доступа и sudo

У каждого файла есть владелец, группа и три набора прав – для владельца,
группы и остальных. `r` = 4, `w` = 2 и `x` = 1, поэтому `755` – это
`rwxr-xr-x`, а `600` – `rw-------`. Скрипту нужно право `x`, а запускают его
через `./`, потому что текущий каталог не входит в `PATH`. `sudo` выполняет
одну команду от имени root и спрашивает ваш собственный пароль. В Ubuntu им
могут пользоваться члены группы `sudo`.

## Ссылки и информация о файлах

Содержимое и права файла хранятся в **inode**, а имена в каталоге указывают
на inode. `ln -s` создаёт **символическую ссылку** – маленький файл с путём,
который становится битым, если цель исчезает; относительный путь в нём
отсчитывается от каталога самой ссылки. `ln` без `-s` создаёт **жёсткую
ссылку** – ещё одно имя для того же inode. `stat` показывает всё о файле,
`file` говорит, что в нём находится, независимо от имени, а **umask**
определяет права новых файлов: при `022` они получают `644`, при `077` –
только `600`.

## Процессы и задания

Каждая запущенная программа – это процесс с PID и родителем (PPID). `ps aux`
показывает их все, а `top` – в реальном времени, отсортированными по нагрузке
на процессор. `kill` отправляет сигнал: по умолчанию `SIGTERM` (15), а
`SIGKILL` (9) – как крайнюю меру. С `&` команда работает в фоне, а `jobs`,
`fg` и `bg` позволяют управлять заданиями в вашем терминале. `nohup`
оставляет команду работать после выхода из системы, а `watch` выполняет
команду снова и снова.

## Архивы и сжатие

`tar` собирает файлы в один архив, а `gzip` уменьшает один файл – вместе они
дают `.tar.gz`. Ровно одна из опций `c`, `x` и `t` говорит tar, что делать, а
после `f` идёт имя архива. `zcat` читает файл `.gz` без распаковки, а
`zip -r` / `unzip` работают с zip-файлами, которыми удобно обмениваться с
Windows и macOS.

## Команды и опции

| Команда | Что делает |
|---|---|
| `echo $NAME` | Показать значение переменной |
| `export NAME=value` | Создать переменную окружения |
| `env` | Вывести все переменные окружения |
| `which ls` · `type cd` | Показать, где находится программа · что представляет собой имя |
| `echo $?` | Показать код возврата предыдущей команды |
| `alias ll='ls -la'` · `unalias ll` | Создать · удалить псевдоним |
| `source ~/.bashrc` | Сразу загрузить `~/.bashrc` |
| `id` · `groups` | Показать вашего пользователя и группы |
| `ls -l` | Показать права, владельца и группу |
| `chmod 644 file` · `chmod u+x file` | Изменить права числами · символами |
| `sudo command` · `sudo -i` | Выполнить команду от имени root · запустить root-shell |
| `sudo tee -a file` | В конце конвейера: дописать текст в файл, который может менять только root |
| `ln -s target name` · `ln file name` | Создать символическую · жёсткую ссылку |
| `readlink link` · `realpath path` | Куда указывает ссылка · полный путь без ссылок |
| `ls -li` | Показать номера inode и счётчики ссылок |
| `stat file` · `stat -c '%a %U' file` | Всё о файле · только то, что вы запросили |
| `file file` | Что содержится в файле |
| `umask` · `umask 077` | Показать · задать права, которые теряют новые файлы |
| `ps` · `ps aux` · `ps -ef` | Ваши процессы · все процессы · с PID родителя |
| `ps aux --sort=-%cpu` | Все процессы, самые тяжёлые первыми |
| `pgrep -l name` | Найти PID процесса по имени |
| `top` | Живой обзор процессов |
| `kill PID` · `kill -9 PID` | Попросить процесс завершиться · принудительно |
| `pkill pattern` · `killall name` | Остановить процессы по имени |
| `command &` | Запустить команду в фоне |
| `jobs` · `fg %1` · `bg %1` · `kill %1` | Список · передний план · фон · завершить задание |
| `nohup command &` | Продолжить работу после выхода из системы |
| `watch -n 5 command` | Выполнять команду каждые пять секунд |
| `uptime` · `free -h` | Нагрузка · память |
| `tar -czvf archive.tar.gz dir` | Упаковать и сжать каталог |
| `tar -tzvf archive.tar.gz` | Показать содержимое архива |
| `tar -xzvf archive.tar.gz -C dir` | Распаковать архив в каталог |
| `gzip file` · `gzip -k file` · `gunzip file.gz` | Сжать · сохранить оригинал · распаковать |
| `zcat file.gz` | Прочитать сжатый файл напрямую |
| `zip -r archive.zip dir` · `unzip archive.zip -d dir` | Создать · распаковать zip-файл |
| `du -sh dir` | Показать, сколько места что-то занимает |
