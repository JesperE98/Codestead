# Экзамен: Скрипты и автоматизация

Ответьте на вопросы о скриптах на shell – для сдачи нужно 80 %.

```quiz
Что делает первая строка скрипта `#!/bin/bash`?
- [ ] Это комментарий, который shell пропускает
- [x] Она сообщает системе, какая программа должна выполнять файл
- [ ] Она делает файл исполняемым
---
Эта строка называется *shebang*. Чтобы сделать файл исполняемым, всё равно
нужна `chmod +x`.
```

```quiz
`{{nameVar}} = Kim` выдаёт ошибку `command not found`. Почему?
- [x] Из-за пробелов вокруг `=` shell считает `{{nameVar}}` командой
- [ ] Имена переменных нужно писать заглавными буквами
- [ ] Нужно писать `${{nameVar}} = Kim`
```

```quiz
Что содержит `"$@"` в скрипте?
- [ ] Число аргументов
- [ ] Имя скрипта
- [x] Все аргументы, каждый по отдельности
```

```quiz
Какая проверка истинна, когда число в `n` больше 10?
- [ ] `[ $n > 10 ]`
- [x] `[ $n -gt 10 ]`
- [ ] `[ $n = 10 ]`
---
Числа сравниваются с помощью `-eq`, `-lt`, `-gt` и т. д.; `=` и `<` сравнивают
текст.
```

```predict
$ plus() { echo $(( $1 + $2 )); }
$ plus 4 5
9
```

```predict
$ for i in 1 2 3 4 5; do if [ $i -eq 3 ]; then continue; fi; echo $i; done
1
2
4
5
---
`continue` сразу переходит к следующему проходу, поэтому `3` так и не
выводится.
```

```quiz
Какая строка crontab запускает `~/backup.sh` в 23:45 каждое воскресенье?
- [ ] `23 45 * * 0 ~/backup.sh`
- [x] `45 23 * * 0 ~/backup.sh`
- [ ] `45 23 0 * * ~/backup.sh`
---
Сначала минута, потом час: 45 23. Воскресенье – день недели 0 (или 7), он
указывается в пятом поле.
```
