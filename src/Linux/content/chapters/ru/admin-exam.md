# Экзамен: Администрирование системы

Покажите, что вы узнали о службах, дисках и пользователях. Вопросы охватывают
всю часть, и для сдачи нужно 80 % правильных ответов.

```quiz
`myserver` должен автоматически запускаться при каждой загрузке компьютера,
но прямо сейчас его запускать **нельзя**. Какая команда делает ровно это?
- [ ] `sudo systemctl start myserver`
- [x] `sudo systemctl enable myserver`
- [ ] `sudo systemctl enable --now myserver`
- [ ] `sudo systemctl restart myserver`
---
`enable` действует при загрузке, `start` – сейчас, а `--now` делает и то, и
другое.
```

Служба `reportd` на этом компьютере не смогла запуститься. Что выведет эта
команда?

```predict
$ systemctl is-active reportd
failed
---
`is-active` выводит всего одно слово – здесь то же состояние, которое
показывает `systemctl --failed`. Код возврата равен 0, только если ответ –
`active`.
```

```quiz
Вы хотите следить за журналом `myserver`, пока тестируете его, чтобы новые
строки появлялись по мере поступления. Какую команду использовать?
- [ ] `journalctl -n 20`
- [x] `journalctl -u myserver -f`
- [ ] `journalctl -p err -b`
- [ ] `systemctl status myserver --all`
---
`-u` выбирает один юнит, а `-f` продолжает показывать новые строки, пока вы не
нажмёте Ctrl+C.
```

```try
systemctl cat myserver
---
`ExecStart=` – команда, которая запускает службу, а `WantedBy=` использует
`enable`.
```

```quiz
Вы выполняете `systemctl stop myserver` без `sudo` и получаете

- [ ] myserver не запущен
- [x] Всё, что меняет службу, требует прав root
- [ ] Сначала нужно выполнить `daemon-reload`
- [ ] `stop` работает только для включённых служб
```

```quiz
Почему в `/etc/fstab` обычно пишут `UUID=…`, а не `/dev/sda2`?
- [ ] UUID короче набирать
- [x] Имена устройств могут меняться при добавлении дисков, а UUID не меняется никогда
- [ ] `mount` не понимает имена устройств
- [ ] UUID показывает, насколько заполнена файловая система
---
UUID создаётся вместе с файловой системой. Его можно найти с помощью
`lsblk -f`, `blkid` или `findmnt`.
```

```quiz
`df -h` показывает, что `/` заполнен на 98 %. Какая команда поможет найти,
**какие каталоги** занимают место?
- [ ] `df -hT`
- [ ] `lsblk -f`
- [x] `du -h -d 1`
- [ ] `swapon --show`
---
`df` спрашивает файловую систему, насколько она заполнена; `du` проходит по
файлам и складывает их размеры.
```

На этом компьютере домашний каталог не находится на отдельной файловой
системе. Что выведет эта команда?

```predict
$ df -h ~ | tail -n 1 | tr -s ' ' | cut -d' ' -f6
/
---
Если передать `df` путь, он покажет только ту файловую систему, на которой этот
путь находится. Шестой столбец – `Mounted on`, корневая файловая система.
```

```quiz
Вы добавили строку в `/etc/fstab`. Что нужно сделать **до** перезагрузки?
- [ ] Ничего – файл читается только при загрузке
- [x] Проверить её с помощью `sudo mount -a`
- [ ] Выполнить `sudo systemctl daemon-reload`
- [ ] Отформатировать раздел с помощью `mkfs`
---
Ошибка в `/etc/fstab` может помешать компьютеру нормально загрузиться.
`mount -a` монтирует всё из файла, что ещё не смонтировано, так что ошибки вы
увидите сразу.
```

```quiz
Вы собираетесь отформатировать раздел с помощью `mkfs` на настоящем
компьютере. Что нужно проверить сначала? (Выберите все подходящие варианты.)
- [x] С помощью `lsblk -f` – что размер, столбец `RM` и метка совпадают
- [x] Что раздел не смонтирован
- [x] Что у вас есть резервная копия всего важного
- [ ] Что раздел указан в `/etc/fstab`
```

```quiz
Почему хеши паролей хранятся в `/etc/shadow`, а не в `/etc/passwd`?
- [ ] `/etc/passwd` слишком маленький
- [x] `/etc/passwd` должен быть доступен для чтения всем, а `/etc/shadow` – только root
- [ ] Хеши можно обратить, поэтому их нужно прятать
- [ ] `/etc/passwd` читается только при загрузке
---
Иначе кто угодно мог бы скопировать хеши и спокойно попытаться их взломать.
`/etc/passwd` нужен `ls -l`, чтобы показывать имена владельцев.
```

Поля в `/etc/group` – это имя группы, `x`, GID и участники. Кто состоит в
группе `sudo`?

```predict
$ grep ^sudo /etc/group | cut -d: -f4
{{user}}
```

```quiz
Что происходит при `sudo userdel kim` – без `-r`?
- [x] Пользователь удаляется, но домашний каталог `/home/kim` остаётся
- [ ] Ничего – `userdel` всегда требует `-r`
- [ ] Удаляются пользователь и домашний каталог
- [ ] Учётная запись только блокируется
```

```quiz
У пользователя UID 33 и shell `/usr/sbin/nologin`. Кто это, скорее всего?
- [ ] root
- [ ] Обычный пользователь – человек
- [x] Системный пользователь, от имени которого работает служба
- [ ] Удалённый пользователь
---
UID 1–999 предназначены для системных пользователей, а `nologin` означает, что
войти под ними никто не может.
```

```try
getent group sudo
---
`getent` ищет группу так же, как это делает система.
```
