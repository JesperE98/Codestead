# परीक्षा: सिस्टम

वेरिएबल, अनुमतियों, प्रोसेस और आर्काइव के बारे में प्रश्नों के उत्तर दीजिए – पास होने के लिए आपको 80 % चाहिए।

```predict
$ echo "$HOME" '$USER'
/home/{{user}} $USER
---
दोहरे उद्धरण चिह्न वेरिएबल को उसके मान से बदल देते हैं; एकल उद्धरण चिह्न उसे ठीक
वैसा ही छापते हैं जैसा लिखा है।
```

```quiz
`export` किसी वेरिएबल के साथ क्या करता है?
- [ ] उसे `~/.bashrc` में सहेजता है
- [x] उसे एनवायरनमेंट वेरिएबल बनाता है, जिसे आपके शुरू किए प्रोग्राम भी पढ़ सकते हैं
- [ ] उसे मिटा देता है
```

```predict
$ ls ~ > /dev/null
$ echo $?
0
---
`ls` ठीक चला, इसलिए एग्ज़िट कोड `0` है। आउटपुट ख़ुद `/dev/null` में ग़ायब हो गया।
```

```quiz
कौन-सी संख्या अनुमतियाँ `rwxr-x---` देती है?

- [x] `750`
- [ ] `640`
---
मालिक: 4 + 2 + 1 = 7। समूह: 4 + 1 = 5। बाक़ी: 0।
```

```quiz
`sudo -i` क्या करता है?
- [ ] sudo के बारे में जानकारी दिखाता है
- [x] एक root शेल शुरू करता है, जिसमें प्रॉम्प्ट `#` में बदल जाता है, जब तक आप `exit` टाइप न करें
- [ ] पिछले कमांड को फिर से root के रूप में चलाता है
```

```quiz

- [ ] वह सो रहा है
- [ ] वह root का है
```


```quiz
आप root के किसी प्रोसेस पर `kill 812` आज़माते हैं और `Operation not permitted`
मिलता है। आप क्या करते हैं?
- [ ] इसके बजाय `kill -9 812` इस्तेमाल करते हैं
- [x] इसे `sudo` के साथ चलाते हैं: `sudo kill 812`
- [ ] कुछ नहीं – root के प्रोसेस कभी रोके नहीं जा सकते
```

```quiz
`pkill` और `killall` में क्या फ़र्क़ है?
- [x] `pkill` किसी पैटर्न से मेल करता है, `killall` को ठीक-ठीक नाम चाहिए
- [ ] `pkill` `SIGKILL` भेजता है, `killall` `SIGTERM` भेजता है
- [ ] कोई फ़र्क़ नहीं – दोनों एक ही प्रोग्राम हैं
```

```quiz
`tar -cvf {{documents}} {{documents}}.tar` में क्या ग़लत है?
- [ ] `-v` को `-c` के साथ नहीं मिलाया जा सकता
- [x] क्रम: आर्काइव का नाम `f` के ठीक बाद, फ़ाइलों से पहले आना चाहिए
- [ ] tar आर्काइव का नाम `.tgz` पर ख़त्म होना ज़रूरी है
```

```quiz
`zcat server.log.gz` क्या करता है?
- [x] बिना कंप्रेशन वाली सामग्री छापता है, और `server.log.gz` जैसी है वैसी रहती है
- [ ] फ़ाइल को `server.log` में खोल देता है
- [ ] फ़ाइल को एक बार और कंप्रेस करता है
---
`zcat` वही है जो `gzip -dc`: स्टैंडर्ड आउटपुट पर डीकंप्रेस करना।
```
