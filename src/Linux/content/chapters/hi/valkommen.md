# Linux shell में आपका स्वागत है

यह गाइड आपको कमांड लाइन से Linux इस्तेमाल करना सिखाती है – आपके सबसे पहले
कमांड से लेकर अलग-अलग डिस्ट्रीब्यूशन पर पैकेज प्रबंधन तक। हर अध्याय एक विषय
समझाता है। बीच-बीच में पाठ में छोटे-छोटे **प्रश्न** आते हैं; उनके उत्तर दीजिए, तो
दाईं ओर वाला टर्मिनल और अध्याय के **कार्य** खुल जाते हैं। जैसे ही आप कोई कार्य
सही कर लेते हैं, उस पर अपने-आप टिक लग जाता है। सीखने का सबसे अच्छा तरीक़ा है
*करके देखना*: पढ़िए, आज़माइए, ग़लतियाँ कीजिए, और फिर से कोशिश कीजिए।

## Linux क्या है?

सख़्ती से कहें तो **Linux** सिर्फ़ *kernel* है: वह program जो hardware से बात
करता है और बाक़ी programs को processor, memory और disks आपस में बाँटने देता है।
Kernel को Linus Torvalds ने 1991 में बनाया था और यह free software है।

एक इस्तेमाल लायक़ system के लिए इससे कहीं ज़्यादा चाहिए: एक shell, files
संभालने के tools, एक package manager, शायद एक desktop भी। एक **distribution**
(*distro*) यह सब मिलाकर एक तैयार पैकेज बना देता है। Debian, Ubuntu, Arch Linux
और Fedora इसके कुछ जाने-माने उदाहरण हैं।

इस गाइड में आप जो कुछ सीखेंगे, उसमें से ज़्यादातर हर डिस्ट्रीब्यूशन पर एक जैसा
काम करता है, इसलिए कोर्स वहीं से शुरू होता है। यहाँ का टर्मिनल **Ubuntu 24.04
LTS** चलाता है। डिस्ट्रीब्यूशन मुख्य रूप से इस बात में अलग होते हैं कि सॉफ़्टवेयर
कैसे इंस्टॉल किया जाता है – यह डिस्ट्रीब्यूशन वाले अध्याय में आएगा।

## Shell क्या है?

**Shell** वह program है जो आपके टाइप किए गए commands पढ़ता है और उन्हें चलाता
है। सबसे आम shell **bash** है, जो लगभग हर distribution पर default है। दूसरे
लोकप्रिय shells हैं **zsh** (macOS पर default) और **fish**। बुनियादी बातें
सभी में एक जैसी हैं।

*Terminal* और *shell* का फ़र्क़ ध्यान में रखिए: terminal वह window है जो text
दिखाती है, और shell वह program है जो उसके अंदर चलता है।

```quiz
आप `ls` टाइप करके Enter दबाते हैं। कौन-सा प्रोग्राम कमांड पढ़ता है और उसे चलाता है?
- [ ] टर्मिनल
- [x] शेल
- [ ] कर्नेल
---
टर्मिनल सिर्फ़ टेक्स्ट दिखाता है। शेल (यहाँ bash) पढ़ता है कि आप क्या टाइप करते
हैं और उसे चलाता है।
```

## Prompt

जब शेल किसी कमांड का इंतज़ार कर रहा होता है, तो वह एक **prompt** दिखाता है।
यहाँ के टर्मिनल में यह ऐसा दिखता है:

```text
{{user}}@ubuntu:~$
```

यह बताता है कि आप कौन हैं (`{{user}}`), किस कंप्यूटर पर हैं (`ubuntu`) और
file system में कहाँ हैं (`~` का मतलब है आपकी home directory)। `$` का निशान
बताता है कि आप एक सामान्य user हैं। अगर आप administrator (*root*) हैं, तो
इसकी जगह `#` दिखेगा।

```quiz
प्रॉम्प्ट `$` की जगह `#` पर ख़त्म होता है। इससे आपको क्या पता चलता है?
- [ ] आप अपनी होम डायरेक्टरी में हैं
- [ ] पिछला कमांड विफल रहा
- [x] आप प्रशासक (administrator), यानी root, हैं
```

## आपका पहला command

Terminal में click कीजिए, नीचे दिया command टाइप कीजिए और **Enter** दबाइए:

```sh
echo {{helloWorld}}
```

`echo` बस वही print कर देता है जो आप उसे देते हैं – यहाँ *{{helloWorld}}*।
ज़्यादातर commands इसी pattern पर चलते हैं:

```text
command  -options  arguments
ls       -l        /etc
```

*Command* वह program है जिसे चलाना है, *options* (या *flags*) उसके बर्ताव को
बदलते हैं, और *arguments* वह चीज़ें हैं जिन पर command को काम करना है।

```quiz
कमांड `ls -l /etc` में कौन-सा हिस्सा **ऑप्शन** है?
- [ ] `ls`
- [x] `-l`
- [ ] `/etc`
---
`ls` कमांड है, `-l` उसके बर्ताव को बदलता है, और `/etc` आर्ग्युमेंट है – वह चीज़
जिस पर `ls` को काम करना है।
```

`echo` को अपने ख़ुद के टेक्स्ट के साथ आज़माइए:

```try
echo Linux मज़ेदार है
---
`echo` ने ठीक वही शब्द छाप दिए जो आपने उसे दिए।
```

## मैं कौन हूँ और कहाँ हूँ?

दो छोटे कमांड आपको उस सिस्टम के बारे में बताते हैं जिस पर आप हैं। `whoami` उस
यूज़र का नाम छापता है जिसके रूप में आप लॉग इन हैं। फ़ाइल `/etc/os-release`
डिस्ट्रीब्यूशन का विवरण देती है, और `cat` किसी फ़ाइल को छापता है (`cat` के बारे में
आगे के एक अध्याय में और):

```sh
whoami
cat /etc/os-release
```

## Simulator कैसे काम करता है

यहाँ का टर्मिनल एक **simulator** है जो पूरी तरह इसी ऐप के अंदर चलता है। यह
एक असली Linux computer की तरह बर्ताव करता है, लेकिन आप जो भी करें उससे आपकी
अपनी machine को कोई नुक़सान नहीं हो सकता – और अगर कुछ गड़बड़ हो जाए, तो आप
सेटिंग्स में *टर्मिनल रीसेट करें* से हमेशा फिर से शुरू कर सकते हैं।

- **किसी code example पर click कीजिए** ताकि command terminal में आ जाए।
- **Tab** commands और file names को पूरा कर देता है।
- **ऊपर/नीचे arrow keys** से पिछले commands पर जा सकते हैं।
- **Ctrl+L** screen साफ़ करता है और **Ctrl+C** टाइप की जा रही line रद्द कर देता है।
- `help` सारे commands की list दिखाता है, और `man command` एक manual page दिखाता है।

```quiz
आपने `ech` टाइप किया है और **Tab** दबाते हैं। क्या होता है?
- [ ] पंक्ति रद्द हो जाती है
- [x] शेल नाम का बाक़ी हिस्सा भरने की कोशिश करता है
- [ ] स्क्रीन साफ़ हो जाती है
---
Tab कमांड और फ़ाइल नाम पूरे करता है। **Ctrl+C** पंक्ति रद्द करता है और
**Ctrl+L** स्क्रीन साफ़ करता है।
```
