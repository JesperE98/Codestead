# सारांश: मूल बातें

आपने वे कमांड सीख लिए हैं जिन्हें आप रोज़, हर डिस्ट्रीब्यूशन पर इस्तेमाल करेंगे।
परीक्षा से पहले यहाँ एक छोटा-सा दोहराव है।

## फ़ाइल सिस्टम में घूमना

सब कुछ एक ही पेड़ (tree) में रहता है जो रूट, `/`, से शुरू होता है। सेटिंग्स
`/etc` में हैं, प्रोग्राम `/usr/bin` में, लॉग `/var/log` में और आपकी अपनी फ़ाइलें
आपकी होम डायरेक्टरी, `~`, में। `pwd` बताता है कि आप कहाँ हैं, `ls` वहाँ की चीज़ों की
सूची देता है और `cd` आपको दूसरी जगह ले जाता है। **निरपेक्ष** (absolute) पाथ `/` से
शुरू होता है; **सापेक्ष** (relative) पाथ उस डायरेक्टरी से शुरू होता है जिसमें आप
हैं। `..` ऊपर वाली डायरेक्टरी है, और बिना आर्ग्युमेंट के `cd` आपको घर ले जाता है।

## फ़ाइलें और डायरेक्टरी

`mkdir` डायरेक्टरी बनाता है (`-p` एक साथ कई स्तर बनाता है) और `touch` ख़ाली फ़ाइलें
बनाता है। `cp` कॉपी करता है (पूरी डायरेक्टरी के लिए `-r`), `mv` स्थानांतरित भी करता
है और नाम भी बदलता है, और `rm` मिटाता है – हमेशा के लिए, कोई रीसायकल बिन नहीं है।
`rmdir` सिर्फ़ ख़ाली डायरेक्टरी हटाता है; `rm -r` एक डायरेक्टरी और उसके अंदर की हर
चीज़ हटा देता है। `*`, `?` और `[abc]` जैसे वाइल्डकार्ड कमांड चलने से पहले शेल
फैलाता है, और जिन नामों में स्पेस हों उन्हें उद्धरण चिह्न (quotes) चाहिए।

## टेक्स्ट पढ़ना और खोजना

`cat` एक फ़ाइल छापता है और `less` से आप उसमें ऊपर-नीचे जा सकते हैं। `head` और `tail`
शुरुआत और अंत दिखाते हैं (`-n` चुनता है कि कितनी पंक्तियाँ, `tail -f` फ़ाइल का पीछा
करता है)। `wc` पंक्तियाँ, शब्द और बाइट गिनता है। `grep` किसी पैटर्न से मेल खाने वाली
पंक्तियाँ दिखाता है, `sort` पंक्तियाँ क्रम में लगाता है और `uniq` एक-दूसरे के ठीक बाद
आने वाली दोहराई गई पंक्तियाँ हटाता है। `man` किसी कमांड का मैनुअल दिखाता है। `cut` एक फ़ील्ड निकालता है (`-d` विभाजक तय करता है, `-f` फ़ील्ड)।

## रीडायरेक्शन और पाइप

हर प्रोग्राम की तीन धाराएँ (streams) होती हैं: stdin, stdout और stderr। `>` stdout
को एक फ़ाइल में भेजता है (और उसे ओवरराइट करता है), `>>` अंत में जोड़ता है, `<` stdin
को एक फ़ाइल से पढ़ता है और `2>` त्रुटि संदेशों को कहीं और भेजता है – उदाहरण के लिए
`/dev/null` में। पाइप `|` एक कमांड का आउटपुट अगले में भेजता है, और `tee` रास्ते में
एक कॉपी सहेज लेता है। `xargs` अपने इनपुट के शब्दों को किसी कमांड के आर्ग्युमेंट में
बदल देता है। `;`, `&&` और `||` एक पंक्ति पर कई कमांड चलाते हैं। `tr` अकेले अक्षरों को बदलता है, मिटाता है (`-d`) या दबाता है (`-s`) और सिर्फ़ stdin पढ़ता है।

## कमांड और ऑप्शन

| कमांड | क्या करता है | इस भाग के ऑप्शन और सिंटैक्स |
|---|---|---|
| `pwd` | दिखाता है कि आप किस डायरेक्टरी में हैं | |
| `ls` | डायरेक्टरी की सामग्री की सूची देता है | `-l` लंबा फ़ॉर्मैट, `-a` छिपी फ़ाइलें भी |
| `cd` | डायरेक्टरी बदलता है | `..` ऊपर, `~` घर, `-` पिछली डायरेक्टरी, कोई आर्ग्युमेंट नहीं = घर |
| `mkdir` | डायरेक्टरी बनाता है | `-p` एक साथ कई स्तर |
| `touch` | ख़ाली फ़ाइल बनाता है | |
| `cp` | कॉपी करता है | `-r` पूरी डायरेक्टरी |
| `mv` | स्थानांतरित करता है या नाम बदलता है | |
| `rm` | मिटाता है | `-r` डायरेक्टरी और उनकी सामग्री, `-f` बिना सवाल |
| `rmdir` | ख़ाली डायरेक्टरी हटाता है | |
| `cat` | फ़ाइल छापता है | |
| `less` | फ़ाइल पन्ना-दर-पन्ना दिखाता है | `/word` खोजता है, `q` बाहर निकलता है |
| `head` / `tail` | पहली / आख़िरी पंक्तियाँ | `-n N` पंक्तियों की संख्या, `tail -f` पीछा करता है |
| `wc` | पंक्तियाँ, शब्द और बाइट गिनता है | `-l` सिर्फ़ पंक्तियाँ |
| `grep` | मेल खाने वाली पंक्तियाँ दिखाता है | `-i`, `-n`, `-v`, `-c`, `-r`, `-E` |
| `sort` | पंक्तियाँ क्रम में लगाता है | `-n` संख्याएँ, `-r` उल्टा क्रम |
| `uniq` | पास-पास दोहराई पंक्तियाँ हटाता है | `-c` उन्हें गिनता है |
| `man` | मैनुअल पेज दिखाता है | |
| `tee` | इनपुट आगे भेजता है और एक कॉपी सहेजता है | |
| `xargs` | अपने इनपुट को किसी कमांड के आर्ग्युमेंट में बदलता है | `-n 1` एक-एक करके, `-I {}` हर पंक्ति के लिए एक बार |
| `tr` | अक्षर बदलता है | `-d` मिटाना, `-s` दबाना |
| `cut` | फ़ील्ड निकालता है | `-d` विभाजक, `-f` फ़ील्ड |

| सिंटैक्स | मतलब |
|---|---|
| `>` / `>>` | stdout को फ़ाइल में (ओवरराइट / अंत में जोड़ना) |
| `<` | stdin फ़ाइल से |
| `2>` | stderr को फ़ाइल में, जैसे `2> /dev/null` |
| `2>&1` | stderr को वहीं जहाँ stdout जाता है |
| `\|` | पाइप: एक कमांड का stdout अगले के stdin में |
| `a ; b` | a चलाओ, फिर b |
| `a && b` | b तभी चलाओ जब a सफल रहा हो |
| `a \|\| b` | b तभी चलाओ जब a विफल रहा हो |
| `*`, `?`, `[abc]` | फ़ाइल नामों के लिए वाइल्डकार्ड |
