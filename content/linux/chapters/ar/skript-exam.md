# اختبار: البرمجة النصية والأتمتة

أجب عن الأسئلة المتعلقة بسكربتات الـ shell – تحتاج إلى 80 % للنجاح.

```quiz
ماذا يفعل السطر الأول `#!/bin/bash` في السكربت؟
- [ ] إنه تعليق يتخطاه الـ shell
- [x] يخبر النظام بالبرنامج الذي يجب أن يشغّل الملف
- [ ] يجعل الملف قابلًا للتنفيذ
---
يسمى *shebang*. وما زلت تحتاج إلى `chmod +x` لتجعل الملف
قابلًا للتنفيذ.
```

```quiz
يعطي `name = Kim` الخطأ `command not found`. لماذا؟
- [x] المسافات حول `=` تجعل الـ shell يعامل `name` كأمر
- [ ] يجب أن تُكتب أسماء المتغيرات بأحرف كبيرة
- [ ] يجب أن تكتب `$name = Kim`
```

يحتوي `~/{{documents}}` على ملفات التدريب الثلاثة `{{fruits}}` و`{{grades}}`

```quiz
ماذا يحتوي `"$@"` في السكربت؟
- [ ] عدد الوسائط
- [ ] اسم السكربت
- [x] كل الوسائط، كلًّا منها على حدة
```

```quiz
أيّ اختبار يكون صحيحًا عندما يكون العدد في `n` أكبر من 10؟
- [ ] `[ $n > 10 ]`
- [x] `[ $n -gt 10 ]`
- [ ] `[ $n = 10 ]`
---
تُقارن الأعداد باستخدام `-eq` و`-lt` و`-gt` وما إلى ذلك، أما `=` و`<` فيقارنان
النصوص.
```

```predict
$ [ -d ~/{{missing}} ] && echo yes || echo no
no
```

```predict
$ file=report.txt
$ case $file in *.jpg|*.png) echo "An image";; *.txt) echo "A text file";; *) echo "Unknown type";; esac

```

```predict
$ plus() { echo $(( $1 + $2 )); }
$ plus 4 5
9
```

```predict
$ for i in 1 2 3 4 5; do if [ $i -eq 3 ]; then continue; fi; echo $i; done
1
2
4
5
---
يقفز `continue` مباشرةً إلى الدورة التالية، لذا لا يُطبع `3` أبدًا.
```
