# ملخّص: إدارة النظام

في هذا الجزء اعتنيت بالحاسوب بوصفك مديرًا له: الخدمات التي تعمل في الخلفية،
والأقراص التي تنتهي إليها الملفات، والمستخدمون الذين يتشاركون الحاسوب. كل ما
**يغيّر** شيئًا هنا تقريبًا يتطلب صلاحيات root – لذا تكرر ظهور `sudo` كثيرًا.

## الخدمات والسجلات مع systemd

**systemd** هو العملية رقم 1 وهو يبدأ كل شيء آخر. كل ما يتتبّعه هو **وحدة**
(unit) يصفها ملف وحدة – الملفات التي تأتي مع الحزم موجودة في
`/usr/lib/systemd/system`، وملفاتك أنت في `/etc/systemd/system`، ولها الأولوية.
يتحكم `systemctl` في الخدمات، و**`start` (الآن) و`enable` (عند الإقلاع) شيئان
مختلفان**. كل ما تطبعه الخدمات ينتهي في الـ **journal**، الذي تقرؤه وتصفّيه
باستخدام `journalctl`. عندما لا تبدأ خدمة: `systemctl --failed`، ثم
`systemctl status`، ثم `journalctl -xeu` – واقرأ السجل كلمة كلمة. على Ubuntu تُسمّى
خدمة SSH `ssh`، وقد تسمّي العائلات الأخرى الخدمات بأسماء مختلفة أحيانًا.

## الأقراص وأنظمة الملفات

يُقسَّم **القرص** إلى **أقسام** (partitions)، ويحتاج كل قسم إلى **نظام ملفات**
قبل أن يستطيع حمل الملفات. الأقراص ملفات في `/dev` (`/dev/sda` و`/dev/sda1` …).
ليس في لينكس أحرف للأقراص: كل نظام ملفات **يُركَّب** (mount) في مكان ما من شجرة
المجلدات الواحدة التي تبدأ من `/`. يعرض `lsblk` الأقراص، ويعرض `df` مدى امتلاء
أنظمة الملفات، ويعرض `du` المساحة التي تشغلها الملفات. **ألغِ تركيب** ذاكرة USB
دائمًا قبل أن تنزعها، لأن التغييرات قد تكون ما زالت تنتظر في الذاكرة RAM. وما
يُركَّب عند الإقلاع مذكور في `/etc/fstab`، ويُفضَّل أن يكون بالـ **UUID** الذي لا
يتغير أبدًا. و`fdisk` و`mkfs` من أخطر الأوامر الموجودة – فتحقّق مرتين.

## المستخدمون والمجموعات

لكل مستخدم **UID** – لـ root الرقم 0، ويحصل مستخدمو النظام على أرقام صغيرة، ويبدأ
البشر من 1000. المستخدمون مذكورون في `/etc/passwd`، والمجموعات في `/etc/group`،
وتجزئات كلمات المرور في `/etc/shadow` الذي لا يقرؤه إلا root. لكل مستخدم **مجموعة
أساسية** واحدة وأي عدد من **المجموعات الإضافية**. ينشئ `useradd -m -s /bin/bash`
مستخدمًا، ويعيّن `passwd` كلمة المرور، ويضيف `usermod -aG` إلى مجموعة – **لا تنسَ
`-a`**. على Ubuntu تأتي صلاحيات sudo من المجموعة `sudo` (وتستخدم العائلات الأخرى
`wheel`). يبدّل `su -` المستخدم بكلمة مرور ذلك المستخدم، ويشغّل `sudo -u` أمرًا
واحدًا بوصفك شخصًا آخر بكلمة مرورك أنت.

## الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `systemctl status NAME` | كيف حال الخدمة؟ |
| `sudo systemctl start` / `stop` / `restart` / `reload NAME` | البدء، الإيقاف، إعادة التشغيل، إعادة قراءة الإعدادات |
| `sudo systemctl enable --now NAME` | البدء عند الإقلاع – والآن |
| `systemctl is-active` / `is-enabled NAME` | كلمة واحدة، وحالة خروج 0 تعني «نعم» |
| `systemctl --failed` | الخدمات التي فشلت |
| `systemctl cat NAME` | عرض ملف الوحدة |
| `sudo systemctl daemon-reload` | إعادة تحميل ملفات الوحدات المعدّلة |
| `journalctl -u NAME` | سجل خدمة واحدة |
| `journalctl -p err -b` | الأخطاء وما هو أسوأ منذ هذا الإقلاع |
| `journalctl -n 20`، `-f`، `--since today` | أحدث الأسطر، المتابعة، منذ منتصف الليل |
| `lsblk -f` | الأقراص والأقسام وأنظمة الملفات |
| `blkid`، `findmnt -n -o UUID /` | النوع والتسمية والـ UUID |
| `df -h`، `du -sh DIR` | مدى امتلاء القرص، والمساحة التي تشغلها الملفات |
| `sudo mount /dev/sdb1 /mnt/usb` | تركيب نظام ملفات |
| `sudo umount /mnt/usb` | إلغاء التركيب |
| `cat /etc/fstab`، `sudo mount -a` | ما يُركَّب عند الإقلاع – واختبار التغييرات |
| `swapon --show`، `free -h` | الـ swap والذاكرة |
| `id`، `groups` | الـ UID والـ GID والمجموعات |
| `sudo useradd -m -s /bin/bash NAME` | إنشاء مستخدم |
| `sudo passwd NAME` | تعيين كلمة مرور |
| `sudo groupadd GROUP` | إنشاء مجموعة |
| `sudo usermod -aG GROUP NAME` | الإضافة إلى مجموعة |
| `sudo usermod -L` / `-U NAME` | إقفال / فتح حساب |
| `sudo userdel -r NAME` | حذف مستخدم ومجلد منزله |
| `su - NAME`، `sudo -u NAME COMMAND` | تبديل المستخدم، التشغيل بوصفك مستخدمًا آخر |
