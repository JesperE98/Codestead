# اختبار: الشبكات

أظهر ما تعلّمته عن العناوين والأسماء والمنافذ والويب وSSH.
تغطي الأسئلة الجزء كله، وتحتاج إلى 80 % من الإجابات الصحيحة للنجاح.

```quiz
أيّ هذه العناوين **خاصة** – لا تُستخدم إلا داخل الشبكات المحلية؟
(اختر كل ما ينطبق.)
- [x] `10.0.0.5`
- [x] `172.20.1.1`
- [x] `192.168.0.7`
- [ ] `8.8.8.8`
- [ ] `1.1.1.1`
```

```quiz
خادم ويب تطوّره يعمل على حاسوبك أنت. إلى أين تذهب حركة البيانات عندما تختبره على
`http://localhost:8080`؟
- [ ] إلى الموجّه ثم تعود
- [x] إلى لا مكان – فحركة البيانات إلى localhost لا تغادر الحاسوب أبدًا
- [ ] إلى خادم DNS، الذي يعيدها
- [ ] إلى `192.168.1.1`
```

```try
ip route
---
يُظهر السطر `default` البوابة التي يُرسَل إليها كل ما عدا ذلك.
```

السطر الخاص بـ `localhost` في `/etc/hosts` هو ما يجده النظام. ماذا يطبع
هذا؟

```predict
$ getent hosts localhost
127.0.0.1 localhost
```

أيّ خادم DNS يسأله Ubuntu، بحسب `/etc/resolv.conf`؟

```predict
$ grep nameserver /etc/resolv.conf
nameserver 127.0.0.53
---
`127.0.0.53` هو systemd-resolved، وسيط محلي على حاسوبك نفسه يسأل بدوره
الموجّه.
```

```quiz
تشغّل `ping 192.168.1.1` دون أي خيارات. متى يتوقف؟
- [ ] بعد 3 حزم
- [ ] بعد حزمة واحدة
- [x] عندما تضغط Ctrl+C
- [ ] عندما يصل أول رد
---
مع `-c` تختار عدد الحزم التي تُرسَل.
```

الترتيب الذي يبحث به النظام عن الأسماء محدد في
`/etc/nsswitch.conf`. ماذا يطبع هذا؟

```predict
$ grep hosts: /etc/nsswitch.conf
hosts: files dns
---
أولًا الملف (`/etc/hosts`)، ثم DNS.
```

```quiz
أضفت `server.lan` إلى `/etc/hosts`. يعمل `ping server.lan`، لكن
`dig +short server.lan` لا يطبع شيئًا. لماذا؟
- [ ] لأن السطر في `/etc/hosts` خاطئ
- [x] لأن `dig` يسأل DNS مباشرةً ويتجاهل `/etc/hosts`
- [ ] لأن `dig` يحتاج إلى `sudo`
- [ ] لأن `ping` لا يستخدم الأسماء
---
لترى ما يحلّه *النظام*، استخدم `getent hosts server.lan`.
```

```quiz
يستمع `myserver` على المنفذ 8080 ويعمل بوصفه مستخدمًا عاديًا. ما الذي كان
سيختلف لو استمع على المنفذ 80؟
- [ ] لا شيء
- [x] لا يحق إلا لـ root فتح المنافذ التي تقل عن 1024
- [ ] المنفذ 80 مخصص لـ SSH فقط
- [ ] لا يمكن استخدام المنفذ 80 على localhost
```

```quiz
يجيب `curl -I http://linux.org` بـ `301 Moved Permanently`. كيف تحصل على
الصفحة الفعلية؟
- [ ] `curl -s http://linux.org`
- [x] `curl -L http://linux.org` – تابع إعادة التوجيه
- [ ] `curl -o http://linux.org`
- [ ] لا يمكن ذلك – فالرمز 301 يعني أن الصفحة اختفت
```

```quiz
تتصل بـ `server.lan` باستخدام ssh، فيحذّرك ssh بشدة من أن مفتاح المضيف الخاص
بالخادم قد تغيّر. ماذا قد يعني ذلك؟
- [ ] أن كلمة مرورك انتهت صلاحيتها
- [x] أن شخصًا ما قد يتظاهر بأنه الخادم
- [ ] أن على الخادم مستخدمًا جديدًا
- [ ] أن زوج مفاتيحك معطوب
---
حُفظ مفتاح المضيف في `~/.ssh/known_hosts` في أول مرة
اتصلت فيها.
```

```quiz
تريد تسجيل الدخول إلى الخادم بزوج مفاتيح بدلًا من كلمة مرور.
أيّ مفتاح يوضع على الخادم؟
- [x] المفتاح العام، `id_ed25519.pub`
- [ ] المفتاح الخاص، `id_ed25519`
- [ ] كلاهما
- [ ] لا هذا ولا ذاك – فالخادم ينشئ مفتاحه الخاص
---
يضيف `ssh-copy-id` المفتاح العام إلى `~/.ssh/authorized_keys` على
الخادم. لا تُطلع أحدًا على المفتاح الخاص أبدًا!
```
