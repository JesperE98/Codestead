# ملخّص: النظام

في هذا الجزء نظرت إلى ما يجري حول أوامرك: ذاكرة الـ shell، ومن يحق له فعل ماذا،
وأيّ البرامج تعمل، وكيف تُحزم الملفات معًا.

## المتغيرات وPATH والأسماء المستعارة

تقرأ المتغير باستخدام `$NAME` وتنشئه باستخدام `NAME=value` – دون مسافات حول `=`.
يحوّله `export` إلى متغير بيئة تستطيع البرامج التي تشغّلها قراءته أيضًا. داخل
علامات الاقتباس المزدوجة تُستبدل المتغيرات بقيمها، أما داخل علامات الاقتباس
المفردة فيُطبع كل شيء كما كُتب تمامًا. يبحث الـ shell عن الأوامر في المجلدات
الموجودة في `PATH`، ويحمل `$?` رمز خروج آخر أمر: `0` يعني أنه نجح. وتختفي الأسماء
المستعارة والمتغيرات عندما تغلق الطرفية ما لم تضعها في `~/.bashrc`.

## المستخدمون والصلاحيات وsudo

لكل ملف مالك ومجموعة وثلاث مجموعات من الصلاحيات – للمالك وللمجموعة وللآخرين.
`r` = 4 و`w` = 2 و`x` = 1، لذا فإن `755` هي `rwxr-xr-x` و`600` هي `rw-------`.
يحتاج السكربت إلى الصلاحية `x` ويُشغَّل باستخدام `./` لأن المجلد الذي أنت فيه ليس
جزءًا من `PATH`. يشغّل `sudo` أمرًا واحدًا بصلاحيات root ويطلب كلمة مرورك أنت. وعلى
Ubuntu يحق للمستخدمين في المجموعة `sudo` استخدامه.

## الروابط ومعلومات الملفات

يوجد محتوى الملف وصلاحياته في **inode**، والأسماء الموجودة في المجلد تشير إلى
inodes. ينشئ `ln -s` **رابطًا رمزيًا**، وهو ملف صغير فيه مسار، وينكسر إذا اختفى
الهدف؛ والمسار النسبي فيه يُحسب من مجلد الرابط نفسه. وينشئ `ln` من دون `-s`
**رابطًا صلبًا**، أي اسمًا إضافيًا للـ inode نفسه. يعرض `stat` كل شيء عن الملف،
ويخبرك `file` بما يحتويه الملف أيًّا كان اسمه، وتحدّد **umask** صلاحيات الملفات
الجديدة: مع `022` تحصل على `644`، ومع `077` على `600` فقط.

## العمليات والمهام

كل برنامج يعمل هو عملية لها PID وأب (PPID). يعرضها `ps aux` كلها، ويعرضها `top`
مباشرةً مرتّبة حسب استخدام المعالج. يرسل `kill` إشارة: `SIGTERM` (15) افتراضيًا،
و`SIGKILL` (9) كملاذ أخير. ومع `&` يعمل الأمر في الخلفية، وتتيح لك `jobs` و`fg`
و`bg` إدارة المهام في طرفيتك. ويُبقي `nohup` الأمر يعمل بعد أن تسجّل الخروج، ويشغّل
`watch` أمرًا مرة بعد مرة.

## الأرشيفات والضغط

يجمع `tar` الملفات في أرشيف واحد، ويصغّر `gzip` ملفًا واحدًا – ومعًا يعطيانك ملف
`.tar.gz`. يخبر واحد بالضبط من `c` و`x` و`t` الأمرَ tar بما يجب أن يفعله، ويأتي بعد
`f` اسم الأرشيف. يقرأ `zcat` ملف `.gz` دون فك ضغطه، ويتعامل `zip -r` / `unzip` مع
ملفات zip، التي يسهل تبادلها مع Windows وmacOS.

## الأوامر والخيارات

| الأمر | ماذا يفعل |
|---|---|
| `echo $NAME` | يعرض قيمة متغير |
| `export NAME=value` | ينشئ متغير بيئة |
| `env` | يسرد كل متغيرات البيئة |
| `which ls` · `type cd` | يعرض مكان برنامج · ماهية اسم |
| `echo $?` | يعرض رمز خروج الأمر السابق |
| `alias ll='ls -la'` · `unalias ll` | ينشئ · يزيل اسمًا مستعارًا |
| `source ~/.bashrc` | يحمّل `~/.bashrc` فورًا |
| `id` · `groups` | يعرض مستخدمك ومجموعاتك |
| `ls -l` | يعرض الصلاحيات والمالك والمجموعة |
| `chmod 644 file` · `chmod u+x file` | يغيّر الصلاحيات بالأرقام · بالرموز |
| `sudo command` · `sudo -i` | يشغّل أمرًا بصلاحيات root · يبدأ shell بصلاحيات root |
| `sudo tee -a file` | في نهاية أنبوب: يضيف نصًّا إلى ملف لا يحق تغييره إلا لـ root |
| `ln -s target name` · `ln file name` | إنشاء رابط رمزي · رابط صلب |
| `readlink link` · `realpath path` | إلى أين يشير الرابط · المسار الكامل من دون روابط |
| `ls -li` | عرض أرقام الـ inode وأعداد الروابط |
| `stat file` · `stat -c '%a %U' file` | كل شيء عن ملف · ما تطلبه فقط |
| `file file` | ماذا يحتوي الملف |
| `umask` · `umask 077` | عرض · ضبط الصلاحيات التي تفقدها الملفات الجديدة |
| `ps` · `ps aux` · `ps -ef` | عملياتك · كل العمليات · مع PID الأب |
| `ps aux --sort=-%cpu` | كل العمليات، الأثقل أولًا |
| `pgrep -l name` | يجد PID عملية من اسمها |
| `top` | عرض مباشر للعمليات |
| `kill PID` · `kill -9 PID` | يطلب من عملية أن تنتهي · يجبرها على ذلك |
| `pkill pattern` · `killall name` | يوقف العمليات حسب الاسم |
| `command &` | يشغّل أمرًا في الخلفية |
| `jobs` · `fg %1` · `bg %1` · `kill %1` | يسرد · إلى الواجهة · إلى الخلفية · ينهي مهمة |
| `nohup command &` | يستمر في العمل بعد تسجيل الخروج |
| `watch -n 5 command` | تشغيل أمر كل خمس ثوانٍ |
| `uptime` · `free -h` | الحِمل · الذاكرة |
| `tar -czvf archive.tar.gz dir` | يحزم مجلدًا ويضغطه |
| `tar -tzvf archive.tar.gz` | يسرد محتويات أرشيف |
| `tar -xzvf archive.tar.gz -C dir` | يفك أرشيفًا في مجلد |
| `gzip file` · `gzip -k file` · `gunzip file.gz` | يضغط · يُبقي الأصل · يفك الضغط |
| `zcat file.gz` | يقرأ ملفًا مضغوطًا مباشرةً |
| `zip -r archive.zip dir` · `unzip archive.zip -d dir` | ينشئ · يفك ملف zip |
| `du -sh dir` | يعرض المساحة التي يشغلها شيء ما |
