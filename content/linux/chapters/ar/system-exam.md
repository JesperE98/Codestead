# اختبار: النظام

أجب عن الأسئلة المتعلقة بالمتغيرات والصلاحيات والعمليات والأرشيفات – تحتاج إلى 80 % للنجاح.

```predict
$ echo "$HOME" '$USER'
/home/elev $USER
---
تستبدل علامات الاقتباس المزدوجة المتغير بقيمته، أما المفردة فتطبعه كما كُتب
تمامًا.
```

```quiz
ماذا يفعل `export` بالمتغير؟
- [ ] يحفظه في `~/.bashrc`
- [x] يجعله متغير بيئة تستطيع البرامج التي تشغّلها قراءته أيضًا
- [ ] يحذفه
```

```predict
$ ls ~ > /dev/null
$ echo $?
0
---
نجح `ls`، لذا فرمز الخروج `0`. أما المخرجات نفسها فاختفت في
`/dev/null`.
```

```quiz
أيّ رقم يعطي الصلاحيات `rwxr-x---`؟
- [ ] `755`
- [x] `750`
- [ ] `640`
---
المالك: 4 + 2 + 1 = 7. المجموعة: 4 + 1 = 5. الآخرون: 0.
```

```quiz
تجرّب `kill 812` على عملية تخص root فتحصل على
`Operation not permitted`. ماذا تفعل؟
- [ ] تستخدم `kill -9 812` بدلًا من ذلك
- [x] تشغّله باستخدام `sudo`: `sudo kill 812`
- [ ] لا شيء – لا يمكن أبدًا إيقاف عمليات root
```

```quiz
ما الفرق بين `pkill` و`killall`؟
- [x] يطابق `pkill` نمطًا، أما `killall` فيحتاج إلى الاسم الدقيق
- [ ] يرسل `pkill` الإشارة `SIGKILL`، ويرسل `killall` الإشارة `SIGTERM`
- [ ] لا فرق – إنهما البرنامج نفسه
```

```quiz
ما الخطأ في `tar -cvf dokument dokument.tar`؟
- [ ] لا يمكن الجمع بين `-v` و`-c`
- [x] الترتيب: يجب أن يأتي اسم الأرشيف مباشرةً بعد `f`، قبل الملفات
- [ ] يجب أن ينتهي أرشيف tar بـ `.tgz`
```

```predict

```
