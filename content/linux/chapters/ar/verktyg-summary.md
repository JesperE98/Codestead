# ملخّص: أدوات أخرى

في هذا الجزء تعرّفت على أداتين ستستخدمهما بقية حياتك في الطرفية: git، الذي يحفظ
تاريخ ملفاتك، وأصداف shell غير bash. إليك ما يجب أن تتذكره قبل الاختبار.

## Git في الطرفية

**Git** نظام للتحكم في الإصدارات: يحفظ لقطات من المشروع كله، ويتذكر من غيّر ماذا
ولماذا، ويتيح لك العودة بالزمن. على Ubuntu تثبّته باستخدام `sudo apt install git`،
وتستخدم التوزيعات الأخرى مدير حزمها الخاص.

- قبل أول commit تخبر git بمن أنت باستخدام `git config --global user.name`
  و`user.email`. يعني `--global` كل مشاريعك، وتنتهي الإعدادات في `~/.gitconfig`.
- يحوّل `git init` مجلدًا إلى **مستودع**. ويعيش التاريخ كله في المجلد المخفي
  `.git`.
- يمر التغيير عبر ثلاثة أماكن: **شجرة العمل** (الملفات التي تراها)، و**الفهرس**
  (ما يدخل في الـ commit التالي)، و**التاريخ** (الـ commits). ينقل `git add`
  التغييرات إلى الفهرس، ويحفظ `git commit` الفهرس كـ commit جديد.
- يضيف `git commit -a` كل ملف متغيّر يتتبّعه git أصلًا – لكن لا يضيف الملفات
  الجديدة أبدًا.
- يعرض `git diff` التغييرات التي لم تدخل الفهرس بعد، ويعرض `git diff --staged` ما
  في الفهرس.
- **الفرع** تسمية تشير إلى commit وتتحرك مع الـ commits الجديدة. عندما تبدّل الفرع،
  يعيد git كتابة شجرة العمل.
- يدمج `git merge` فرعًا في الفرع الذي أنت عليه. إذا غيّر كلا الفرعين الأسطر نفسها
  تحصل على **تعارض**: أصلح الملف، ثم `git add` له، وأنهِ باستخدام `git commit`.
- يسرد `.gitignore` الملفات التي يجب ألا يتتبّعها git. ولا يسري إلا على الملفات
  التي لا يتتبّعها git أصلًا.
- الـ **remote** نسخة من المستودع في مكان آخر، وتُسمّى عادةً `origin`. يجلب
  `git pull` ويدمج، ويرسل `git push` الـ commits الخاصة بك.

| الأمر | ماذا يفعل |
|---|---|
| `git config --global user.name "…"` | يخبر git باسمك (و`user.email`) |
| `git init` | يحوّل المجلد إلى مستودع |
| `git status` | يعرض مكان كل تغيير |
| `git add FILE` / `git add .` | يضع التغييرات في الفهرس |
| `git commit -m "…"` | يحفظ الفهرس كـ commit جديد |
| `git commit -am "…"` | يضيف كل ملف متتبَّع ويعمل commit بخطوة واحدة |
| `git diff` / `git diff --staged` | يعرض التغييرات التي لم تُحفظ في commit |
| `git log --oneline --graph --all` | يعرض التاريخ |
| `git restore FILE` | يتخلص من التغييرات في ملف |
| `git restore --staged FILE` | يُخرج ملفًا من الفهرس |
| `git switch -c BRANCH` / `git switch BRANCH` | ينشئ فرعًا / يبدّل الفرع |
| `git merge BRANCH` | يدمج فرعًا في الفرع الذي أنت عليه |
| `git branch -d BRANCH` | يحذف فرعًا مدموجًا |
| `git rm --cached FILE` | يتوقف عن تتبّع ملف لكن يُبقيه على القرص |
| `git clone`، `git pull`، `git push` | التعاون عبر remote |

## أصداف shell أخرى: zsh وfish

يقرأ **الـ shell** ما تكتبه ويبدأ برامج أخرى. تعمل البرامج مثل `ls` و`grep` بالطريقة
نفسها في كل shell – أما ما يختلف فهو اللغة المحيطة بها: المتغيّرات، والحلقات،
والشروط، والمحث.

- يسرد `/etc/shells` الأصداف التي يجوز أن تكون أصداف تسجيل دخول. الـ shell الخاص
  بتسجيل دخولك هو الحقل الأخير من سطرك في `/etc/passwd`، وهو موجود أيضًا في
  `$SHELL`. ويحمل `$0` الـ shell الذي تشغّله الآن.
- يفهم **zsh** كل صياغة bash تقريبًا ويضيف وسائل راحة: يبحث `**/` في كل المجلدات
  الفرعية، ومع `autocd` تنتقل إلى مجلد بمجرد كتابة اسمه. تُفعَّل الخيارات وتُعطَّل
  باستخدام `setopt` و`unsetopt`. وعلى عكس bash، لا يقسّم zsh المتغيّرات غير
  المقتبسة عند المسافات.
- **fish** سهل الاستخدام من البداية لكن له **صياغته الخاصة**: `set` بدلًا من `=`،
  و`$status` بدلًا من `$?`، و`math` بدلًا من `$((...))`، وكل كتلة تنتهي بـ `end`.
  وكل متغيّر قائمة، مرقّمة بدءًا من 1.
- الـ shell الذي تبدؤه يعمل **داخل** bash، و`exit` يعيدك. ومع `-c` يشغّل الـ shell
  أمرًا واحدًا ثم يخرج.
- ما زالت السكربتات تُكتب لـ bash (أو لـ `sh` وفق POSIX): سطر `#!` هو الذي يحدد
  الـ shell الذي يشغّل السكربت، أيًّا كان الـ shell الذي تجلس فيه.
- يغيّر `chsh -s` الـ shell الخاص بتسجيل دخولك. ويسري التغيير عند تسجيل الدخول
  التالي.

| الأمر | ماذا يفعل |
|---|---|
| `cat /etc/shells` | يسرد الأصداف التي يجوز استخدامها |
| `echo $0` / `ps` | يُظهر الـ shell الذي تشغّله الآن |
| `echo $SHELL` | يُظهر الـ shell الخاص بتسجيل دخولك |
| `zsh` / `fish` / `exit` | يبدأ shell آخر / يعود |
| `zsh -c '…'` / `fish -c '…'` | يشغّل أمرًا واحدًا في shell آخر |
| `setopt autocd` / `unsetopt autocd` | يفعّل / يعطّل خيارًا في zsh |
| `set frukt äpple` / `set -e frukt` | يعيّن / يزيل متغيّرًا في fish |
| `set -x NAME value` | يعيّن متغيّر بيئة في fish |
| `math 17 x 23` | الحساب في fish |
| `chsh -s /usr/bin/zsh` | يغيّر الـ shell الخاص بتسجيل دخولك |

ملفات الإعدادات: `~/.bashrc` (bash)، و`~/.zshrc` (zsh)، و
`~/.config/fish/config.fish` (fish).
