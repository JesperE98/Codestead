# 欢迎来到 Linux shell

本教程将教你如何通过命令行使用 Linux——从你的第一条命令，一直到在不同发行版上进行软件包管理。每一章讲解一个主题，并在最后附上一组**任务**，你需要在右侧的终端中完成它们。只要你做对了，任务就会被自动勾选。学习的最好方法就是*动手*：阅读、尝试、犯错，然后再试一次。

## 什么是 Linux？

严格来说，**Linux** 只是*内核*（kernel）：它是与硬件打交道的程序，让其他程序能够共享处理器、内存和磁盘。内核由 Linus Torvalds 于 1991 年创建，是自由软件。

要得到一个能用的系统，光有内核还远远不够：你还需要 shell、管理文件的工具、包管理器，也许还要一个桌面环境。**发行版**（*distribution*，简称 *distro*）把这些东西打包成一个开箱即用的整体。你现在运行的是 **{{distro}}**。

发行版按*家族*划分，同一家族的发行版彼此衍生，并使用相同的包管理器：

| 家族 | 包管理器 | 例子 |
|---|---|---|
| Debian | `apt` | Debian、Ubuntu、Linux Mint、Pop!_OS |
| Arch | `pacman` | Arch Linux、Manjaro、EndeavourOS |
| Red Hat | `dnf` | Fedora、RHEL、Rocky Linux、AlmaLinux |

你在本教程中学到的大部分内容在哪里都一样。不同的地方——主要是软件包管理——会有专门的章节来讲。你可以随时通过顶部的菜单切换发行版。

## 什么是 shell？

**shell** 是读取你输入的命令并执行它们的程序。最常见的 shell 是 **bash**，几乎所有发行版都默认使用它。其他流行的 shell 还有 **zsh**（macOS 的默认 shell）和 **fish**。它们的基础用法都是一样的。

注意*终端*（terminal）和 *shell* 的区别：终端是显示文字的窗口，而 shell 是在窗口里运行的程序。

## 提示符

当 shell 在等待命令时，它会显示一个**提示符**（prompt）。在 {{distro}} 上，它看起来大概是这样的：

:::debian
```text
elev@{{hostname}}:~$
```
:::

:::arch
```text
[elev@{{hostname}} ~]$
```
:::

:::redhat
```text
[elev@{{hostname}} ~]$
```
:::

它告诉你：你是谁（`elev`）、你在哪台计算机上（`{{hostname}}`），以及你在文件系统中的位置（`~` 表示你的主目录）。`$` 符号表示你是普通用户。如果你是管理员（*root*），看到的会是 `#`。

## 你的第一条命令

点击终端，输入下面的命令，然后按 **Enter**：

```sh
echo Hej världen
```

`echo` 只是把你给它的内容打印出来——这里是 *Hej världen*，也就是瑞典语的“你好，世界”。大多数命令都遵循同样的格式：

```text
command  -options  arguments
ls       -l        /etc
```

*命令*（command）是要运行的程序，*选项*（options，也叫 *flags*）改变命令的行为，*参数*（arguments）则是命令要处理的对象。

## 模拟器是如何工作的

这里的终端是一个完全在浏览器中运行的**模拟器**。它的表现就像一台真正的 Linux 计算机，但你在这里做的任何事都不会伤害你自己的电脑——如果你搞砸了，随时可以用*重置*按钮从头开始。

- **点击代码示例**，即可把命令放进终端。
- **Tab** 键可以补全命令和文件名。
- **上/下方向键**可以翻看之前输入过的命令。
- **Ctrl+L** 清屏，**Ctrl+C** 取消你正在输入的这一行。
- `help` 列出所有命令，`man command` 显示某个命令（command）的手册页。

### 几个瑞典语单词

本教程最初是用瑞典语写的，所以模拟器中的用户和练习文件都用了瑞典语名称。你不需要会瑞典语——命令完全一样——不过这个小词汇表可能会对你有帮助：

| 名称 | 含义 |

| `elev` | 学生（你的用户名） |
| `dokument` | 文档 |
| `anteckningar.txt` | 笔记 |
| `frukter.txt` | 水果 |
| `betyg.csv` | 成绩 |
| `bilder` | 图片 |
| `gammalt` | 旧东西 |
