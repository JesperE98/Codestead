# 总结：基础知识

你已经学会了那些每天都会用到、在每个发行版上都一样的命令。测验之前，先来快速回顾一下。

## 在文件系统中导航

所有东西都位于同一棵从根目录 `/` 开始的目录树中。设置位于 `/etc`，程序位于 `/usr/bin`，日志位于 `/var/log`，而你自己的文件位于主目录 `~` 中。`pwd` 显示你在哪里，`ls` 列出这里有什么，`cd` 带你去别的地方。**绝对**路径以 `/` 开头；**相对**路径则从你当前所在的目录出发。`..` 是上一级目录，不带参数的 `cd` 会带你回到主目录。

## 文件和目录

`mkdir` 创建目录（`-p` 可以一次创建多级目录），`touch` 创建空文件。`cp` 复制（整个目录要用 `-r`），`mv` 既能移动也能重命名，`rm` 删除——永久删除，没有回收站。`rmdir` 只能删除空目录；`rm -r` 会删除目录以及其中的所有内容。`*`、`?` 和 `[abc]` 这样的通配符会在命令运行之前由 shell 展开，而带空格的名字需要加引号。

## 阅读和搜索文本

`cat` 打印文件，`less` 让你可以滚动浏览文件。`head` 和 `tail` 显示开头和结尾（`-n` 指定行数，`tail -f` 跟踪文件）。`wc` 统计行数、单词数和字节数。`grep` 显示匹配某个模式的行，`sort` 对行进行排序，`uniq` 删除相邻的重复行。`man` 显示命令的手册。

## 重定向和管道

每个程序都有三个流：stdin、stdout 和 stderr。`>` 把 stdout 发送到文件（并覆盖它），`>>` 追加到文件末尾，`<` 从文件读取 stdin，`2>` 重定向错误信息——例如发送到 `/dev/null`。管道 `|` 把一个命令的输出送进下一个命令，`tee` 则在中途保存一份副本。`;`、`&&` 和 `||` 可以在一行中运行多个命令。

## 用 sed、tr 和 awk 处理文本

`tr` 替换、删除（`-d`）或压缩（`-s`）单个字符，并且只从 stdin 读取。`sed` 编辑行：`s/old/new/` 进行替换（`g` 替换所有匹配项），地址用来选择行，`d` 删除行，`-n` 搭配 `p` 只打印你要求的内容。`sed -i` 会直接修改文件本身。`cut` 挑出一个字段，而 `awk` 处理列：`-F` 设置分隔符，`$1` … `$NF` 是各个字段，`{ }` 前面的模式用来选择行，`END { }` 在最后一行之后运行。

## 命令和选项

| 命令 | 作用 | 本部分中的选项和语法 |
|---|---|---|
| `pwd` | 显示你当前所在的目录 | |
| `ls` | 列出目录的内容 | `-l` 长格式，`-a` 也显示隐藏文件 |
| `cd` | 切换目录 | `..` 上一级，`~` 主目录，`-` 上一次所在的目录，不带参数 = 主目录 |
| `mkdir` | 创建目录 | `-p` 一次创建多级目录 |
| `touch` | 创建空文件 | |
| `cp` | 复制 | `-r` 整个目录 |
| `mv` | 移动或重命名 | |
| `rm` | 删除 | `-r` 目录及其内容，`-f` 不询问 |
| `rmdir` | 删除空目录 | |
| `cat` | 打印文件 | |
| `less` | 逐页显示文件 | `/word` 搜索，`q` 退出 |
| `head` / `tail` | 开头 / 结尾的几行 | `-n N` 行数，`tail -f` 跟踪 |
| `wc` | 统计行数、单词数和字节数 | `-l` 只统计行数 |
| `grep` | 显示匹配的行 | `-i`、`-n`、`-v`、`-c`、`-r`、`-E` |
| `sort` | 对行进行排序 | `-n` 按数字，`-r` 逆序 |
| `uniq` | 删除相邻的重复行 | `-c` 统计重复次数 |
| `man` | 显示手册页 | |
| `tee` | 把输入继续往下传，并保存一份副本 | |
| `tr` | 转换字符 | `-d` 删除，`-s` 压缩 |
| `sed` | 编辑行流 | `s/…/…/g`、`d`、`p`、`q`、`-n`、`-i`、`-E`、`-e` |
| `cut` | 挑出字段 | `-d` 分隔符，`-f` 字段 |
| `awk` | 处理列 | `-F` 分隔符，`$1`、`$NF`、`NF`、`NR`、`BEGIN`、`END` |

| 语法 | 含义 |
|---|---|
| `>` / `>>` | stdout 写入文件（覆盖 / 追加） |
| `<` | 从文件读取 stdin |
| `2>` | stderr 写入文件，例如 `2> /dev/null` |
| `2>&1` | stderr 发送到和 stdout 相同的地方 |
| `\|` | 管道：一个命令的 stdout 送进下一个命令的 stdin |
| `a ; b` | 先运行 a，再运行 b |
| `a && b` | 只有 a 成功时才运行 b |
| `a \|\| b` | 只有 a 失败时才运行 b |
| `*`, `?`, `[abc]` | 文件名通配符 |
