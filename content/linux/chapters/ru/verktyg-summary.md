# Итоги: Другие инструменты

В этой части вы познакомились с двумя инструментами, которыми будете
пользоваться в терминале всю жизнь: git, который хранит историю ваших файлов,
и другими shell, кроме bash. Вот что стоит запомнить перед экзаменом.

## Git в терминале

**Git** – это система контроля версий: она сохраняет снимки всего проекта,
помнит, кто что изменил и зачем, и позволяет вернуться назад во времени. В
Ubuntu он устанавливается командой `sudo apt install git`; в других
дистрибутивах используется свой менеджер пакетов.

- Перед первым коммитом вы сообщаете git, кто вы, с помощью
  `git config --global user.name` и `user.email`. `--global` означает – для
  всех ваших проектов; настройки попадают в `~/.gitconfig`.
- `git init` превращает каталог в **репозиторий**. Вся история хранится в
  скрытом каталоге `.git`.
- Изменение проходит через три места: **рабочий каталог** (файлы, которые вы
  видите), **индекс** (то, что попадёт в следующий коммит) и **историю**
  (коммиты). `git add` переносит изменения в индекс, `git commit` сохраняет
  индекс как новый коммит.
- `git commit -a` добавляет все изменённые файлы, которые git уже
  отслеживает, – но никогда не добавляет новые файлы.
- `git diff` показывает изменения, которых ещё нет в индексе; `git diff --staged`
  показывает то, что лежит в индексе.
- **Ветка** – это метка, которая указывает на коммит и сдвигается вместе с
  новыми коммитами. Когда вы переключаетесь между ветками, git переписывает
  рабочий каталог.
- `git merge` вливает ветку в ту, на которой вы находитесь. Если обе ветки
  изменили одни и те же строки, возникает **конфликт**: исправьте файл,
  выполните для него `git add` и завершите командой `git commit`.
- В `.gitignore` перечислены файлы, которые git не должен отслеживать. Он
  действует только на файлы, которые git ещё не отслеживает.
- **Удалённый репозиторий** (*remote*) – это копия репозитория где-то в
  другом месте, обычно с именем `origin`. `git pull` получает и сливает
  изменения, `git push` отправляет ваши коммиты.

| Команда | Что делает |
|---|---|
| `git config --global user.name "…"` | Сообщить git своё имя (и `user.email`) |
| `git init` | Превратить каталог в репозиторий |
| `git status` | Показать, где находится каждое изменение |
| `git add FILE` / `git add .` | Положить изменения в индекс |
| `git commit -m "…"` | Сохранить индекс как новый коммит |
| `git commit -am "…"` | Добавить все отслеживаемые файлы и закоммитить за один шаг |
| `git diff` / `git diff --staged` | Показать незакоммиченные изменения |
| `git log --oneline --graph --all` | Показать историю |
| `git restore FILE` | Отбросить изменения в файле |
| `git restore --staged FILE` | Убрать файл из индекса |
| `git switch -c BRANCH` / `git switch BRANCH` | Создать ветку / переключиться на ветку |
| `git merge BRANCH` | Влить ветку в ту, на которой вы находитесь |
| `git branch -d BRANCH` | Удалить слитую ветку |
| `git rm --cached FILE` | Перестать отслеживать файл, но оставить его на диске |
| `git clone`, `git pull`, `git push` | Совместная работа через удалённый репозиторий |

## Другие shell: zsh и fish

**Shell** читает то, что вы вводите, и запускает другие программы. Программы
вроде `ls` и `grep` работают одинаково в любом shell – различается язык
вокруг них: переменные, циклы, условия и приглашение.

- В `/etc/shells` перечислены shell, которые можно использовать как login
  shell. Ваш login shell – последнее поле вашей строки в `/etc/passwd`, и он
  же лежит в `$SHELL`. `$0` содержит shell, который работает прямо сейчас.
- **zsh** понимает почти весь синтаксис bash и добавляет удобства: `**/`
  ищет во всех подкаталогах, а с `autocd` можно перейти в каталог, просто
  набрав его имя. Опции включаются и выключаются командами `setopt` и
  `unsetopt`. В отличие от bash, zsh не разбивает переменные без кавычек по
  пробелам.
- **fish** прост в использовании с самого начала, но у него **свой
  собственный синтаксис**: `set` вместо `=`, `$status` вместо `$?`, `math`
  вместо `$((...))`, и каждый блок заканчивается словом `end`. Каждая
  переменная – это список, пронумерованный с 1.
- Запущенный shell работает **внутри** bash; `exit` возвращает вас обратно. С
  `-c` shell выполняет одну команду и завершается.
- Скрипты по-прежнему пишутся для bash (или POSIX `sh`): строка `#!`
  определяет, какой shell выполняет скрипт, в каком бы shell вы ни сидели.
- `chsh -s` меняет ваш login shell. Изменение вступает в силу при следующем
  входе в систему.

| Команда | Что делает |
|---|---|
| `cat /etc/shells` | Показать shell, которые можно использовать |
| `echo $0` / `ps` | Узнать, какой shell работает прямо сейчас |
| `echo $SHELL` | Узнать свой login shell |
| `zsh` / `fish` / `exit` | Запустить другой shell / вернуться назад |
| `zsh -c '…'` / `fish -c '…'` | Выполнить одну команду в другом shell |
| `setopt autocd` / `unsetopt autocd` | Включить / выключить опцию zsh |
| `set frukt äpple` / `set -e frukt` | Задать / удалить переменную в fish |
| `set -x NAME value` | Задать переменную окружения в fish |
| `math 17 x 23` | Арифметика в fish |
| `chsh -s /usr/bin/zsh` | Сменить login shell |

Файлы настроек: `~/.bashrc` (bash), `~/.zshrc` (zsh) и
`~/.config/fish/config.fish` (fish).
