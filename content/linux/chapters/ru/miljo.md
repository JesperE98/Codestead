# Переменные, PATH и псевдонимы

У shell есть собственная память – **переменные**. В этой главе вы узнаете,
как их читать и задавать, как shell находит программы и как создавать
собственные сокращения.

## Переменные окружения

Чтобы прочитать переменную, поставьте перед её именем `$`:

```sh
echo $HOME
echo "Меня зовут $USER"
```

`env` выводит все *переменные окружения* – переменные, которые могут читать
и запускаемые вами программы:

```sh
env
```

Переменная создаётся так: `ИМЯ=значение` (без пробелов вокруг `=`!). С
помощью `export` она становится переменной окружения:

```sh
export EDITOR=nano
```

```quiz
Какая строка создаёт переменную `FARG` со значением `blue`?
- [ ] `FARG = blue`
- [x] `FARG=blue`
- [ ] `$FARG=blue`
---
Вокруг `=` не должно быть пробелов. С пробелами shell решит, что `FARG` – это
команда. `$` нужен только тогда, когда вы *читаете* переменную.
```

## Одинарные и двойные кавычки

Здесь есть важная разница:

```sh
echo "Дом: $HOME"
echo 'Дом: $HOME'
```

Внутри **двойных** кавычек переменные заменяются своими значениями. Внутри
**одинарных** кавычек всё выводится в точности так, как написано.

```predict
$ x=linux
$ echo "I like $x"
$ echo 'I like $x'
I like linux
I like $x
```

## PATH – где ищутся команды?

Когда вы вводите `ls`, shell ищет файл с именем `ls` по очереди в каталогах,
перечисленных в переменной `PATH`:

```sh
echo $PATH
```

`which` показывает, где была найдена программа. Некоторые команды, например
`cd`, – вовсе не файлы, а *встроены* в shell; `type` сообщает, что
представляет собой имя:

```sh
which ls
type cd
```

Чтобы запустить программу, которой нет в `PATH`, нужно указать путь к ней,
например `./myprogram` для файла в текущем каталоге.

```quiz
В текущем каталоге есть программа `hej`, а сам каталог не входит в `PATH`.
Как её запустить?
- [ ] `hej`
- [x] `./hej`
- [ ] `type hej`
---
Без пути shell ищет только в каталогах из `PATH`. `./hej` точно указывает, где
лежит файл: в текущем каталоге.
```

## Коды возврата – `$?`

Каждая команда по завершении оставляет **код возврата** (exit code): `0`
означает, что всё прошло хорошо, всё остальное – ошибку. Последний код
возврата хранится в `$?`:

```sh
ls /finnsinte
echo $?
```

Именно на код возврата смотрят `&&` и `||`.

## Псевдонимы

**Alias** (псевдоним) – это ваше собственное сокращение:

```sh
alias ll='ls -la'
ll
```

`alias` без аргументов выводит все псевдонимы, а `unalias ll` удаляет один
из них.

```predict
$ alias hej='echo Hello'
$ hej
Hello
```

## Сохранение настроек – `~/.bashrc`

Созданные вами переменные и псевдонимы исчезают, когда вы закрываете
терминал. Чтобы сохранить их, запишите их в файл `~/.bashrc`, который bash
читает каждый раз при открытии нового терминала. После изменения файла его
можно сразу загрузить командой:

```sh
source ~/.bashrc
```

```quiz
Вы создали псевдоним, закрыли терминал и открыли новый. Псевдонима больше нет.
Что нужно было сделать?
- [ ] Выполнить `alias` без аргументов
- [x] Записать псевдоним в `~/.bashrc`
- [ ] Создать его с помощью `export`
---
Всё, что записано в `~/.bashrc`, читается заново при каждом открытии нового
терминала.
```
