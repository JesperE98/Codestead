# Перенаправление и конвейеры

Эта глава о том, что делает командную строку такой мощной: о *соединении*
маленьких программ друг с другом.

## Три потока

У каждой программы есть три стандартных потока:

| Номер | Имя | Что это |
|---|---|---|
| 0 | stdin | Ввод, обычно с клавиатуры |
| 1 | stdout | Обычный вывод, обычно на экран |
| 2 | stderr | Сообщения об ошибках, тоже на экран |

С помощью *перенаправления* и *конвейеров* (pipes) эти потоки можно
направить в другое место.

## В файл – `>` и `>>`

`>` отправляет stdout в файл вместо экрана. Файл создаётся, если его нет, –
и **перезаписывается**, если он есть!

```sh
echo "первая строка" > test.txt
```

`>>` вместо этого дописывает в конец файла:

```sh
echo "вторая строка" >> test.txt
cat test.txt
```

## Из файла – `<`

`<` позволяет программе читать stdin из файла:

```sh
wc -l < dokument/frukter.txt
```

## Сообщения об ошибках – `2>`

Сообщения об ошибках идут в stderr, и `>` на них не влияет. Чтобы
перенаправить их, укажите перед знаком номер потока:

```sh
ls /finnsinte 2> fel.txt
```

(*Finns inte* по-шведски значит «не существует», а *fel* – «ошибка».)

Файл `/dev/null` – это «чёрная дыра»: всё, что в него записано, исчезает.
Это удобно, чтобы заглушить ошибки. С помощью `2>&1` stderr отправляется
туда же, куда и stdout.

## Конвейеры – `|`

**Pipe** (конвейер) передаёт stdout одной команды прямо в stdin следующей.
В этом суть философии Unix: *делай что-то одно и делай это хорошо, а
программы пусть работают вместе*.

```sh
grep INFO dokument/server.log | wc -l
```

`grep` находит строки, а `wc -l` их считает. Соединять можно сколько угодно
команд:

```sh
sort dokument/frukter.txt | uniq -c | sort -rn
```

Читайте по шагам: отсортировать фрукты, посчитать, сколько раз встречается
каждый (`uniq -c`), а затем отсортировать по числу, начиная с наибольшего
(`sort -rn`).

## И на экран, и в файл – `tee`

`tee` передаёт свой ввод дальше *и* сохраняет копию в файл:

```sh
ls /etc | tee etc-lista.txt | wc -l
```

## Цепочки – `;`, `&&` и `||`

В одной строке можно записать несколько команд:

| Синтаксис | Означает |
|---|---|
| `a ; b` | Выполнить a, затем b |
| `a && b` | Выполнить b, только если a завершилась успешно |
| `a \|\| b` | Выполнить b, только если a завершилась с ошибкой |

```sh
mkdir -p ny && cd ny
```
