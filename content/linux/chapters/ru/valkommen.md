# Добро пожаловать в shell Linux

Это руководство научит вас работать с Linux из командной строки – от самых
первых команд до управления пакетами в разных дистрибутивах. Каждая глава
объясняет одну тему. По ходу текста встречаются короткие **вопросы**;
ответьте на них, и откроются терминал справа и **задания** главы. Задание
отмечается выполненным автоматически, как только вы с ним справитесь. Лучший способ учиться – *делать*: читайте, пробуйте,
ошибайтесь и пробуйте снова.

## Что такое Linux?

Строго говоря, **Linux** – это только *ядро* (kernel): программа, которая
общается с железом и позволяет другим программам совместно использовать
процессор, память и диски. Ядро создал Линус Торвальдс в 1991 году, и это
свободное программное обеспечение.

Чтобы получить пригодную для работы систему, нужно гораздо больше: shell,
инструменты для работы с файлами, пакетный менеджер, возможно, графический
рабочий стол. **Дистрибутив** (*distro*) собирает всё это в готовое целое.
Debian, Ubuntu, Arch Linux и Fedora – несколько известных примеров.

Большая часть того, что вы изучите в этом руководстве, работает одинаково во
всех дистрибутивах, поэтому с этого курс и начинается. Терминал здесь работает
на **Ubuntu 24.04 LTS**. Дистрибутивы различаются в основном тем, как
устанавливаются программы, – об этом в главе о дистрибутивах.

## Что такое shell?

**Shell** (командная оболочка) – это программа, которая читает вводимые вами
команды и выполняет их. Самый распространённый shell – **bash**, он стоит по
умолчанию почти во всех дистрибутивах. Другие популярные оболочки – **zsh**
(по умолчанию в macOS) и **fish**. Основы во всех них одинаковы.

Обратите внимание на разницу между *терминалом* и *shell*: терминал – это
окно, которое показывает текст, а shell – программа, работающая внутри него.

```quiz
Вы вводите `ls` и нажимаете Enter. Какая программа читает команду и выполняет её?
- [ ] Терминал
- [x] Shell
- [ ] Ядро
---
Терминал только показывает текст. Shell (здесь bash) читает то, что вы вводите,
и выполняет это.
```

## Приглашение

Когда shell ждёт команду, он показывает **приглашение** (prompt). В здешнем
терминале оно выглядит так:

```text
elev@ubuntu:~$
```

Оно сообщает, кто вы (`elev`), на каком компьютере находитесь (`ubuntu`)
и где в файловой системе вы сейчас (`~` означает ваш домашний каталог). Знак
`$` показывает, что вы обычный пользователь. Если вы администратор (*root*),
вместо него будет `#`.

```quiz
Приглашение заканчивается на `#` вместо `$`. О чём это говорит?
- [ ] Вы находитесь в домашнем каталоге
- [ ] Предыдущая команда завершилась ошибкой
- [x] Вы – администратор, root
```

## Ваша первая команда

Щёлкните в терминале, введите команду ниже и нажмите **Enter**:

```sh
echo Hej världen
```

`echo` просто выводит то, что вы ему передали, – здесь *Hej världen*, что
по-шведски значит «Привет, мир». Большинство команд построены по одному
образцу:

```text
команда  -опции    аргументы
ls       -l        /etc
```

*Команда* – это программа, которую нужно запустить, *опции* (или *флаги*)
меняют её поведение, а *аргументы* – это то, с чем команда должна работать.

```quiz
Какая часть команды `ls -l /etc` – **опция**?
- [ ] `ls`
- [x] `-l`
- [ ] `/etc`
---
`ls` – это команда, `-l` меняет её поведение, а `/etc` – аргумент, то, с чем
`ls` должна работать.
```

Попробуйте `echo` со своим собственным текстом:

```try
echo Linux is fun
---
`echo` вывел ровно те слова, которые вы ему передали.
```

## Кто я и где я?

Две маленькие команды рассказывают о системе, в которой вы находитесь.
`whoami` выводит имя пользователя, под которым вы вошли. Файл
`/etc/os-release` описывает дистрибутив, а `cat` выводит файл (подробнее о
`cat` – в одной из следующих глав):

```sh
whoami
cat /etc/os-release
```

## Как устроен симулятор

Терминал здесь – это **симулятор**, который работает целиком внутри этого
приложения. Он ведёт себя как настоящий компьютер с Linux, но ничто из того,
что вы делаете, не может навредить вашей машине, – а если вы натворите
что-нибудь не то, всегда можно начать заново с помощью *Сбросить терминал* в
настройках.

- **Щёлкните по примеру кода**, чтобы вставить команду в терминал.
- **Tab** дополняет команды и имена файлов.
- **Стрелки вверх/вниз** листают ранее введённые команды.
- **Ctrl+L** очищает экран, а **Ctrl+C** отменяет набираемую строку.
- `help` выводит список всех команд, а `man команда` показывает страницу руководства.

```quiz
Вы ввели `ech` и нажали **Tab**. Что произойдёт?
- [ ] Строка будет отменена
- [x] Shell попытается дописать остальную часть имени
- [ ] Экран очистится
---
Tab дополняет команды и имена файлов. **Ctrl+C** отменяет строку, а **Ctrl+L**
очищает экран.
```

### Несколько шведских слов

Изначально это руководство было написано на шведском, поэтому пользователь и
учебные файлы в симуляторе имеют шведские имена. Знать шведский не нужно –
команды точно такие же, – но этот маленький словарик может пригодиться:

| Имя | Значение |
|---|---|
| `elev` | ученик (ваше имя пользователя) |
| `dokument` | документы |
| `anteckningar.txt` | заметки |
| `frukter.txt` | фрукты |
| `betyg.csv` | оценки |
| `bilder` | картинки |
| `gammalt` | старьё |
