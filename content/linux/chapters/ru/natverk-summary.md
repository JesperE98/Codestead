# Итоги: Сеть

В этой части вы освоились в небольшой домашней сети из терминала: ваш
собственный адрес, выход в интернет, имена и DNS, порты, веб и другие
компьютеры по SSH.

## Сеть

У каждого компьютера в сети есть **IP-адрес**, а адреса, начинающиеся с
`192.168.`, `10.` или `172.16.`–`172.31.`, – **частные**. `ip a` показывает
интерфейсы и адреса компьютера – `lo` – это петлевая карта, а `127.0.0.1`
(**localhost**) всегда означает сам компьютер. **Маска сети** (`/24`)
говорит, какие адреса находятся в локальной сети; всё остальное идёт по
маршруту по умолчанию на **шлюз**, который показывает `ip route`. `ping`
проверяет, доступен ли компьютер.

**DNS** переводит имена в адреса. Прежде чем спрашивать DNS, компьютер
смотрит в `/etc/hosts`, а `getent hosts` показывает, что находит система,
тогда как `dig` спрашивает DNS напрямую. В Ubuntu `/etc/resolv.conf`
указывает на `127.0.0.53`, systemd-resolved, а `dig`, `host` и `nslookup`
входят в пакет `dnsutils`.

**Порт** указывает на программу на компьютере, а `ss -tulpn` показывает,
какие порты слушаются. `curl` загружает URL и выводит его, `wget` скачивает в
файл – в Ubuntu `wget` предустановлен, а `curl` устанавливается с помощью apt.
С помощью **SSH** вы выполняете команды на другом компьютере в зашифрованном
виде; в первый раз вы подтверждаете ключ хоста сервера, а с парой ключей
пароль больше не нужен.

Когда «интернет не работает», идите изнутри наружу: адрес, маршрут, роутер,
адрес в интернете и, наконец, имя. Если адреса работают, а имена – нет, дело
в DNS.

## Команды

| Команда | Что делает |
|---|---|
| `ip a`, `ip -br a`, `hostname -I` | Показать IP-адреса |
| `ip route` | Показать таблицу маршрутизации и шлюз |
| `ping -c 3 HOST` | Проверить, доступен ли компьютер |
| `sudo ip link set CARD down` / `up` | Выключить / включить сетевую карту |
| `cat /etc/resolv.conf` | Какой DNS-сервер опрашивается |
| `dig +short NAME`, `dig @SERVER NAME` | Найти имя в DNS |
| `host NAME`, `nslookup NAME` | Найти имя (с `host` – и от адреса к имени) |
| `getent hosts NAME` | Найти так, как это делает система (с `/etc/hosts`) |
| `sudo tee -a /etc/hosts` | Дописать то, что приходит из конвейера, в `/etc/hosts` от имени root |
| `ss -tulpn` | Показать слушающие порты |
| `curl URL` | Загрузить и показать |
| `curl -I URL`, `curl -L URL` | Только заголовки, следовать за перенаправлениями |
| `curl -o FILE URL`, `wget URL`, `wget -O FILE URL` | Скачать в файл |
| `ssh USER@HOST COMMAND` | Выполнить команду на другом компьютере |
| `ssh-keygen`, `ssh-copy-id USER@HOST` | Создать пару ключей и положить открытый ключ на сервер |
