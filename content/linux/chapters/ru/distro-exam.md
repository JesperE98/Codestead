# Экзамен: дистрибутивы и пакеты

Ответьте на вопросы ниже. Для сдачи нужно 80 %.

```quiz
Какой файл во всех современных дистрибутивах сообщает название и версию
дистрибутива?
- [ ] `/etc/hostname`
- [x] `/etc/os-release`
- [ ] `/etc/version`
```

```try
uname -r
---
`uname -r` показывает версию ядра Linux.
```

```quiz

- [ ] `dnf` и `.deb`
- [ ] `apt` и `.rpm`
```


```quiz
Чем отличаются `apt update` и `apt upgrade`?
- [x] `update` загружает список доступных пакетов, а `upgrade` устанавливает новые версии
- [ ] `update` устанавливает новые версии, а `upgrade` загружает список
- [ ] Ничем
```

```quiz
Какая команда устанавливает пакет `htop` в Arch?
- [ ] `sudo pacman -R htop`
- [ ] `sudo pacman -Q htop`
- [x] `sudo pacman -S htop`
- [ ] `sudo pacman -Ss htop`
```

```quiz
Почему плохая идея выполнять `pacman -Sy`, а затем `pacman -S пакет`?
- [ ] Пакет устанавливается дважды
- [x] Это частичное обновление, которое может сломать систему
- [ ] `-Sy` удаляет все установленные пакеты
```

```quiz
dnf спрашивает `Is this ok [y/N]`, а вы просто нажимаете Enter. Что произойдёт?
- [ ] Пакет установится
- [x] Ничего не установится – по умолчанию ответ «нет»
```

```quiz
Что из этого верно об AUR?
- [x] В нём рецепты сборки (`PKGBUILD`), а не готовые пакеты
- [x] Его пакеты командой Arch не проверяются
- [ ] `sudo pacman -Syu` обновляет пакеты из AUR
- [ ] `makepkg` нужно запускать через sudo
```
