# Экзамен: Основы

Ответьте на вопросы ниже, чтобы показать, чему вы научились в этой части.

```quiz
Какой из этих путей **абсолютный**?
- [ ] `var/log`
- [ ] `../etc`
- [x] `/usr/bin`
- [ ] `{{documents}}`
---
Абсолютный путь начинается с `/`, от корня. Остальные отсчитываются от
текущего каталога.
```

```predict
$ cd /var/log
$ cd ../..
$ pwd
/
---
Каждый `..` поднимает на уровень выше: из `/var/log` в `/var`, а затем в `/`.
```

```quiz
Что делает `cd -`?
- [ ] Поднимается на уровень выше
- [ ] Переходит в домашний каталог
- [x] Возвращается в каталог, в котором вы были перед этим
```

```quiz
Вы хотите скопировать весь каталог `{{pictures}}` со всем содержимым в `{{pictures}}-copy`. Какая команда сработает?
- [ ] `cp {{pictures}} {{pictures}}-copy`
- [x] `cp -r {{pictures}} {{pictures}}-copy`
- [ ] `mv {{pictures}} {{pictures}}-copy`
---
Каталог копируется с `-r` (*recursive*). `mv` переместил бы его, а не
скопировал.
```

```predict
$ mkdir -p a/b/c
$ ls a/b
c
---
`-p` создаёт `a`, `a/b` и `a/b/c` за один раз, поэтому в `a/b` лежит `c`.
```

```quiz
Вы вводите `touch my file.txt` – без кавычек. Что произойдёт?
- [ ] Будет создан файл `my file.txt`
- [x] Будут созданы два файла: `my` и `file.txt`
- [ ] Ничего, потому что в имени есть пробел
---
Shell разбивает строку по пробелам, поэтому `touch` получает два аргумента.
Напишите `touch "my file.txt"`, чтобы получить один файл.
```

```quiz
Какие строки покажет `grep -i error {{documents}}/server.log`?
- [ ] Только строки с `error` строчными буквами
- [ ] Только строки с `ERROR` прописными буквами
- [x] Строки с `error` в любом сочетании прописных и строчных букв
```

```quiz
Вы хотите следить за файлом журнала и видеть новые строки по мере их записи. Какая команда подходит?
- [ ] `head -n 10 {{documents}}/server.log`
- [x] `tail -f {{documents}}/server.log`
- [ ] `wc -l {{documents}}/server.log`
---
`tail -f` *следит* за файлом. Остановить можно клавишами **Ctrl+C**.
```

```quiz
Что выводит `wc`, если передать ему файл без опций?
- [ ] Только число строк
- [x] Число строк, слов и байтов
- [ ] Первые 10 строк файла
```

```predict
$ echo a > x.txt
$ echo b >> x.txt
$ echo c > x.txt
$ cat x.txt
c
---
`>>` дописал `b`, но последний `>` перезаписал весь файл.
```

```quiz
Когда выполняется `b` в `a || b`?
- [ ] Всегда, после `a`
- [ ] Только если `a` завершилась успешно
- [x] Только если `a` завершилась с ошибкой
```

```try
grep ERROR ~/{{documents}}/server.log | tee errors.txt | wc -l
---
`tee` сохранил строки с ошибками в `errors.txt` и передал их дальше в `wc -l`,
который их посчитал.
```

```predict
$ echo "a,b,c" | cut -d, -f2
b
---
`-d,` делает запятую разделителем, а `-f2` оставляет поле 2.
```

```predict
$ echo "x y z" | awk '{print NF}'
3
---
`NF` – число полей в строке. Поля разделены пробелами.
```

```quiz
Почему программу awk вроде `'{print $3}'` нужно заключать в **одинарные** кавычки?
- [ ] awk не умеет читать двойные кавычки
- [x] Иначе shell решит, что `$3` – переменная shell, и подставит её ещё до запуска awk
- [ ] С одинарными кавычками awk работает быстрее
```
