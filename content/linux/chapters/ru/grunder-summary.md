# Итоги: Основы

Вы изучили команды, которыми будете пользоваться каждый день в любом
дистрибутиве. Вот краткое повторение перед экзаменом.

## Навигация по файловой системе

Всё находится в одном дереве, которое начинается с корня, `/`. Настройки
лежат в `/etc`, программы – в `/usr/bin`, журналы – в `/var/log`, а ваши
собственные файлы – в домашнем каталоге, `~`. `pwd` показывает, где вы
находитесь, `ls` выводит, что там есть, а `cd` переводит вас в другое место.
**Абсолютный** путь начинается с `/`; **относительный** путь отсчитывается от
текущего каталога. `..` – каталог уровнем выше, а `cd` без аргументов
возвращает вас домой.

## Файлы и каталоги

`mkdir` создаёт каталоги (`-p` создаёт сразу несколько уровней), а `touch`
создаёт пустые файлы. `cp` копирует (`-r` для целых каталогов), `mv` и
перемещает, и переименовывает, а `rm` удаляет – навсегда, корзины нет.
`rmdir` удаляет только пустые каталоги; `rm -r` удаляет каталог со всем
содержимым. Шаблоны вроде `*`, `?` и `[abc]` разворачивает shell ещё до
запуска команды, а имена с пробелами нужно брать в кавычки.

## Чтение и поиск текста

`cat` выводит файл, а `less` позволяет его листать. `head` и `tail`
показывают начало и конец (`-n` задаёт число строк, `tail -f` следит за
файлом). `wc` считает строки, слова и байты. `grep` показывает строки,
совпадающие с шаблоном, `sort` сортирует строки, а `uniq` удаляет повторяющиеся
строки, стоящие рядом. `man` показывает руководство по команде.

## Перенаправление и конвейеры

У каждой программы три потока: stdin, stdout и stderr. `>` отправляет stdout
в файл (и перезаписывает его), `>>` дописывает в конец, `<` читает stdin из
файла, а `2>` перенаправляет сообщения об ошибках – например, в `/dev/null`.
Конвейер `|` передаёт вывод одной команды в следующую, а `tee` по пути
сохраняет копию. `xargs` превращает слова из своего ввода в аргументы для
команды. `;`, `&&` и `||` выполняют несколько команд в одной строке.

## Обработка текста с помощью sed, tr и awk

`tr` заменяет, удаляет (`-d`) или сжимает (`-s`) отдельные символы и читает
только stdin. `sed` правит строки: `s/old/new/` заменяет (`g` – все
совпадения), адреса выбирают строки, `d` удаляет, а `-n` вместе с `p` выводит
только то, что вы попросили. `sed -i` меняет сам файл. `cut` вырезает поле, а
`awk` работает со столбцами: `-F` задаёт разделитель, `$1` … `$NF` – поля,
шаблон перед `{ }` выбирает строки, а `END { }` выполняется после последней
строки.

## Команды и опции

| Команда | Что делает | Опции и синтаксис из этой части |
|---|---|---|
| `pwd` | Показывает текущий каталог | |
| `ls` | Выводит содержимое каталога | `-l` длинный формат, `-a` и скрытые файлы |
| `cd` | Меняет каталог | `..` вверх, `~` домой, `-` предыдущий каталог, без аргумента = домой |
| `mkdir` | Создаёт каталог | `-p` сразу несколько уровней |
| `touch` | Создаёт пустой файл | |
| `cp` | Копирует | `-r` целые каталоги |
| `mv` | Перемещает или переименовывает | |
| `rm` | Удаляет | `-r` каталоги с содержимым, `-f` без вопросов |
| `rmdir` | Удаляет пустой каталог | |
| `cat` | Выводит файл | |
| `less` | Показывает файл постранично | `/слово` ищет, `q` выходит |
| `head` / `tail` | Первые / последние строки | `-n N` число строк, `tail -f` следит |
| `wc` | Считает строки, слова и байты | `-l` только строки |
| `grep` | Показывает совпадающие строки | `-i`, `-n`, `-v`, `-c`, `-r`, `-E` |
| `sort` | Сортирует строки | `-n` числа, `-r` обратный порядок |
| `uniq` | Удаляет повторяющиеся соседние строки | `-c` считает их |
| `man` | Показывает страницу руководства | |
| `tee` | Передаёт ввод дальше и сохраняет копию | |
| `xargs` | Превращает свой ввод в аргументы для команды | `-n 1` по одному, `-I {}` по строке |
| `tr` | Заменяет символы | `-d` удалить, `-s` сжать |
| `sed` | Правит поток строк | `s/…/…/g`, `d`, `p`, `q`, `-n`, `-i`, `-E`, `-e` |
| `cut` | Вырезает поля | `-d` разделитель, `-f` поле |
| `awk` | Работает со столбцами | `-F` разделитель, `$1`, `$NF`, `NF`, `NR`, `BEGIN`, `END` |

| Синтаксис | Означает |
|---|---|
| `>` / `>>` | stdout в файл (перезаписать / дописать) |
| `<` | stdin из файла |
| `2>` | stderr в файл, например `2> /dev/null` |
| `2>&1` | stderr туда же, куда stdout |
| `\|` | Конвейер: stdout одной команды в stdin следующей |
| `a ; b` | Выполнить a, затем b |
| `a && b` | Выполнить b, только если a завершилась успешно |
| `a \|\| b` | Выполнить b, только если a завершилась с ошибкой |
| `*`, `?`, `[abc]` | Шаблоны для имён файлов |
