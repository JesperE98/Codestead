# Экзамен: Сеть

Покажите, что вы узнали об адресах, именах, портах, вебе и SSH. Вопросы
охватывают всю часть, и для сдачи нужно 80 % правильных ответов.

```quiz
Какие из этих адресов **частные** – используются только внутри локальных
сетей? (Выберите все подходящие.)

- [x] `172.20.1.1`
- [x] `192.168.0.7`
- [ ] `8.8.8.8`
- [ ] `1.1.1.1`
```

```quiz
Веб-сервер, который вы разрабатываете, работает на вашем собственном
компьютере. Куда идёт трафик, когда вы проверяете его по адресу
`http://localhost:8080`?
- [ ] Наружу на роутер и обратно
- [x] Никуда – трафик на localhost никогда не покидает компьютер
- [ ] На DNS-сервер, который отправляет его обратно
- [ ] На `192.168.1.1`
```

```try
ip route
---
Строка `default` показывает шлюз, на который отправляется всё остальное.
```

Система находит строку для `localhost` в `/etc/hosts`. Что выведет эта
команда?

```predict
$ getent hosts localhost
127.0.0.1 localhost
```

Какой DNS-сервер опрашивает Ubuntu, согласно `/etc/resolv.conf`?

```predict
$ grep nameserver /etc/resolv.conf
nameserver 127.0.0.53
---
`127.0.0.53` – это systemd-resolved, локальный посредник на вашем собственном
компьютере, который в свою очередь спрашивает роутер.
```

Порядок, в котором система ищет имена, задаётся в `/etc/nsswitch.conf`. Что
выведет эта команда?

```predict
$ grep hosts: /etc/nsswitch.conf
hosts: files dns
---
Сначала файл (`/etc/hosts`), потом DNS.
```

```quiz
Вы добавили `server.lan` в `/etc/hosts`. `ping server.lan` работает, но
`dig +short server.lan` ничего не выводит. Почему?
- [ ] Строка в `/etc/hosts` неправильная
- [x] `dig` спрашивает DNS напрямую и не смотрит в `/etc/hosts`
- [ ] `dig` нужен `sudo`
- [ ] `ping` не использует имена
---
Чтобы увидеть, что находит *система*, используйте `getent hosts server.lan`.
```

```quiz
`minserver` слушает порт 8080 и работает от имени обычного пользователя. Что
изменилось бы, если бы он слушал порт 80?
- [ ] Ничего
- [x] Открывать порты ниже 1024 может только root
- [ ] Порт 80 предназначен только для SSH
- [ ] Порт 80 нельзя использовать на localhost
```

```quiz

саму страницу?
- [ ] `curl -s http://linux.org`
- [x] `curl -L http://linux.org` – следовать за перенаправлением
- [ ] `curl -o http://linux.org`
```

```quiz
Вы подключаетесь к `server.lan` по ssh, и ssh громко предупреждает, что ключ
хоста сервера изменился. Что это может значить?
- [ ] Срок действия вашего пароля истёк
- [x] Кто-то может выдавать себя за сервер
- [ ] На сервере появился новый пользователь
- [ ] Ваша пара ключей испорчена
---
Ключ хоста был сохранён в `~/.ssh/known_hosts` при первом подключении.
```

```quiz
Вы хотите входить на сервер с парой ключей вместо пароля. Какой ключ
кладётся на сервер?
- [x] Открытый ключ, `id_ed25519.pub`
- [ ] Закрытый ключ, `id_ed25519`
- [ ] Оба
- [ ] Никакой – сервер создаёт свой собственный
---
`ssh-copy-id` добавляет открытый ключ в `~/.ssh/authorized_keys` на сервере.
Никогда никому не показывайте закрытый ключ!
```
