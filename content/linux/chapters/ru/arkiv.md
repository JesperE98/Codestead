# Архивы и сжатие

Рано или поздно вам понадобится отправить кому-то целый каталог, сделать
резервную копию или скачать исходный код программы. Тогда множество файлов
нужно превратить в **один** файл – и желательно поменьше. В Linux это обычно
делают две разные программы, работающие вместе.

## Архивирование и сжатие – разные вещи

- **Архивирование** – это сборка множества файлов и каталогов в один файл,
  *архив*. Права доступа, владельцы и отметки времени сохраняются вместе с
  ними. Программа называется `tar` (от *tape archive* – её написали для
  ленточных накопителей в 1970-х). Архив **не** меньше файлов, которые в нём
  лежат, – скорее даже больше.
- **Сжатие** – это уменьшение файла за счёт более хитрого кодирования
  повторов. Самая распространённая программа – `gzip`. Она обрабатывает только
  один файл за раз и ничего не знает о каталогах.

Поэтому их используют вместе: сначала `tar`, чтобы получить один файл, потом
`gzip`, чтобы сделать его меньше. Результат называется `.tar.gz` или
сокращённо `.tgz`. Это философия Unix в двух словах: маленькие программы,
каждая из которых делает одно дело, и их можно комбинировать.

| Расширение файла | Что это? | Чем распаковать |
|---|---|---|
| `.tar` | Архив без сжатия | `tar -xf` |
| `.gz` | Один сжатый файл | `gunzip` |
| `.tar.gz`, `.tgz` | Сжатый архив | `tar -xzf` |
| `.zip` | Архив и сжатие в одном (распространён в Windows) | `unzip` |

Вам также встретятся `.tar.xz`, `.tar.bz2` и `.tar.zst`. Идея та же, но с
другими программами сжатия (`xz`, `bzip2` и `zstd`).

## Упаковка с помощью `tar`

Перейдите в домашний каталог и упакуйте каталог `dokument`:

```sh
cd ~
tar -cvf dokument.tar dokument
```

```text
dokument/
dokument/frukter.txt
dokument/server.log
```

`-c` означает *создать архив*, `-v` велит tar показывать, что он делает, а
`-f` говорит, что дальше идёт имя файла архива. Всё, что стоит после имени
архива, упаковывается – сколько угодно файлов и каталогов.

> **Внимание!** Порядок такой: *сначала архив, потом файлы*. Если перепутать
> порядок, как в `tar -cvf dokument dokument.tar`, tar попытается
> перезаписать каталог – или, хуже того, файл, который вы хотели сохранить.

## Опции, которые стоит запомнить

| Опция | Расшифровка | Означает |
|---|---|---|
| `c` | **c**reate | Создать новый архив |
| `x` | e**x**tract | Распаковать |
| `t` | lis**t** (*table of contents*) | Показать содержимое |
| `v` | **v**erbose | Показывать обрабатываемые файлы |
| `f` | **f**ile | Дальше идёт имя файла архива |
| `z` | g**z**ip | Сжимать или распаковывать с помощью gzip |

Ровно **одна** из опций `c`, `x` и `t` должна присутствовать – она говорит
tar, *что* делать. Остальные – модификаторы. Популярная английская
запоминалка:

- **c**reate **z**ipped **v**erbose **f**ile → `tar -czvf`
- e**x**tract **z**ipped **v**erbose **f**ile → `tar -xzvf`
- lis**t** **z**ipped **v**erbose **f**ile → `tar -tzvf`

Когда пишете опции слитно, всегда ставьте `f` **последней**, ведь имя файла
должно идти сразу после неё. По историческим причинам дефис можно опустить:
`tar czvf` означает то же самое, что `tar -czvf`.

## Сжатие с помощью `-z`

Добавьте `z`, и архив по пути пройдёт через gzip:

```sh
tar -czvf dokument.tar.gz dokument
ls -l dokument.tar dokument.tar.gz
```

```text
-rw-r--r-- 1 elev elev 10240 Oct 30 12:00 dokument.tar
-rw-r--r-- 1 elev elev   674 Oct 30 12:00 dokument.tar.gz
```

Несжатый архив занимает целых 10 240 байт, хотя в сумме файлы весят чуть
меньше 900 байт. Дело в том, что tar ставит перед каждым файлом заголовок в
512 байт и дополняет архив до целых блоков. Всё это пустое место gzip
сжимает почти до нуля.

Команда `du` (*disk usage*) показывает, сколько места что-то занимает на
диске. С `-h` вы получаете размеры в удобочитаемом виде, а с `-s` – итог для
целого каталога:

```sh
du -h dokument.tar dokument.tar.gz
du -sh dokument
```

```text
12K	dokument.tar
4.0K	dokument.tar.gz
12K	dokument
```

Диск разбит на блоки по 4 КиБ, поэтому `du` никогда не показывает меньше
`4.0K` для непустого файла. Чтобы увидеть точный размер, используйте `ls -l`
(или `ls -lh`).

## Загляните в архив перед распаковкой

```sh
tar -tzvf dokument.tar.gz
```

```text
drwxr-xr-x elev/elev         0 2026-10-30 12:00 dokument/
-rw-r--r-- elev/elev        64 2026-10-30 12:00 dokument/frukter.txt
-rw-r--r-- elev/elev       848 2026-10-30 12:00 dokument/server.log
```

С `v` содержимое показывается как в `ls -l` – с правами, владельцем и
размером. Сначала посмотреть – хорошая привычка: в некоторых архивах нет
общего каталога верхнего уровня, и они рассыпают сотни файлов там, где вы
окажетесь в момент распаковки.

## Распаковка

```sh
mkdir uppackat
tar -xzvf dokument.tar.gz -C uppackat
```

`-C` (заглавная C) задаёт каталог, в который tar распаковывает файлы
(*uppackat* по-шведски значит «распакованное»). Без неё всё окажется в
текущем каталоге. Современные версии tar при распаковке сами определяют,
сжат ли архив, так что `tar -xf dokument.tar.gz` тоже работает.

> **Осторожно!** tar не спрашивает, прежде чем перезаписать уже существующие
> файлы. Если сомневаетесь, сначала посмотрите содержимое.

### Абсолютные пути

Если упаковать абсолютный путь, начальный `/` удаляется, чтобы архив можно
было распаковать где угодно:

```sh
tar -czf backup.tar.gz ~/dokument
```

```text
tar: Removing leading `/' from member names
```

Теперь архив содержит `home/elev/dokument/...`. Если вы хотите, чтобы в архиве
был только `dokument/`, можно попросить tar сначала сменить каталог с помощью
`-C`:

```sh
tar -czf backup.tar.gz -C ~ dokument
tar -tzf backup.tar.gz
```

## Сжатие отдельных файлов с помощью `gzip`

`gzip` сжимает файл и **заменяет** его файлом `.gz`. Права доступа и отметка
времени сохраняются:

```sh
cp dokument/server.log .
gzip -v server.log
```

```text
server.log:	 39.0% -- replaced with server.log.gz
```

`gzip -l` показывает размер до и после, а `gunzip` снова распаковывает файл:

```sh
gzip -l server.log.gz
gunzip server.log.gz
```

Если хотите сохранить оригинал, используйте `gzip -k` (*keep*). Попробуйте на
совсем маленьком файле – он на самом деле станет **больше**, потому что gzip
добавляет заголовок, в котором, помимо прочего, хранится имя файла:

```sh
cp dokument/frukter.txt .
gzip -kv frukter.txt
```

```text
frukter.txt:	-20.3% -- created frukter.txt.gz
```

### Чтение сжатых файлов напрямую

Старые журналы в `/var/log` часто хранятся в виде `.gz`, чтобы сэкономить
место. С помощью `zcat` их можно читать без распаковки – а результат, как
обычно, передать дальше по конвейеру:

```sh
gzip server.log
zcat server.log.gz | grep ERROR
```

`zcat` – то же самое, что `gzip -dc`: распаковать (`d`) в стандартный вывод
(`c`). В настоящей системе есть ещё `zless` и `zgrep`.

## zip – для обмена с Windows

Формат `.zip` делает обе работы сразу: собирает файлы *и* сжимает их. Windows
и macOS открывают zip-файлы без дополнительных программ, поэтому это очевидный
выбор, когда вы отправляете файлы тому, у кого нет Linux. В мире Linux
чаще встречается `.tar.gz`, потому что он лучше сохраняет владельцев и права
доступа.

Программы `zip` и `unzip` установлены не всегда. В таком случае их ставят
пакетным менеджером – подробнее об этом в главе об управлении пакетами. В
{{distro}} это делается так:

:::debian
```sh
sudo apt update
sudo apt install zip unzip
```

`apt update` загружает список доступных пакетов. Без этого apt вообще не
может найти никаких пакетов.
:::

:::arch
```sh
sudo pacman -S zip unzip
```

Ответьте «да» (`Y` или просто Enter), когда pacman спросит, хотите ли вы
продолжить.
:::

:::redhat
```sh
sudo dnf install zip unzip
```

Ответьте `y`, когда dnf спросит `Is this ok [y/N]`, – заглавная `N` означает,
что если просто нажать Enter, ответом по умолчанию будет «нет».
:::

Затем упакуйте каталог. Не забудьте `-r` (*recursive*) – без неё zip добавит
только пустой каталог, а не файлы внутри него:

```sh
zip -r dokument.zip dokument
```

```text
  adding: dokument/ (stored 0%)
  adding: dokument/frukter.txt (deflated 27%)
  adding: dokument/server.log (deflated 42%)
```

Обратите внимание: порядок тот же, что и у tar, – сначала архив, потом файлы.
`unzip -l` показывает содержимое, а `-d` задаёт, куда распаковывать (каталог
создаётся, если его нет):

```sh
unzip -l dokument.zip
unzip dokument.zip -d fran-zip
```

Если файлы уже существуют, unzip их пропускает. С `unzip -o` они
перезаписываются.

## Итоги

| Если нужно ... | Команда |
|---|---|
| упаковать и сжать каталог | `tar -czvf archive.tar.gz directory` |
| посмотреть, что в архиве | `tar -tzvf archive.tar.gz` |
| распаковать архив | `tar -xzvf archive.tar.gz` (добавьте `-C directory`) |
| сжать файл | `gzip file` (или `gzip -k file`) |
| распаковать файл `.gz` | `gunzip file.gz` |
| прочитать файл `.gz` напрямую | `zcat file.gz` |
| создать или распаковать zip-файл | `zip -r archive.zip directory` · `unzip archive.zip` |
| узнать, сколько что-то занимает | `du -sh directory` · `ls -lh` |
