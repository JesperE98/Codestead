# Итоги: Скрипты и автоматизация

В этой части вы превратили команды в собственные программы.

## Скрипты на shell

Скрипт – это текстовый файл с командами, который начинается со строки shebang
`#!/bin/bash`. Его можно написать с помощью here document (`cat > file << '{{heredocEnd}}'`),
сделать исполняемым командой `chmod +x` и запустить через `./`. Строки,
начинающиеся с `#`, – это комментарии.

Переменные создаются так: `имя=значение` – без пробелов, а используются
внутри двойных кавычек: `"$имя"` или `"${имя}_текст"`, если сразу после
имени идёт текст. `$(команда)` заменяется тем, что выводит команда, а `$(( ))`
выполняет целочисленную арифметику. Скрипт получает свои аргументы из `$1`,
`$2` …, `$#` и `"$@"`.

`if` смотрит на код возврата команды – обычно команды проверки `[ ]`. Числа
сравниваются с помощью `-eq`, `-lt` и им подобных, текст – с помощью `=` и
`!=`. `for` перебирает список, `while` повторяется, пока условие истинно, а
`while read` проходит по файлу строка за строкой. `case` выбирает между
шаблонами, функции – это именованные фрагменты кода со своими `$1`, а `read`
спрашивает у пользователя ввод. `exit 1` сообщает тому, кто вызвал скрипт,
что что-то пошло не так.

## Команды и синтаксис

| Синтаксис | Что делает |
|---|---|
| `#!/bin/bash` | Shebang: какая программа выполняет скрипт |
| `cat > file << '{{heredocEnd}}'` | Записать строки в файл до строки `{{heredocEnd}}` |
| `name=value` · `"$name"` · `"${name}"` | Создать · использовать переменную |
| `$(command)` | Заменяется тем, что выводит команда |
| `$(( a * 6 ))` · `(( a++ ))` | Целочисленная арифметика · изменить переменную |
| `$0` · `$1` · `$#` · `"$@"` | Имя скрипта · первый аргумент · число аргументов · все аргументы |
| `if [ ... ]; then ...; elif ...; else ...; fi` | Условия |
| `-f` · `-d` · `-z` | Файл существует · каталог существует · переменная пуста |
| `=` · `!=` | Текст совпадает · различается |
| `-eq` · `-ne` · `-lt` · `-le` · `-gt` · `-ge` | Сравнить числа |
| `[[ $file == *.txt ]]` | Более умная проверка bash, с шаблонами |
| `for x in list; do ...; done` | Цикл по списку |
| `while [ ... ]; do ...; done` | Цикл, пока условие истинно |
| `while read line; do ...; done < file` | Пройти по файлу строка за строкой |
| `break` · `continue` | Выйти из цикла · перейти к следующему проходу |
| `case $x in pattern) ...;; *) ...;; esac` | Выбрать по шаблону |
| `name() { ...; }` · `local` · `return` | Функция · локальная переменная · завершить функцию |
| `read -p "Question " var` | Прочитать строку с клавиатуры |
| `exit 1` | Завершить скрипт с кодом возврата |
| `set -euo pipefail` | Остановить скрипт при первой ошибке |
