# ファイルシステムを移動する

Linux には `C:` のようなドライブ文字がありません。ハードディスク、USB メモリ、
さらにはハードウェアまで、すべてが **ルート**（`/` と書きます）から始まる
**1 つのツリー** 状のディレクトリ構造の中にあります。

## 最も重要なディレクトリ

| ディレクトリ | 内容 |
|---|---|
| `/` | ルート（ツリーのいちばん上） |
| `/home` | ユーザーのホームディレクトリ。例: `/home/{{user}}` |
| `/root` | 管理者 root のホームディレクトリ |
| `/etc` | システムの設定（設定ファイル） |
| `/usr/bin` | `ls` や `cat` などのプログラム（コマンド） |
| `/var/log` | ログファイル |
| `/tmp` | 誰でも書き込める一時ファイル |
| `/dev` | デバイス。例: ディスク |
| `/proc` | プロセスとカーネルに関する情報 |
| `/boot` | コンピューターの起動に必要なファイル |

この構成は *Filesystem Hierarchy Standard*（ファイルシステム階層標準）と呼ばれ、
ディストリビューションが違ってもほとんど同じです。

```quiz
あるプログラムがログファイルを書き出します。どのディレクトリにあると考えられますか？
- [ ] `/etc`
- [ ] `/usr/bin`
- [x] `/var/log`
- [ ] `/home`
---
ログファイルは `/var/log` に置かれます。設定は `/etc` に、プログラムは `/usr/bin` にあります。
```

## 今どこにいる？ – `pwd`

`pwd`（*print working directory*）は、今いるディレクトリを表示します。

```sh
pwd
```

## ここには何がある？ – `ls`

`ls` はディレクトリの中身を一覧表示します。引数なしだと今いるディレクトリを
表示しますが、別のディレクトリを指定することもできます。

```sh
ls /etc
```

`-l` オプションを付けると、より多くの情報を含む詳細形式で表示されます。

```sh
ls -l
```

名前がドットで始まるファイルは **隠しファイル** で、通常は表示されません。
`.bashrc` のような設定ファイルであることがよくあります。`-a`（*all*）
オプションを付けると表示されます。

```sh
ls -a
```

オプションは組み合わせられます。`ls -la` は `ls -l -a` と同じです。

```quiz
ホームディレクトリで `ls` だけを実行しても、ファイル `.bashrc` が表示されないのはなぜですか？
- [ ] root だけが見られるシステムファイルだから
- [x] 名前がドットで始まるので隠しファイルだから
- [ ] `ls` はディレクトリしか表示しないから
---
名前がドットで始まるファイルは隠しファイルです。`ls -a` を使うとそれらも表示されます。
```

詳細形式と隠しファイルの表示を組み合わせて試してみましょう。

```try
ls -la
```

## ディレクトリを移動する – `cd`

`cd`（*change directory*）で別のディレクトリに移動します。

```sh
cd /var/log
```

パスには 2 種類あります。

- **絶対** パスは `/` で始まり、ルートから始まります。例: `/var/log`。
  どこにいても使えます。
- **相対** パスは今いるディレクトリから始まります。`/` にいるなら、
  `cd var/log` だけで `/var/log` に移動できます。

```quiz
いま `/home` にいます。`/home/{{user}}/{{documents}}` に移動できるコマンドはどれですか？（使えるものをすべて選んでください）
- [x] `cd {{user}}/{{documents}}`
- [x] `cd /home/{{user}}/{{documents}}`
- [ ] `cd /{{user}}/{{documents}}`
- [ ] `cd {{documents}}`
---
`{{user}}/{{documents}}` は `/home` からの相対パスで、`/home/{{user}}/{{documents}}` は絶対パスなので
どこからでも使えます。`/{{user}}/{{documents}}` はルートから始まりますが、そこには `{{user}}` はありません。
```

覚えておくと便利な特別な名前がいくつかあります。

| 名前 | 意味 |
|---|---|
| `.` | 今いるディレクトリ |
| `..` | 1 つ上のディレクトリ（親ディレクトリ） |
| `~` | ホームディレクトリ |
| `-` | （`cd` でのみ）直前にいたディレクトリ |

引数なしの `cd` は、いつでもホームディレクトリに戻ります。

```sh
cd ..
```

```predict
$ cd /usr/bin
$ cd ..
$ pwd
/usr
---
`..` は 1 つ上のディレクトリなので、`/usr/bin` から `/usr` に移動します。
```

## Tab 補完

名前を最後まで入力する必要はほとんどありません。たとえば `cd /va` のように
最初の部分を入力して **Tab** を押すと、シェルが残りを補ってくれます。
候補が複数ある場合は、Tab を押すと一覧が表示されます。経験豊富な Linux
ユーザーは、ひっきりなしに Tab を押しています！
