# Linux シェルへようこそ

このガイドでは、コマンドラインから Linux を使う方法を学びます。はじめての
コマンドから、さまざまなディストリビューションでのパッケージ管理まで扱います。
各章では 1 つのテーマを説明します。本文の途中には短い **問題** があり、
それに答えると右側のターミナルとその章の **課題** のロックが解除されます。
正しくできると、課題には自動的にチェックが付きます。いちばんの学び方は
*やってみる* ことです。読んで、試して、失敗して、もう一度試してみましょう。

## Linux とは？

厳密に言えば、**Linux** は *カーネル* だけを指します。カーネルとは、
ハードウェアとやり取りし、ほかのプログラムがプロセッサ・メモリ・ディスクを
共有できるようにするプログラムです。カーネルは 1991 年に Linus Torvalds が
作ったもので、フリーソフトウェアです。

実際に使えるシステムにするには、それ以外にもたくさんのものが必要です。
シェル、ファイルを管理するツール、パッケージマネージャー、場合によっては
デスクトップ環境などです。**ディストリビューション**（*ディストロ*）は、
これらをすべてまとめて、すぐに使える形にしたものです。Debian、Ubuntu、
Arch Linux、Fedora などがよく知られた例です。

このガイドで学ぶことのほとんどは、どのディストリビューションでも同じように
使えるので、コースはそこから始まります。ここにあるターミナルでは
**Ubuntu 24.04 LTS** が動いています。ディストリビューションの違いは主に
ソフトウェアのインストール方法にあり、それはディストリビューションの章で扱います。

## シェルとは？

**シェル** は、入力したコマンドを読み取って実行するプログラムです。
最もよく使われているシェルは **bash** で、ほぼすべてのディストリビューションで
標準になっています。ほかによく使われるシェルには **zsh**（macOS の標準）や
**fish** があります。基本はどのシェルでも同じです。

*ターミナル* と *シェル* の違いに注意しましょう。ターミナルは文字を表示する
ウィンドウで、シェルはその中で動いているプログラムです。

```quiz
`ls` と入力して Enter を押しました。コマンドを読み取って実行するのはどのプログラムですか？
- [ ] ターミナル
- [x] シェル
- [ ] カーネル
---
ターミナルは文字を表示するだけです。入力した内容を読み取って実行するのは
シェル（ここでは bash）です。
```

## プロンプト

シェルがコマンドを待っているときは、**プロンプト** が表示されます。
ここにあるターミナルでは、次のような見た目です。

```text
{{user}}@ubuntu:~$
```

プロンプトは、あなたが誰なのか（`{{user}}`）、どのコンピューターにいるのか
（`ubuntu`）、ファイルシステムのどこにいるのか（`~` はホームディレクトリ
を意味します）を教えてくれます。`$` 記号は一般ユーザーであることを示します。
管理者（*root*）の場合は、代わりに `#` が表示されます。

```quiz
プロンプトの最後が `$` ではなく `#` になっています。これは何を意味しますか？
- [ ] ホームディレクトリにいる
- [ ] 直前のコマンドが失敗した
- [x] 管理者（root）である
```

## はじめてのコマンド

ターミナルをクリックし、次のコマンドを入力して **Enter** を押してください。

```sh
echo {{helloWorld}}
```

`echo` は、渡されたものをそのまま表示するだけのコマンドです。ここでは
*{{helloWorld}}* を表示します。ほとんどのコマンドは同じ形をしています。

```text
command  -options  arguments
ls       -l        /etc
```

*コマンド* は実行するプログラム、*オプション*（*フラグ* とも言います）は
その動作を変えるもの、*引数* はコマンドが処理する対象です。

```quiz
コマンド `ls -l /etc` で、**オプション** はどの部分ですか？
- [ ] `ls`
- [x] `-l`
- [ ] `/etc`
---
`ls` はコマンド、`-l` はその動作を変えるもの、`/etc` は引数、つまり
`ls` が処理する対象です。
```

自分で考えた文を使って `echo` を試してみましょう。

```try
echo Linux is fun
---
`echo` は渡した単語をそのまま表示しました。
```

## 自分は誰で、どこにいる？

いま使っているシステムについて教えてくれる小さなコマンドが 2 つあります。
`whoami` は、ログインしているユーザーの名前を表示します。ファイル
`/etc/os-release` にはディストリビューションの情報が書かれていて、`cat` は
ファイルの内容を表示します（`cat` については後の章で詳しく扱います）。

```sh
whoami
cat /etc/os-release
```

## シミュレーターのしくみ

ここにあるターミナルは、このアプリの中だけで動く **シミュレーター** です。
本物の Linux コンピューターのように動きますが、何をしてもあなた自身の
コンピューターに害を与えることはありません。おかしなことをしてしまっても、
設定の *ターミナルをリセット* でいつでも最初からやり直せます。

- **コード例をクリック** すると、そのコマンドがターミナルに入ります。
- **Tab** でコマンドやファイル名を補完できます。
- **上/下矢印キー** で以前のコマンドをたどれます。
- **Ctrl+L** で画面をクリアし、**Ctrl+C** で入力中の行を取り消します。
- `help` ですべてのコマンドを一覧表示し、`man command` でマニュアルページを表示します。

```quiz
`ech` と入力して **Tab** を押しました。何が起こりますか？
- [ ] 行が取り消される
- [x] シェルが名前の残りを補完しようとする
- [ ] 画面がクリアされる
---
Tab はコマンドやファイル名を補完します。**Ctrl+C** は行を取り消し、
**Ctrl+L** は画面をクリアします。
```
