# सारांश: नेटवर्किंग

इस भाग में आपने टर्मिनल से एक छोटे घरेलू नेटवर्क में अपना रास्ता खोजा: आपका अपना
पता, इंटरनेट तक बाहर जाने का रास्ता, नाम और DNS, पोर्ट, वेब और SSH के ज़रिए दूसरे
कंप्यूटर।

## नेटवर्किंग

नेटवर्क पर हर कंप्यूटर का एक **IP पता** होता है, और `192.168.`, `10.` या
`172.16.`–`172.31.` से शुरू होने वाले पते **निजी** (private) होते हैं। `ip a`
कंप्यूटर के इंटरफ़ेस और पते दिखाता है – `lo` लूपबैक कार्ड है, और `127.0.0.1`
(**localhost**) का मतलब हमेशा ख़ुद वही कंप्यूटर होता है। **नेटमास्क** (`/24`) बताता
है कि कौन-से पते स्थानीय नेटवर्क पर हैं; बाक़ी सब डिफ़ॉल्ट रूट से होकर **गेटवे** तक
जाता है, जिसे `ip route` दिखाता है। `ping` परखता है कि किसी कंप्यूटर तक पहुँचा जा
सकता है या नहीं।

**DNS** नामों को पतों में बदलता है। DNS से पूछने से पहले कंप्यूटर `/etc/hosts` में
देखता है, और `getent hosts` दिखाता है कि सिस्टम क्या हल (resolve) करता है, जबकि
`dig` सीधे DNS से पूछता है। Ubuntu पर `/etc/resolv.conf` `127.0.0.53`, यानी
systemd-resolved, की ओर इशारा करती है, और `dig`, `host` और `nslookup` पैकेज
`dnsutils` में आते हैं।

**पोर्ट** किसी कंप्यूटर पर एक प्रोग्राम की ओर इशारा करता है, और `ss -tulpn` दिखाता है
कि कौन-से पोर्ट सुन रहे हैं। `curl` एक URL लाता है और उसे छापता है, `wget` एक फ़ाइल
में डाउनलोड करता है – Ubuntu पर `wget` पहले से इंस्टॉल होता है और `curl` apt से
इंस्टॉल किया जाता है। **SSH** से आप किसी दूसरे कंप्यूटर पर एन्क्रिप्टेड रूप से कमांड
चलाते हैं; पहली बार आप सर्वर की होस्ट कुंजी की पुष्टि करते हैं, और एक कुंजी जोड़ी
(key pair) के साथ आपको पासवर्ड की ज़रूरत नहीं रहती।

जब "इंटरनेट काम नहीं करता", तो अंदर से बाहर की ओर चलिए: पता, रूट, राउटर, इंटरनेट
पर कोई पता, और आख़िर में कोई नाम। अगर पते काम करते हैं लेकिन नाम नहीं, तो यह DNS है।

## कमांड

| कमांड | क्या करता है |
|---|---|
| `ip a`, `ip -br a`, `hostname -I` | IP पते दिखाना |
| `ip route` | रूटिंग तालिका और गेटवे दिखाना |
| `ping -c 3 HOST` | परखना कि किसी कंप्यूटर तक पहुँचा जा सकता है या नहीं |
| `sudo ip link set CARD down` / `up` | नेटवर्क कार्ड बंद / चालू करना |
| `cat /etc/resolv.conf` | किस DNS सर्वर से पूछा जाता है |
| `dig +short NAME`, `dig @SERVER NAME` | DNS में कोई नाम खोजना |
| `host NAME`, `nslookup NAME` | कोई नाम खोजना (`host` से पते से नाम भी) |
| `getent hosts NAME` | वैसे ही खोजना जैसे सिस्टम खोजता है (`/etc/hosts` के साथ) |
| `sudo tee -a /etc/hosts` | पाइप से आने वाली चीज़ को root के रूप में `/etc/hosts` के अंत में जोड़ना |
| `ss -tulpn` | सुनने वाले पोर्ट दिखाना |
| `curl URL` | लाना और दिखाना |
| `curl -I URL`, `curl -L URL` | सिर्फ़ हेडर, रीडायरेक्ट का पीछा करना |
| `curl -o FILE URL`, `wget URL`, `wget -O FILE URL` | फ़ाइल में डाउनलोड करना |
| `ssh USER@HOST COMMAND` | किसी दूसरे कंप्यूटर पर कमांड चलाना |
| `ssh-keygen`, `ssh-copy-id USER@HOST` | कुंजी जोड़ी बनाना और सार्वजनिक कुंजी सर्वर पर रखना |
