# सारांश: स्क्रिप्ट और ऑटोमेशन

इस भाग में आपने कमांड को अपने ख़ुद के प्रोग्राम में बदला है।

## शेल स्क्रिप्ट

स्क्रिप्ट कमांड वाली एक टेक्स्ट फ़ाइल है जो शेबैंग `#!/bin/bash` से शुरू होती है। आप
उसे here document (`cat > file << 'SLUT'`) से लिख सकते हैं, `chmod +x` से चलाने योग्य
बना सकते हैं और `./` से चला सकते हैं। `#` से शुरू होने वाली पंक्तियाँ टिप्पणियाँ हैं।

आप वेरिएबल `name=value` से बनाते हैं – बिना स्पेस के – और उन्हें दोहरे उद्धरण चिह्नों
के अंदर इस्तेमाल करते हैं: `"$name"`, या `"${name}_text"` जब ठीक बाद में टेक्स्ट
आए। `$(command)` उस चीज़ से बदल जाता है जो कमांड छापता है, और `$(( ))` पूर्णांक
गणित करता है। स्क्रिप्ट अपने आर्ग्युमेंट `$1`, `$2` …, `$#` और `"$@"` से पढ़ती है।

`if` किसी कमांड का एग्ज़िट कोड देखता है, आमतौर पर टेस्ट कमांड `[ ]` का। संख्याओं की
तुलना `-eq`, `-lt` और उनके साथियों से होती है; टेक्स्ट की `=` और `!=` से। `for` एक
सूची पर लूप चलाता है, `while` तब तक चलता रहता है जब तक कोई शर्त सही है, और
`while read` एक फ़ाइल को पंक्ति-दर-पंक्ति पढ़ता है। `case` पैटर्नों के बीच चुनता है,
फ़ंक्शन कोड के नाम वाले टुकड़े हैं जिनका अपना `$1` होता है, और `read` यूज़र से इनपुट
माँगता है। `exit 1` स्क्रिप्ट को बुलाने वाले को बताता है कि कुछ ग़लत हो गया।

## कमांड और सिंटैक्स

| सिंटैक्स | क्या करता है |
|---|---|
| `#!/bin/bash` | शेबैंग: कौन-सा प्रोग्राम स्क्रिप्ट चलाता है |
| `cat > file << 'SLUT'` | पंक्ति `SLUT` तक की पंक्तियाँ एक फ़ाइल में लिखना |
| `name=value` · `"$name"` · `"${name}"` | वेरिएबल बनाना · इस्तेमाल करना |
| `$(command)` | उस चीज़ से बदल जाता है जो कमांड छापता है |
| `$(( a * 6 ))` · `(( a++ ))` | पूर्णांक गणित · वेरिएबल बदलना |
| `$0` · `$1` · `$#` · `"$@"` | स्क्रिप्ट का नाम · पहला आर्ग्युमेंट · आर्ग्युमेंट की संख्या · सारे आर्ग्युमेंट |
| `if [ ... ]; then ...; elif ...; else ...; fi` | शर्तें |
| `-f` · `-d` · `-z` | फ़ाइल मौजूद है · डायरेक्टरी मौजूद है · वेरिएबल ख़ाली है |
| `=` · `!=` | टेक्स्ट बराबर · अलग |
| `-eq` · `-ne` · `-lt` · `-le` · `-gt` · `-ge` | संख्याओं की तुलना |
| `[[ $file == *.txt ]]` | bash का ज़्यादा समझदार टेस्ट, पैटर्न के साथ |
| `for x in list; do ...; done` | एक सूची पर लूप |
| `while [ ... ]; do ...; done` | जब तक शर्त सही है तब तक लूप |
| `while read line; do ...; done < file` | एक फ़ाइल को पंक्ति-दर-पंक्ति पढ़ना |
| `break` · `continue` | लूप से बाहर निकलना · अगले चक्कर पर जाना |
| `case $x in pattern) ...;; *) ...;; esac` | पैटर्न के अनुसार चुनना |
| `name() { ...; }` · `local` · `return` | फ़ंक्शन · स्थानीय वेरिएबल · फ़ंक्शन ख़त्म करना |
| `read -p "Question " var` | कीबोर्ड से एक पंक्ति पढ़ना |
| `exit 1` | एक एग्ज़िट कोड के साथ स्क्रिप्ट ख़त्म करना |
| `set -euo pipefail` | पहली त्रुटि पर स्क्रिप्ट रोक देना |
