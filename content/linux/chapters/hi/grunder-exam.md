# परीक्षा: मूल बातें

इस भाग में आपने जो सीखा है, उसे दिखाने के लिए नीचे दिए प्रश्नों के उत्तर दीजिए।

```quiz
इनमें से कौन-सा पाथ **निरपेक्ष** (absolute) है?
- [ ] `var/log`
- [ ] `../etc`
- [x] `/usr/bin`
- [ ] `{{documents}}`
---
निरपेक्ष पाथ `/` से, यानी रूट से, शुरू होता है। बाक़ी उस डायरेक्टरी से शुरू होते हैं
जिसमें आप हैं।
```

```predict
$ cd /var/log
$ cd ../..
$ pwd
/
---
हर `..` एक स्तर ऊपर जाता है: `/var/log` से `/var` में, और फिर `/` में।
```

```quiz
`cd -` क्या करता है?
- [ ] एक स्तर ऊपर जाता है
- [ ] आपकी होम डायरेक्टरी में जाता है
- [x] उस डायरेक्टरी में वापस जाता है जिसमें आप पिछली बार थे
```

```quiz
आप पूरी डायरेक्टरी `{{pictures}}` को, उसके अंदर की हर चीज़ के साथ, `{{pictures}}-copy` में कॉपी करना चाहते हैं। कौन-सा कमांड काम करता है?
- [ ] `cp {{pictures}} {{pictures}}-copy`
- [x] `cp -r {{pictures}} {{pictures}}-copy`
- [ ] `mv {{pictures}} {{pictures}}-copy`
---
डायरेक्टरी `-r` (*recursive*) से कॉपी होती है। `mv` उसे कॉपी करने के बजाय
स्थानांतरित कर देता।
```

```predict
$ mkdir -p a/b/c
$ ls a/b
c
---
`-p` एक ही बार में `a`, `a/b` और `a/b/c` बना देता है, इसलिए `a/b` में `c` है।
```

```quiz
आप `touch my file.txt` टाइप करते हैं – बिना उद्धरण चिह्नों के। क्या होता है?
- [ ] `my file.txt` नाम की एक फ़ाइल बनती है
- [x] दो फ़ाइलें बनती हैं: `my` और `file.txt`
- [ ] कुछ नहीं, क्योंकि नाम में स्पेस है
---
शेल पंक्ति को स्पेस पर बाँट देता है, इसलिए `touch` को दो आर्ग्युमेंट मिलते हैं। एक
फ़ाइल पाने के लिए `touch "my file.txt"` लिखिए।
```

```quiz
`grep -i error {{documents}}/server.log` कौन-सी पंक्तियाँ दिखाता है?
- [ ] सिर्फ़ छोटे अक्षरों में `error` वाली पंक्तियाँ
- [ ] सिर्फ़ बड़े अक्षरों में `ERROR` वाली पंक्तियाँ
- [x] छोटे-बड़े अक्षरों के किसी भी मेल में `error` वाली पंक्तियाँ
```

```quiz
आप एक लॉग फ़ाइल पर नज़र रखना चाहते हैं और नई पंक्तियाँ लिखे जाते ही देखना चाहते हैं। कौन-सा कमांड सही है?
- [ ] `head -n 10 {{documents}}/server.log`
- [x] `tail -f {{documents}}/server.log`
- [ ] `wc -l {{documents}}/server.log`
---
`tail -f` फ़ाइल का *पीछा* करता है। इसे **Ctrl+C** से रोकिए।
```

```quiz
जब आप `wc` को एक फ़ाइल देते हैं और कोई ऑप्शन नहीं, तो वह क्या छापता है?
- [ ] सिर्फ़ पंक्तियों की संख्या
- [x] पंक्तियों, शब्दों और बाइट की संख्या
- [ ] फ़ाइल की पहली 10 पंक्तियाँ
```

```predict
$ echo a > x.txt
$ echo b >> x.txt
$ echo c > x.txt
$ cat x.txt
c
---
`>>` ने `b` जोड़ा, लेकिन आख़िरी `>` ने पूरी फ़ाइल ओवरराइट कर दी।
```

```quiz
`a || b` में `b` कब चलता है?
- [ ] हमेशा, `a` के बाद
- [ ] सिर्फ़ तब जब `a` सफल रहा हो
- [x] सिर्फ़ तब जब `a` विफल रहा हो
```

```try
grep ERROR ~/{{documents}}/server.log | tee errors.txt | wc -l
---
`tee` ने त्रुटि वाली पंक्तियाँ `errors.txt` में सहेजीं और उन्हें `wc -l` को आगे भेजा,
जिसने उन्हें गिना।
```

```predict
$ echo "a,b,c" | cut -d, -f2
b
---
`-d,` कॉमा को विभाजक बनाता है, और `-f2` फ़ील्ड 2 रखता है।
```

```predict
$ echo "x y z" | awk '{print NF}'
3
---
`NF` पंक्ति में फ़ील्ड की संख्या है। फ़ील्ड स्पेस से अलग होते हैं।
```

```quiz
`'{print $3}'` जैसा awk प्रोग्राम **एकल** उद्धरण चिह्नों (single quotes) में क्यों लिखना चाहिए?
- [ ] awk दोहरे उद्धरण चिह्न नहीं पढ़ सकता
- [x] वरना शेल सोचता है कि `$3` एक शेल वेरिएबल है और awk शुरू होने से पहले उसे बदल देता है
- [ ] एकल उद्धरण चिह्नों से awk तेज़ चलता है
```
