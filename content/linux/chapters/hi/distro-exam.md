# परीक्षा: डिस्ट्रीब्यूशन और पैकेज

नीचे दिए प्रश्नों के उत्तर दीजिए। पास होने के लिए आपको 80 % चाहिए।

```quiz
सभी आधुनिक डिस्ट्रीब्यूशन पर कौन-सी फ़ाइल आपको डिस्ट्रीब्यूशन का नाम और संस्करण
बताती है?
- [ ] `/etc/hostname`
- [x] `/etc/os-release`
- [ ] `/etc/version`
```

```try
uname -r
---
`uname -r` Linux कर्नेल का संस्करण दिखाता है।
```

```quiz
कौन-सा पैकेज मैनेजर और पैकेज फ़ॉर्मैट एक साथ चलते हैं?
- [x] `pacman` और `.pkg.tar.zst`
- [ ] `dnf` और `.deb`
- [ ] `apt` और `.rpm`
```

```quiz
कौन-सा डिस्ट्रीब्यूशन बिना संस्करणों वाला *rolling release* है?
- [ ] Ubuntu LTS
- [ ] Debian
- [x] Arch
- [ ] Fedora
```

```quiz
`apt update` और `apt upgrade` में क्या फ़र्क़ है?
- [x] `update` उपलब्ध पैकेजों की सूची डाउनलोड करता है, `upgrade` नए संस्करण इंस्टॉल करता है
- [ ] `update` नए संस्करण इंस्टॉल करता है, `upgrade` सूची डाउनलोड करता है
- [ ] कोई फ़र्क़ नहीं है
```

```quiz
Arch पर कौन-सा कमांड पैकेज `htop` इंस्टॉल करता है?
- [ ] `sudo pacman -R htop`
- [ ] `sudo pacman -Q htop`
- [x] `sudo pacman -S htop`
- [ ] `sudo pacman -Ss htop`
```

```quiz
`pacman -Sy` और फिर `pacman -S package` चलाना बुरा विचार क्यों है?
- [ ] यह पैकेज को दो बार इंस्टॉल करता है
- [x] यह एक आंशिक अपग्रेड है जो सिस्टम तोड़ सकता है
- [ ] `-Sy` सारे इंस्टॉल किए पैकेज हटा देता है
```

```quiz
dnf पूछता है `Is this ok [y/N]` और आप बस Enter दबाते हैं। क्या होता है?
- [ ] पैकेज इंस्टॉल हो जाता है
- [x] कुछ भी इंस्टॉल नहीं होता – No डिफ़ॉल्ट है
```

```quiz
AUR के बारे में इनमें से कौन-सी बातें सही हैं?
- [x] इसमें बिल्ड नुस्ख़े (`PKGBUILD`) होते हैं, तैयार पैकेज नहीं
- [x] इसके पैकेजों की Arch समीक्षा नहीं करता
- [ ] `sudo pacman -Syu` AUR पैकेजों को अपडेट करता है
- [ ] `makepkg` को sudo के साथ चलाना चाहिए
```

```quiz
Fedora पर कौन-सा कमांड एक COPR रिपॉज़िटरी जोड़ता है?
- [ ] `sudo add-apt-repository copr:user/project`
- [x] `sudo dnf copr enable user/project`
- [ ] `git clone` और `makepkg -si`
```

```quiz
Snap पैकेज कैसे अपडेट होते हैं?
- [ ] `flatpak update` से
- [x] बैकग्राउंड में अपने-आप
- [ ] डेवलपर की वेबसाइट से नई फ़ाइल डाउनलोड करके
```

```predict
$ ~/{{downloads}}/{{calculator}}
bash: /home/{{user}}/{{downloads}}/{{calculator}}: Permission denied
---
डाउनलोड की गई फ़ाइल शुरू में कभी चलाने योग्य नहीं होती। पहले
`chmod +x ~/{{downloads}}/{{calculator}}` चलाइए।
```

```quiz
आपको किसी डेस्कटॉप प्रोग्राम का नया संस्करण चाहिए जो डिस्ट्रीब्यूशन की रिपॉज़िटरी
में नहीं है। मोटा नियम सबसे पहले क्या सुझाता है?
- [ ] किसी अनजान व्यक्ति की अतिरिक्त रिपॉज़िटरी
- [x] एक Flatpak
- [ ] प्रोग्राम को root के रूप में सोर्स कोड से बिल्ड करना
```
