# सारांश: सिस्टम

इस भाग में आपने देखा कि आपके कमांड के आसपास क्या होता है: शेल की याददाश्त, कौन क्या
कर सकता है, कौन-से प्रोग्राम चल रहे हैं और फ़ाइलें एक साथ कैसे पैक की जाती हैं।

## वेरिएबल, PATH और एलियास

किसी वेरिएबल को आप `$NAME` से पढ़ते हैं और `NAME=value` से बनाते हैं – `=` के आसपास
बिना स्पेस के। `export` उसे एनवायरनमेंट वेरिएबल बना देता है, जिसे आपके शुरू किए
प्रोग्राम भी पढ़ सकते हैं। दोहरे उद्धरण चिह्नों के अंदर वेरिएबल अपने मानों से बदल
जाते हैं; एकल उद्धरण चिह्नों के अंदर सब कुछ ठीक वैसा ही छपता है जैसा लिखा है। शेल
कमांड को `PATH` की डायरेक्टरी में खोजता है, और `$?` में सबसे हाल के कमांड का
एग्ज़िट कोड होता है: `0` का मतलब है कि सब ठीक रहा। एलियास और वेरिएबल टर्मिनल बंद
करते ही ग़ायब हो जाते हैं, जब तक आप उन्हें `~/.bashrc` में न डालें।

## यूज़र, अनुमतियाँ और sudo

हर फ़ाइल का एक मालिक, एक समूह और अनुमतियों के तीन सेट होते हैं – मालिक, समूह और
बाक़ी सबके लिए। `r` = 4, `w` = 2 और `x` = 1, इसलिए `755` का मतलब `rwxr-xr-x` है
और `600` का `rw-------`। स्क्रिप्ट को `x` अनुमति चाहिए और उसे `./` से चलाया जाता
है, क्योंकि जिस डायरेक्टरी में आप हैं वह `PATH` का हिस्सा नहीं है। `sudo` एक अकेला
कमांड root के रूप में चलाता है और आपका अपना पासवर्ड माँगता है। Ubuntu पर `sudo`
समूह के यूज़र इसे इस्तेमाल कर सकते हैं।

## लिंक और फ़ाइल की जानकारी

फ़ाइल का कंटेंट और उसकी अनुमतियाँ एक **inode** में रहती हैं, और डायरेक्टरी के नाम
inodes की ओर इशारा करते हैं। `ln -s` एक **सिम्बॉलिक लिंक** बनाता है – एक छोटी फ़ाइल
जिसमें एक पाथ होता है, और जो टारगेट के ग़ायब होने पर टूट जाता है; उसमें relative
पाथ लिंक की अपनी डायरेक्टरी से गिना जाता है। `-s` के बिना `ln` एक **हार्ड लिंक**
बनाता है, यानी उसी inode का एक और नाम। `stat` किसी फ़ाइल के बारे में सब कुछ दिखाता
है, `file` बताता है कि फ़ाइल में क्या है, चाहे उसका नाम कुछ भी हो, और **umask** नई
फ़ाइलों की अनुमतियाँ तय करता है: `022` के साथ उन्हें `644` मिलता है, `077` के साथ
सिर्फ़ `600`।

## प्रोसेस और जॉब

हर चलता हुआ प्रोग्राम एक प्रोसेस है जिसका एक PID और एक पैरेंट (PPID) होता है।
`ps aux` उन सबको दिखाता है, और `top` उन्हें लाइव दिखाता है, प्रोसेसर के इस्तेमाल के
हिसाब से क्रम में। `kill` एक सिग्नल भेजता है: डिफ़ॉल्ट रूप से `SIGTERM` (15), और
आख़िरी उपाय के रूप में `SIGKILL` (9)। `&` के साथ कोई कमांड बैकग्राउंड में चलता है,
और `jobs`, `fg` और `bg` से आप अपने टर्मिनल के जॉब संभाल सकते हैं। `nohup` लॉग आउट
करने के बाद भी कमांड को चलाता रखता है, और `watch` किसी कमांड को बार-बार चलाता है।

## आर्काइव और कंप्रेशन

`tar` फ़ाइलों को एक आर्काइव में इकट्ठा करता है और `gzip` एक अकेली फ़ाइल को छोटा
करता है – दोनों मिलकर आपको `.tar.gz` देते हैं। `c`, `x` और `t` में से ठीक एक tar को
बताता है कि क्या करना है, और `f` के बाद आर्काइव का नाम आता है। `zcat` किसी `.gz`
फ़ाइल को बिना खोले पढ़ता है, और `zip -r` / `unzip` zip फ़ाइलें संभालते हैं, जिन्हें
Windows और macOS के साथ साझा करना आसान है।

## कमांड और ऑप्शन

| कमांड | क्या करता है |
|---|---|
| `echo $NAME` | किसी वेरिएबल का मान दिखाना |
| `export NAME=value` | एनवायरनमेंट वेरिएबल बनाना |
| `env` | सभी एनवायरनमेंट वेरिएबल की सूची |
| `which ls` · `type cd` | दिखाना कि प्रोग्राम कहाँ है · कोई नाम क्या है |
| `echo $?` | पिछले कमांड का एग्ज़िट कोड दिखाना |
| `alias ll='ls -la'` · `unalias ll` | एलियास बनाना · हटाना |
| `source ~/.bashrc` | `~/.bashrc` को तुरंत लोड करना |
| `id` · `groups` | अपना यूज़र और समूह दिखाना |
| `ls -l` | अनुमतियाँ, मालिक और समूह दिखाना |
| `chmod 644 file` · `chmod u+x file` | अनुमतियाँ संख्याओं · चिह्नों से बदलना |
| `sudo command` · `sudo -i` | कोई कमांड root के रूप में चलाना · root शेल शुरू करना |
| `sudo tee -a file` | पाइप के अंत में: ऐसी फ़ाइल में टेक्स्ट जोड़ना जिसे सिर्फ़ root बदल सकता है |
| `ln -s target name` · `ln file name` | सिम्बॉलिक लिंक · हार्ड लिंक बनाना |
| `readlink link` · `realpath path` | लिंक किस ओर इशारा करता है · लिंक के बिना पूरा पाथ |
| `ls -li` | inode नंबर और लिंक काउंट दिखाना |
| `stat file` · `stat -c '%a %U' file` | फ़ाइल के बारे में सब कुछ · सिर्फ़ वह जो आप माँगें |
| `file file` | फ़ाइल में क्या है |
| `umask` · `umask 077` | नई फ़ाइलों से हटने वाली अनुमतियाँ दिखाना · सेट करना |
| `ps` · `ps aux` · `ps -ef` | आपके प्रोसेस · सभी प्रोसेस · पैरेंट के PID के साथ |
| `ps aux --sort=-%cpu` | सभी प्रोसेस, सबसे भारी पहले |
| `pgrep -l name` | नाम से किसी प्रोसेस का PID ढूँढना |
| `top` | प्रोसेस का लाइव दृश्य |
| `kill PID` · `kill -9 PID` | किसी प्रोसेस से बंद होने को कहना · ज़बरदस्ती बंद करना |
| `pkill pattern` · `killall name` | नाम से प्रोसेस रोकना |
| `command &` | कोई कमांड बैकग्राउंड में चलाना |
| `jobs` · `fg %1` · `bg %1` · `kill %1` | जॉब की सूची · फ़ोरग्राउंड · बैकग्राउंड · जॉब ख़त्म करना |
| `nohup command &` | लॉग आउट के बाद भी चलते रहना |
| `watch -n 5 command` | किसी कमांड को हर पाँच सेकंड में चलाना |
| `uptime` · `free -h` | लोड · मेमोरी |
| `tar -czvf archive.tar.gz dir` | किसी डायरेक्टरी को पैक और कंप्रेस करना |
| `tar -tzvf archive.tar.gz` | आर्काइव की सामग्री की सूची |
| `tar -xzvf archive.tar.gz -C dir` | आर्काइव को किसी डायरेक्टरी में खोलना |
| `gzip file` · `gzip -k file` · `gunzip file.gz` | कंप्रेस करना · मूल फ़ाइल रखना · खोलना |
| `zcat file.gz` | कंप्रेस की गई फ़ाइल सीधे पढ़ना |
| `zip -r archive.zip dir` · `unzip archive.zip -d dir` | zip फ़ाइल बनाना · खोलना |
| `du -sh dir` | दिखाना कि कोई चीज़ कितनी जगह लेती है |
