# परीक्षा: नेटवर्किंग

दिखाइए कि आपने पतों, नामों, पोर्ट, वेब और SSH के बारे में क्या सीखा है। प्रश्न पूरे
भाग से हैं, और पास होने के लिए आपको 80 % सही चाहिए।

```quiz
इनमें से कौन-से पते **निजी** हैं – जो सिर्फ़ स्थानीय नेटवर्क के अंदर इस्तेमाल होते हैं?
(जो भी लागू हों, सब चुनिए।)
- [x] `10.0.0.5`
- [x] `172.20.1.1`
- [x] `192.168.0.7`
- [ ] `8.8.8.8`
- [ ] `1.1.1.1`
```

```quiz
आप जो वेब सर्वर बना रहे हैं, वह आपके अपने कंप्यूटर पर चलता है। जब आप उसे
`http://localhost:8080` पर परखते हैं, तो ट्रैफ़िक कहाँ जाता है?
- [ ] बाहर राउटर तक और वापस
- [x] कहीं नहीं – localhost का ट्रैफ़िक कभी कंप्यूटर से बाहर नहीं जाता
- [ ] DNS सर्वर तक, जो उसे वापस भेज देता है
- [ ] `192.168.1.1` तक
```

```try
ip route
---
`default` वाली पंक्ति वह गेटवे दिखाती है जिसे बाक़ी सब कुछ भेजा जाता है।
```

`/etc/hosts` में `localhost` वाली पंक्ति वह है जो सिस्टम को मिलती है। यह क्या छापता
है?

```predict
$ getent hosts localhost
127.0.0.1 localhost
```

`/etc/resolv.conf` के अनुसार Ubuntu किस DNS सर्वर से पूछता है?

```predict
$ grep nameserver /etc/resolv.conf
nameserver 127.0.0.53
---
`127.0.0.53` systemd-resolved है, आपके अपने कंप्यूटर पर एक स्थानीय बिचौलिया, जो आगे
राउटर से पूछता है।
```

```quiz
आप बिना किसी ऑप्शन के `ping 192.168.1.1` चलाते हैं। यह कब रुकता है?
- [ ] 3 पैकेट के बाद
- [ ] एक पैकेट के बाद
- [x] जब आप Ctrl+C दबाते हैं
- [ ] जब पहला जवाब आता है
---
`-c` से आप चुनते हैं कि कितने पैकेट भेजने हैं।
```

सिस्टम किस क्रम में नाम खोजता है, यह `/etc/nsswitch.conf` में तय होता है। यह क्या
छापता है?

```predict
$ grep hosts: /etc/nsswitch.conf
hosts: files dns
---
पहले फ़ाइल (`/etc/hosts`), फिर DNS।
```

```quiz
आपने `/etc/hosts` में `server.lan` जोड़ा है। `ping server.lan` काम करता है, लेकिन
`dig +short server.lan` कुछ नहीं छापता। क्यों?
- [ ] `/etc/hosts` की पंक्ति ग़लत है
- [x] `dig` सीधे DNS से पूछता है और `/etc/hosts` को अनदेखा करता है
- [ ] `dig` को `sudo` चाहिए
- [ ] `ping` नाम इस्तेमाल नहीं करता
---
*सिस्टम* क्या हल करता है, यह देखने के लिए `getent hosts server.lan` इस्तेमाल कीजिए।
```

```quiz
`myserver` पोर्ट 8080 पर सुनता है और एक सामान्य यूज़र के रूप में चलता है। अगर वह
पोर्ट 80 पर सुनता, तो क्या अलग होता?
- [ ] कुछ नहीं
- [x] 1024 से नीचे के पोर्ट सिर्फ़ root खोल सकता है
- [ ] पोर्ट 80 सिर्फ़ SSH के लिए है
- [ ] पोर्ट 80 localhost पर इस्तेमाल नहीं हो सकता
```


```quiz
आप ssh से `server.lan` से जुड़ते हैं, और ssh ज़ोर से चेतावनी देता है कि सर्वर की होस्ट
कुंजी बदल गई है। इसका क्या मतलब हो सकता है?
- [ ] आपके पासवर्ड की अवधि ख़त्म हो गई है
- [x] कोई सर्वर होने का नाटक कर रहा हो सकता है
- [ ] सर्वर पर एक नया यूज़र है
- [ ] आपकी कुंजी जोड़ी टूट गई है
---
पहली बार जुड़ने पर होस्ट कुंजी `~/.ssh/known_hosts` में सहेजी गई थी।
```

```quiz
आप पासवर्ड के बजाय कुंजी जोड़ी से सर्वर पर लॉग इन करना चाहते हैं। सर्वर पर कौन-सी
कुंजी रखी जाती है?
- [x] सार्वजनिक कुंजी, `id_ed25519.pub`
- [ ] निजी कुंजी, `id_ed25519`
- [ ] दोनों

`ssh-copy-id` सार्वजनिक कुंजी को सर्वर पर `~/.ssh/authorized_keys` में जोड़ता है।

```
